## 三、方法（三层，互不依赖）

1. **cell 字段归因**：lyrdb 每个 `<item>` 带 `<cell>`＝违规被发现时所处的 cell。KLayout 分层 DRC 在**跨 cell 交互**时把违规报在**共同祖先 cell**（此处＝M4_TOP_V3）。故：
   * `cell == M4_TOP_V3` 的条目＝**顶层侧**（跨岛交互 + 顶层走线自身）；
   * `cell == TX5G_M2_MIX_V29 / TX5G_M3_DRV1_V20 / TX5G_M3_DRV2_V20`＝块内；
   * `cell == npn13G2$… / rsil$… / rppd$…`＝块内器件 PCell。
2. **归一化多重集相等**：顶层报告的 (cell, category) 多重集，与三岛报告并集的同名多重集逐项相等（双向）。归一化＝去掉 KLayout 变体后缀 `$N`（同一 PCell 在多岛出现时的同名消歧）。
3. **坐标系判定 + 落位实测**：用顶层件 GDS 实测三岛摆位与 bbox，判定条目坐标属于**块局部帧**还是**顶层帧**，并验证叠加摆位偏移后落进顶层帧对应岛的 bbox 内。

## 五、结论

* **C1 ★顶层侧零违例**：顶层 418 条中，`cell == M4_TOP_V3` 的条目 **0 条** ⇒ **既无跨岛交互违例，也无顶层走线自身违例**。这与裁定八十五「换版不破走线」**互相独立、互为佐证**（八十五＝几何/净距侧，八十六＝DRC 报告侧）。
* **C2 ★418 全部为块内继承**：418 = 253（mix v29）+ 18（drv1 v20）+ 147（drv2 v20），逐条可归、逐规则零漂移 ⇒ **顶层件 DRC 418 不代表顶层设计缺陷**，它是基座三块陈旧版内部违例的原样继承（与裁定八十四「顶层 418 与现役无关」同向，并给出机制）。
* **C3 修正阶段九十四的「17 类规则」**：现算实测顶层报告为 **16 类**（cont/metal1/gatpoly/extblock/psd/activ/substrate/polyres/salblock 的 Offgrid 族 ＋ CntB.h1/CntB.g2/M1.b/M2.b/M4.b/V1.a/V1.b）⇒ 阶段九十四记载「17 类」为**误记**，此处现算修正为 16（自纠，见第七节）。
* **C4 预期装配后顶层 DRC 基线 ＝ 384**：换现役三块后，顶层 DRC 预期 = 现役三块之和（mix v35 **219** ＋ drv1 v23 **18** ＋ drv2 v22 **147** ＝ **384**）＋ 顶层侧 **0** ＝ **384**，较现基线 418 **减 34**，**全部来自 mix（253→219）**，drv1/drv2 零差。
* **C5 ★但 384 是预期值、不是实测值**：跨岛交互风险并未随基座消除——裁定三十八记 M4 **v2** 基座曾出现**岛际型违例**（drv1 岛内 M2 顶缘 ↔ 顶层 nmixn M2 横段净距 0.195µm < 0.21µm，差 15nm），**岛级 DRC 结构性抓不到、只有顶层代跑能抓到**；v3 基线因该条被修掉而表现为顶层侧 0 条，但换入 mix v35（v34＋M4.b 根修）后几何已变，**跨岛净距必须重测** ⇒ **候选合并件装配后顶层 DRC 必须重跑**，384 只作对照基准（预期与实测之差＝新出现的跨岛交互条数）。
* **C6 对 P4 的影响**：P4「DRC/LVS 回归段」四件待决之④（走线）已由八十五收敛；本裁定把「顶层 DRC 基线」从**未归因的总数**变为**可预期的结构**：块内违例随块版本走（253→219 等），顶层侧违例必须以装配后实测为准（基线 0 条，预期 0 条）。

## 七、自纠（本口工具与既往记录）

1. **工具首版四处缺陷，全部由机器校验自己暴露**（未靠人眼）：①C04 集合表达式误写成 `set(i["cell"])`（迭代字符）⇒ 判定恒假；②C11 坐标正则要求坐标对带闭合括号，而 lyrdb 的 value 用 `;` 分隔（`(-10.85,31.05;-12.5,31.05)`）⇒ 坐标解析全空、受检 0 条；③每岛继承数按「逐条目 × 该岛份额」累乘 ⇒ mix 被算成 8279（正确 253）；④改名可解释判定只认「本侧含 `$`」⇒ 岛侧基名（`rppd`）被误判为不可解释。**四者皆先表现为 FAIL，再定位修复**，无一靠"应该没问题"放行。
2. **阶段九十四「17 类规则」为误记**：现算为 **16 类**，本裁定据实修正（C10）。
3. **坐标系判定写成可证伪形式**：C11 要求「局部帧越界 = 0 **且** 顶层帧越界 > 0」——后者保证两帧可区分，防止该判定退化为恒真。

## 八、新律三条

* **★DRC 报告须按报告 cell 逐条归因、禁只报总数律**：lyrdb 的 `<cell>` 字段直接给出违规所在 cell；跨 cell 交互报在共同祖先 ⇒ 顶层侧条目数＝`cell==顶层cell` 的条目数。报「顶层 418 条」而不分归属，等于没测。
* **★分层 DRC 的跨 cell 交互只有顶层代跑抓得到律**（裁定三十八 v2 的 0.195µm 岛际违例实证）：岛级 DRC 结构性抓不到岛际净距；「顶层侧 0 条」只对**该基座该版本**成立，换块后必须重跑。
* **★归一化必须配反向对照律**：PCell 同名多实例会产生 `$N` 变体名；比较两报告前须归一化，并同时给出「未归一化的差集全部为改名等价」与「关闭归一化即 FAIL」两条证据（否则无法排除「用归一化掩盖了真实差异」）。
