## 1. 系统链路衔接（与 design_circuit v1.4 预算表的映射）

旧链口径（40nm CMOS，v1.4 §2）：链入 −5 dBm → VGA 0dB 档 → 混频器净 0dB → 驱动 +6dB → PA 输入 +1dBm → PA +17dB → 6G 输出 +18 dBm。

组长指定 **Gilbert 有源混频**（替代原「gm 级+25% 无源正交」），典型 CG +2~+6 dB。增益重分配两案（首版网表按**模块最优**做，链路定案等代跑数据）：

| 方案 | MIX CG | DRV 增益 | 说明 |
|---|---|---|---|
| A（默认） | +2 dB（gm 对大简并换取 OIP3，RL 压低） | +4 dB（DRV1 +8 → 级间 π 衰减 4dB → DRV2 +6，或 DRV1 直接做 +2dB 缓冲档） | 链路总增益与旧链一致，VGA 档位/分配表**零改动** |
| B | +4 dB（模块 CG 最优） | DRV 需求降为 +2 dB；级间衰减器加 2dB | 多 2dB 混频线性度压力换驱动电流 |

**判据**：混频器带内 IM3 直接入 EVM（IF 双音 9/11 MHz → IM3 落 LO±(7,13) MHz，信道内），按旧分配 VGAMIX −46 dB 反推要求 **OIP3 ≥ +15 dBm**（三次方口径近似，双音每音 S=−8 dBm）。这是 gm 对尺寸的主导约束——**OIP3 优先于 CG**，缺的增益由 DRV1 补（HBT 高 gm，代价小）。

## 3. 模块设计

### 3.1 上变频混频器 MIX（Gilbert double-balanced）

```
         VCC 2.5V
      ┌───┬───┐
     RL   RL   (45Ω/边 + L tank 5.5G，首版 R+tank 简化)
      out+ │  out−   ← RF 差分输出（LO+IF 边带）
   ┌──swQ3┬swQ4┐      开关对 Q3-Q6 nx=4，LO 差分驱动
   └──┬───────┬──┘
   gmQ1═gmQ2           跨导差分对 nx=6，Re=15Ω/边（8/15/22Ω 三档预留）
      │  IF+ / IF−（0–160MHz，基极偏置 1.2V 经高阻）
     I_tail 16mA（HBT 电流镜，Vbe 基准）
```

| 项 | 值 | 说明 |
|---|---|---|
| gm 对 | npn13G2 nx=6，Ic_pair=16 mA（8mA/边），Re=15 Ω/边（rsil） | 简并系数 1+gm0·Re≈4.6 → IIP3 半电路单音 ~+15 dBm 量级；gm_eff≈50 mS/边 |
| 开关对 | Q3–Q6 nx=4，LO 差分 0.4 Vpp | 全切换需 ~4Vt=103 mV/管，裕量足；Vce 稳态 ~0.8 V |
| 负载 | R=45 Ω/边 + L(1 nH 理想)//C(0.8 pF) tank @5.5 GHz | 抑制 LO 泄漏/IF 谐波；电感版图阶段换 PDK 电感（Q~15） |
| 偏置 | 尾流 16 mA HBT 镜像；gm 对基极 **1.2 V** 高阻注入（理想 V 源+2 kΩ）——ntail≈+0.20V 镜像合规 | 版图阶段换带隙+温度补偿 |
| **目标** | **CG +2 dB（方案 A）/ OIP3 ≥ +15 dBm / LO-RF 隔离 ≥ 35 dB / LOFT ≤ −40 dBc** | tb 双音 IF 9/11 MHz @ −8 dBm/音 |
| 功耗 | 16 mA × 2.5 V = **40 mW**（旧预算 33 mW，超 7 mW 换 OIP3，待对账） | |

### 3.2 PA 驱动级 DRV（2 级）

| 项 | DRV1（CE+简并） | DRV2（CASCODE 输出级） |
|---|---|---|
| 结构 | npn13G2 CE，Re=4 Ω/边；级间 π 衰减 4 dB（预留） | CE(nx=10) + 共基 CB(nx=10)，Re=1.5 Ω/边 |
| 偏置 | Ic=8 mA（4mA/边，1.33mA/unit），基极 **0.95 V** 经镜像（v0.91：0.88V 时 ntail 贴地）；单管 Vce≈2.4V 声明口径 | Ic=30 mA（15mA/边，3mA/unit 近 fT 峰区），CE 基极 **0.95V**；**Vbcas=2.05V**→ccas≈1.16V，CE Vbc 反偏 ✓ |
| 负载 | tank @5.5G，RL 差分 50 Ω 口（半电路 25 Ω） | tank @5.5G（L~0.7 nH 理想）→ 输出差分 50 Ω（tb 口；版图阶段换变压器 1:1） |
| 增益 | ~+8 dB（gm_eff 96 mS × 25 Ω） | ~+6~8 dB（30 mA 强驱动） |
| **目标** | OP1dB ≥ −4 dBm，OIP3 ≥ +8 dBm | **OP1dB ≥ +10 dBm**（PA 输入 +1 dBm 留 9 dB 回退），OIP3 ≥ +18 dBm |
| 功耗 | 20 mW | **75 mW**（1.8V 轨可降到 ~54 mW） |

fT 富余：全链工作频率 5.5 GHz 仅为 fT（>380 GHz）的 **1.4%**——电流密度可自由偏向线性度/效率，不构成约束。关键参数是 fmax 与击穿（cascode 后 C-B 反偏最大 ~2.3V < BVCBO 4.5V ✓，tb 复核）。

## 7. 2.4G 复用架构说明（任务书要求，简要）

- **同一模拟链路复用**，分带靠三处切换：① LO 频率（6G 直通 5.5G / 2.4G 由 VCO 4.8G÷2，沿用 architecture 方案）；② 各级 tank 电容阵列切换（5.5G：L 1nH/C 0.8pF；2.4G：L 1nH 需 C≈4.2pF，cmim 开关位 4 bit 覆盖 0.8–5 pF）；③ DRV2 电流档位（2.4G 增益需求高 5dB → 电流 +20% 或 tank Q 提升补偿）。
- HBT 器件本身 2.4–5.85 GHz 宽带可用（fT 比 5.5G 高 70 倍），无需双链路。带宽切换的 S 参数/平坦度在第二轮网表加 2.4G tb 验证。

## 8. 风险与边界
