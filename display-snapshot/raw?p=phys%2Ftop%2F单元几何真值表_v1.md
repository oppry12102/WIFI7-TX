## 4. 库 API 与纪律（v1 现状）

- `Board(top_name)` → `rect/wire_h/wire_v/path/label`（µm 坐标；DBox/Text dbu 坑已处理）、`mkpc_at`（锚点摆放+镜像）、`via`、`bondpad`、`net_check(ALL)`（连通簇/短路/悬空自检）、`save`。
