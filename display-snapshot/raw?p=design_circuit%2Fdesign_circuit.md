## 0. 结论摘要

| 项 | 结论 |
|---|---|
| **预算是否闭环** | **闭环，且有裕量**。全链 EVM：6G **−44.7 dB**、2.4G **−44.9 dB**（目标 −41 dB，裕量 3.7/3.9 dB）；功耗 6G **881 mW**（上限 1000）、2.4G **731 mW**（上限 800）。7 个 EVM 分配块**全部达标**，每块裕量 ≥2.1 dB。 |
| **有无超差项** | **无超差项，但有 1 个硬依赖 + 6 项待裁决（§5）**：本设计闭环**依赖架构未列的 DPD**（6G 需 13 dB、2.4G 需 24 dB 三阶 IM3 对消，已把 60 mW 计入预算）；§7 已把「不引入 DPD」的代价算清——加大 PA 要全链 1818 mW（上限 800）、偏置回退救不了 EVM、只剩降输出功率一条路（2.4G 降 7.0 dB / 6G 降 3.5 dB）。若 DPD 对消能力只有 15 dB，2.4G 全链 EVM 仅 **−39.5 dB（不达标）**。 |
| **风险头条** | **LO 近带相噪是 EVM 的第一限制项**（6G 仅 2.1 dB 裕量）：参考源用常规 40 MHz TCXO 会使 LO_IPN 恶化 **14 dB**（−50.1 → −36.2 dB），直接击穿 −48 dB 分配。参考源规格必须写进 spec。 |

## 1. 口径与假设（复算的前提，全部显式声明）

### 1.1 EVM 口径（关键：与任务书一致）

- **EVM_dB ≡ 10·log10(P_err / P_sig)**（功率比口径）。
  用任务书给定分配表复算：DAC −50 / 重构滤波 −55 / VGA+混频 −48 / LO IPN −48 / IQ −52 / LOFT −52 / PA −46，
  RSS = **−41.2 dB**，与任务书标注的 −40.8 dB 一致（差异来自取整），故确认组长采用的是**功率比口径**，本文与脚本均沿用。
  若误用幅度口径（20log10），同一张表 RSS 会变成 −32.8 dB —— 差 8 dB，这是对账时最容易出错的地方。

### 1.2 计算公式

| 项 | 公式 | 说明 |
|---|---|---|
| 三次方失真（单级） | P_IM3 = k·(P_out/OIP3)³·P_out，k = 0.75 | 双音三次方，每级失真按**其后各级增益**折算到链输出后 RSS |
| OIP3 级联 | 1/IIP3_tot = Σ_i G_prefix,i² / OIP3_i；OIP3_tot = IIP3_tot + G_tot | dB 域：10^((2·prefix − OIP3_i)/10) 求和 |
| OP1dB 级联（简化） | P1dB_tot = min_i ( P1dB_i + 其后各级增益之和 ) | 任务书要求的"简化级联公式"；忽略压缩累加，**偏乐观** |
| 相噪 → EVM | σ² = 2∫₁ₖ^₁₀₀ᴹ L(f) df；EVM = σ²/2 | L(f) 为单边带相噪 dBc/Hz；理想 1/N 分频**保持 dBc/Hz 不变**，只叠加分频器自身底噪 |

### 1.3 显式假设清单

| # | 假设 | 依据/影响 |
|---|---|---|
| A1 | 工艺：40 nm CMOS 典型角（TT, 25 °C, 1.1/1.8/2.0 V） | spec 给定工艺，未给 PDK；所有器件级数字为估算级 |

## 2. 逐级参数表

电平链（两条带）：链入 −5 dBm → 2.4G 输出 +23 dBm（增益 28 dB）／6G 输出 +18 dBm（增益 23 dB）。

### 2.1 DAC（12b, 1.28 Gsps, 1.8 V, 25 mW）

| 项 | 值 | 说明 |
|---|---|---|
| **结构选型** | **分段电流舵 DAC（6b 二进制 + 6b 温度计分段）** | 备选①纯二进制加权 CS：面积小但 INL/glitch 差，−50 dB 分配达不到；备选②R-2R 电阻串：省面积，但 1.28 Gsps 下寄生与开关电阻难以匹配。选分段：温度计把单开关做大，glitch 能量分散。 |
| 满量程电流 | 11.5 mA（1.8 V，含偏置 25 mW） | 输出 −5 dBm @50 Ω |
| 线性度 | INL ≤ 0.5 LSB，DNL ≤ 0.2 LSB；有效位 ≈ 11.5（SNR 71 dB） | 分配 −50 dB，设计 −53 dB（INL −68 / glitch −56 / ISI −57 三项 RSS） |
| 关键无源 | 单位电容阵列（总电容 ≈1.2 pF，MIM 1.5 fF/μm²）；bootstrap 采样开关 | 面积 ≈0.8 mm² |
| 版图敏感点 | 单位电容阵列周边对称（梯度匹配）；时钟走线与开关节点寄生不对称 → glitch；温度计段边界处的电流阶跃 | |

### 2.2 4 阶重构 LPF（fc≈420 MHz, 1.8 V, 13 mW）

| 项 | 值 | 说明 |
|---|---|---|
| **结构选型** | **Gm-C 4 阶 Butterworth + 输出缓冲** | 备选①无源 RC + 源跟随：功耗最低，但级间 Q 受寄生与负载牵制，fc 漂移不可控；备选②有源 RC（MFB，每级 1 阶）：Q 精确，但 4 阶需 2 级级联，每级 GBW 需 >10 GHz，40 nm 下 gm 级 ~10 mA/级 → 超 13 mW 预算。**选 Gm-C**：0.5 pF/节点 → gm = 2π·fc·C = 1.3 mS/级。 |
| 偏置 | Vov = 0.2 V，Id ≈ 0.35 mA/级 ×4 级 + 缓冲 ≈ 7.2 mA | 12.9 mW ✓ 与 13 mW 预算吻合 |
| 通带/阻带 | 160 MHz 处 −0.16 dB；1.12 Gsps 第一镜像（1.12 GHz）−34 dB | 与 DAC 镜像本底 −45 dBc 合成 −79 dBc → 对 EVM 贡献可忽略 |
| 关键无源 | MIM 电容 0.5 pF/节点（≈580 μm²），共 6 个节点 | 面积 ≈0.35 mm² |
| EVM 贡献 | −58 dB（分配 −55） | 假设通带幅相误差 RMS 0.13% |

### 2.3 VGA（0–15 dB，0.5 dB 步进，1.8 V，15 mW）

| 项 | 值 | 说明 |
|---|---|---|
| **结构选型** | **dB-线性开关电阻衰减器 + 两级共源共栅 gm 放大** | 备选①MOS 三极管衰减：面积小，但线性度/温漂差，每档需数字校准；备选②两级独立 VGA：级数多、增益精度差。选电阻衰减：0.5 dB 步进只需版图匹配 σ<0.5%，无温漂。 |
| 增益 | 0–15 dB，31 档；单级 8 dB，NF 6 dB | 满功率档 0 dB |
| 线性度 | OIP3 **+18 dBm**（0 dB 档，输入 −5 dBm → 23 dB 余量） | EVM 贡献 −69 dB（分配 −48，**极宽松**） |
| 偏置/电流 | 1.8 V，1.5 mA/级 ×2 = 3 mA + 衰减网络偏置 → 8 mA = 14.4 mW | ✓ 预算 15 mW |
| 关键无源 | 衰减电阻 1–8 kΩ（薄层多晶）；30 pF 补偿电容（带宽 ≥3.5 GHz） | 0.5 dB 步进 → 电阻比 1.122，需单位电阻交叉排布 |

### 2.4 混频器（gm 级 + 25% 占空无源正交，1.8 V，33 mW）

| 项 | 值 | 说明 |
|---|---|---|

| 项 | 值 | 说明 |

### 2.6 功率级（6G：+17 dB / 直流 600 mW；2.4G：+22 dB / 直流 450 mW）

| 项 | 6G | 2.4G |
|---|---|---|
| **结构选型** | **3 级共源共栅（1.8 V 薄氧驱动 + 2.0 V 厚氧功放），每级 4–8 unit 并联，级间电感/变压器** | 同左，1.8 V 薄氧即可 |

### 2.7 LO / PLL（55 mW）

- **ΣΔ 分数 N PLL**，环路 BW 800 kHz；VCO 4.8–7.2 GHz 双子带（核心电感 + 变容切换子带）；**6 GHz 直通 / 2.4 GHz ÷2**。
- ÷2 保持 dBc/Hz 相噪不变，仅叠加分频器自身 1/f 底噪（假设 −140 dBc/Hz）。
- 功耗拆分（估算）：VCO 25 mA@1.8 V = 45 mW + 分频/LO 驱动 ≈ 10 mW。
- **正交 LO**：I/Q 由 90° RC 网络（2 路极对称）；25% 占空误差 δ → IQ 不平衡 ≈ δ/2；要达校准后 −55 dB，需 δ ≤ 0.22%（两级整形 LO 缓冲可达 ±0.1%）。

### 2.8 辅助路与校准（40 mW）

| 项 | 值 | 说明 |
|---|---|---|
| 耦合器 | −25 dB，变压器耦合（1:4 匝比） | 输出端并联，强耦合需注意对 PA 输出的负载 |
| RF 检波 | 平方律 MOS 检波 + 对数放大，**动态范围 ≥70 dB**（要看 −55 dBc 的校准残差）→ 两段式（粗平均 + 峰值保持） | 4096-QAM PAPR ≈ 11 dB，纯平均检波会低估 |
| ADC | 10-bit、20 MS/s（320 MHz 包络采样），功控闭环 ±1.5 dB | |
| 校准 | LOFT / IQ 失配 / PA 温漂；观测口复用同一耦合器 + 检波 | 建议 DPD 反馈用**独立耦合器**或时分复用，避免互相拖累 |

### 2.9 DPD（60 mW，架构未列，见 OQ-4）

- 三阶 IM3 对消（记忆多项式长度 5），1.28 Gsps 等效多相累加，40 nm 数字逻辑 ≈50–70 mW。
- 本设计只对消 IM3，**未含 AM/PM 相位线性化**（偏乐观，见 A12 / R1）。
- 取舍的完整量化见 **§7（`dpd_study.py`）**：满功率下 2.4G 需 ≥23 dB、6G 需 ≥12 dB 三阶对消；不上的话只有「降输出功率」一条现实路线。

## 7. DPD 取舍量化研究（`dpd_study.py`，支撑 OQ-4 裁决）

### 7.1 为什么要单列

OQ-4 问的是「架构没列 DPD，要不要加进来」。这个问题不能靠感觉答：**DPD 值 60 mW，不值那 1300 mW 吗？** 本节把这个问题算成四张表——DPD 拿掉会怎样、拿掉后有哪些替代路线、每条路线各付多少 dB / 多少 mW / 是否还守得住输出功率规格。

方法上不引入新的失真模型：全部数字来自 `budget_check.py` 的同一套公式与同一份 `params.csv`，只是换着问不同的问题。判定口径与 `budget_check.py` 完全一致：

- **EVM 口径**：全链 EVM ≤ 设计目标 − 自设裕量（2.4G/6G 均 ≤ −43 dB）
- **总体口径**：EVM 口径 ∧ 每块 EVM 优于分配值 ≥ 2 dB ∧ 功耗 ≤ 上限 ∧ 输出功率 = 规格

### 7.2 结论速览（两带）

| 问题 | 2.4G（+23 dBm / 上限 800 mW） | 5-6G（+18 dBm / 上限 1000 mW） |
|---|---|---|
| 设计取用的 DPD 对消量 | 24 dB | 13 dB |
| **满功率所需最小 DPD 对消（EVM 口径）** | **20 dB** | **10 dB** |
| **满功率所需最小 DPD 对消（总体口径）** | **23 dB** | **12 dB** |
| 设计取值余量 | 1 dB | 1 dB |
| 无 DPD · 驱动回退（偏置不动） | 需 **7.0 dB** → Pout 16.0 dBm（比规格低 7 dB） | 需 **3.5 dB** → Pout 14.5 dBm（低 3.5 dB） |
| 无 DPD · 偏置回退（省电） | **12 dB 内无解**（回退 12 dB、PA 块仅 −34.4 dB） | **无解** |
| 无 DPD · 加大 PA（OIP3 +Δ） | EVM 口径需 PA 直流 **≈1540 mW**（exp=1.5）→ 全链 **1818 mW = 上限的 2.3 倍** | 需 PA 直流 **≈1110 mW** → 全链 **1390 mW**，仍超上限 |
| 目标放回规范 −38 dB 时所需回退 | 4.4 dB → Pout 18.6 dBm | 0.8 dB → Pout 17.2 dBm |

**三条一句话结论**

1. **加大 PA 换线性度在两条带都不成立**——三档电流标度指数（OIP3 ∝ I^1.0 / 1.5 / 2.0）算下来都要超功耗上限 1.4–2.3 倍。这条路可以排除。
2. **省电式的偏置回退救不了 EVM**——OIP3 随电流下降，每 1 dB 输出回退只换来 0.75 dB IM3 改善（而固定偏置下的驱动回退是 3 dB/dB）。想同时省电又保线性度，只能上 DPD。
3. **DPD 确实是本架构的关键件**，但 **2.4G 需要 23 dB 三阶对消是激进的**（宽带 DPD 实测常见 10–15 dB）。所以我的建议不是「无脑加 DPD」，而是 7.5 的三选一。

### 7.3 表 A：DPD 对消量敏感性（满功率）

| DPD 对消 | 2.4G PA 块 | 2.4G 全链 | 6G PA 块 | 6G 全链 |
|---|---|---|---|---|
| 0 dB | −25.4 dB | −25.4 dB | −36.5 dB | −36.1 dB |
| 10 dB | −35.4 | −35.1 | −45.5 | −42.9 |
| 12 dB | −37.4 | −37.0 | −48.5 ✓ | −44.3 ✓ |
| 15 dB | −40.4 | −39.5 | −51.5 | −45.3 ✓ |
| 20 dB | −45.4 ✓ | −43.1 ✓ | −55.4 | −46.3 |
| **23 dB** | **−48.4 ✓** | **−44.6 ✓** | — | — |
| **24 dB（设计值）** | −49.4 | **−44.9** | — | — |
| 32 dB | −57.4 | −46.5 | −68.5 | −46.4 |

（✓ = 过 **EVM 口径**（≤ −43 dB）；过「总体口径」所需的最小对消量见 7.2：2.4G 23 dB、6G 12 dB。功耗不随 DPD 对消量变化，恒为 731 / 881 mW。）

要点：**2.4G 的 PA 块裕量来自 DPD**——没有 DPD 时它离 −46 dB 分配差 **20.6 dB**；6G 差 9.5 dB。2.4G 是紧的那条。

### 7.4 表 B：两种「回退」机理必须分开建模

| 回退 | 机理 | 1 dB 回退换到的 IM3 改善 | 2.4G 达标所需 | 功耗 |
|---|---|---|---|---|
| **M1 驱动回退** | 降 VGA 驱动，PA 偏置不动 → 器件 OIP3 不变，只是离饱和更远 | **3 dB/dB** | 7.0 dB | 直流不变，**不省电**（效率下降） |
| **M2 偏置回退** | 降 PA 偏置省电 → OIP3 ∝ I^1.5 随之下降 | **0.75 dB/dB** | 12 dB 仍无解 | 731 → 394 mW（省 337 mW，但线性度只到 −34.4 dB） |

工程含义：**线性度只能靠「固定偏置下的驱动回退」或 DPD 拿，不能靠降偏置**。降偏置省的是钱，花的是 EVM。

### 7.5 表 C：加大 PA 的代价（三档指数做敏感性，不押单一假设）

| 频带 | 基线 PA | EVM 口径过线所需 ΔOIP3 | 电流倍数（exp=1.0 / 1.5 / 2.0） | 全链功耗（exp=1.5） | 上限 |
|---|---|---|---|---|---|
| 2.4G | OIP3 31.1 dBm / 450 mW | +8 dB | ×6.3 / ×3.4 / ×2.5 | **1818 mW** | 800 mW |
| 5-6G | OIP3 29.8 dBm / 600 mW | +4 dB | ×2.5 / ×1.9 / ×1.6 | **1390 mW** | 1000 mW |

三档指数结论一致：**加大 PA 这条路在任何合理标度下都超功耗上限**（且还没算配套驱动级要跟着加大）。

| 目标 | 2.4G 所需回退 | 对应 Pout | 与规格差 | 5-6G 所需回退 | 对应 Pout | 与规格差 |
|---|---|---|---|---|---|---|

### 7.7 给组长的三个可选方案（建议 ①）

| 方案 | 内容 | 换到的东西 | 风险 |
|---|---|---|---|
| **① 纳入 DPD（建议）** | 架构加一行 DPD 引擎，60 mW（两带共用，同一时刻只有一个频带在发） | 2.4G +23 dBm @ −44.9 dB、6G +18 dBm @ −44.7 dB，双带全功率达标且各留 ≥3 dB 块裕量 | 2.4G 需 23 dB 三阶对消，实现难度高；须做 AM/PM 相位线性化，否则 SEM 无保障（见 6.1 第 1 行） |
| ② 不纳入 DPD，放宽 2.4G | 2.4G 输出降到 +18.6 dBm（−4.4 dB）+ 目标放回 −38 dB | 省 60 mW 与 DPD 的校准/验证开销 | 链路余量：2.4G 室内可接受，但 6G 传播环境差，同样降 0.8 dB 影响不可忽略；且 PA 块仍违 −46 分配，需重议 |

### 7.8 本节的局限（必须一起读）

- 数字仍基于三次方 IM3 模型（无 OFDM 带内稀释、无 AM/PM、无记忆效应），是**分配检查级**不是签核级；2.4G 的 23 dB 需求尤其要以 PA 实测 + 320 MHz/40 MHz OFDM 仿真复核。
- 「驱动回退」按 VGA 增益下调建模，未建模功控环的实际响应时间（MAC 降功率到 EVM 稳定有数 ms 级延迟，对突发包 EVM 有影响）。
- M2 的 OIP3 ∝ I^1.5、表 C 的三档指数都是工程近似，已在脚本里显式参数化，可改可复跑。
