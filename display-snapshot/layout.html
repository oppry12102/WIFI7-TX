1. 直接变频 TX 的版图敏感点（为什么版图是本模组的成败项之一）

  1. 衬底耦合 PA→VCO：功率级 ~333 mW 开关噪声经衬底串入 VCO，直接抬 IPN（预算 ≤−48 dBc， spec §8）→ 相噪劣化 → EVM 恶化。对策见 §3 隔离 + 图 2。
  2. LO 泄漏/串扰：LO 分配走线与 RF/基带长并行 → LOFT 与正交误差（0.3°/0.05 dB 预算）。
  3. I/Q 失配：全链差分对称性决定幅度/相位不平衡，校准只能修慢漂，版图决定底账。
  4. 电源串扰：PA（3.3V）与敏感模拟（1.8V）电源域必须隔离，LDO 独立（图 2）。
  5. 大电流回流：功率级差分电流环路面积 → 寄生电感 → 谐波/EMI；变压器与去耦回路要最短。

2. 顶层 floorplan（图 1）

die ≈ 2.1 × 1.35 mm（估，±30%，待 PDK 核），pad ring + 岛式布局：

  • 数字接口与校准逻辑（1.1V）：居左，紧贴数字接口焊盘（SPI/DATA/CLK/EN）。
  • 模拟基带 I/Q（1.8V，DAC→LPF→VGA）：紧邻数字区，镜像对称摆置； 处于 LO 岛与 PA 岛之间的"干净走廊"。
  • gm + 25% 占空混频器：基带与驱动级之间，LO 缓冲末级贴其栅端。
  • LO 岛（PLL+VCO，上中）：深 N 阱岛中岛 + 双 guard ring + 独立 LDO； 与 PA 岛对角摆置，硅上直线距离 ≥200 µm 量级（图 2 剖面呼应）。
  • 驱动级 ×2 / 功率级 ×2 / 片上变压器 ×2（右缘）：PA 岛双 guard ring + 深沟槽 + 3.3V 专用电源环；变压器紧贴 RF 焊盘（低容 ESD），反馈耦合器贴 PA 输出。
  • LDO/带隙 + 密集 decap：沿下缘排布，各域独立 LDO 就近供电。
  • 电源网格：各域独立顶环 + 正交条带；3.3V 环随 PA 岛走大电流最短回路。

3. 电源域与隔离（图 2）

  • 三域划分（口径以 design_circuit v1.4 为准）： 1.1V（数字接口/校准逻辑/PLL 数字部分/SAR ADC）、 1.8V（DAC/LPF/VGA/gm+混频/驱动级/LO 缓冲）、 3.3V（功率级 ×2 + 变压器 CT）。
  • 岛式隔离：LO 岛与 PA 岛各自独立深 N 阱 + P+/N+ 双 guard ring；岛间深沟槽（DTI）。
  • 衬底：高阻 P 衬底 + 背注/GND 缝合，噪声回流路径最短化；敏感模拟置于两噪声岛之间。
  • 带隙全片共享，各域独立 LDO 收敛；敏感域 LDO 级联 PSRR 增强。
  • 跨域信号全部过缓冲/电平移位；域间避免长并行走线。

4. LO 分配（图 3）

  • 星形等长缓冲树（1→2→4），四相（0/90/180/270）走线对称等长。
  • 走线包地（地-信号-地）贴地平面；避开 PA 电感/变压器投影区；走线层选择在 floorplan 冻结时定。
  • 每级缓冲独立 LDO 抽头 + 就地 decap；25% 占空整形器贴近混频器栅（缩短高速节点）。
  • 2.4G 档 ÷2 天生正交可旁路多相级——版图预留旁路走线（architecture §4）。

5. 匹配与对称原则

  • I/Q 全链镜像对称（DAC 阵列 decode、LPF 元件、VGA、混频器开关四管、走线），关键差分对共质心。
  • 电感/变压器禁区：螺旋电感与变压器投影区下方及邻近禁布其他金属走线； 敏感信号不得穿越；RF 电感加图形屏蔽（patterned ground shield，视 PDK）。
  • DAC 电流舵阵列：温度计段单位电流源共质心 + 虚拟列，抑制梯度误差。
  • 天生对称结构（差分 PA、开关四管）优先，靠结构而非靠校准。

6. 电源网格 / 电迁移 / decap

  • 3.3V PA 岛：电源环与条带按峰值电流（~200 mA 量级/路差分）与电迁移规则（PDK）加宽金属、 多层并联；差分大电流环路面积最小化（变压器 CT 供电就近去耦）。
  • 全片 decap 密度目标 ≥2 nF/mm²（MOS cap + MOM，PDK 允许内），敏感域就地加稠。
  • IR drop 预算：各域 LDO 输出到最远点 ≤2%（PDK 到位后复核）。

7. ESD 与焊盘

  • RF 输出焊盘（RF1 5/6G / RF2 2.4G）：低容 ESD 方案（电容预算影响 S12 回损/匹配， 不得用常规二极管直拖；具体结构按 PDK 器件库选型），插损与回损列入后仿核对项。
  • 数字/控制/电源焊盘：常规全保护（HBM 2 kV 目标，PDK IO 库）。
  • 焊盘环：GND 填充 + 电源焊盘冗余（3.3V 至少双 bond）。

9. 物理验证与后仿签核清单（PDK 到位后执行）

  1. DRC / LVS / 天线规则（ANT）/ ERC 常规签核。
  2. EM-IR：3.3V 电源网络（大电流）+ 全片 IR drop 扫描。
  3. 寄生提取（PEX）：数字/模拟走线 RC；RF 无源件（电感/变压器/调谐开关）用电磁场 仿真器单独提取（版图级建模），回填网表。
  4. 后仿真重查（对照 sim_report v1.5 判定口径，零变更前提）： EVM / ACLR / SEM / 单音压缩 —— 前仿→后仿退化预留 EVM ≤3 dB、输出功率 ≤0.5 dB； 超限则回改版图（重点是输出匹配与 LO 走线）。
  5. PVT 角点 + 蒙特卡洛（失配）后仿，覆盖 spec §11 RSS 判据。
