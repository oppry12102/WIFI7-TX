## 一、闸体设计（`tools/stage154_batch_rerun_gate.py`，30990 B）

**立身之问**（任何时刻可问，机器给答案）：
> 当前仪器字节与舰队清单，是否**已被一次批次级复跑**覆盖？若否 ⇒ 该批不是现役仪器产物 ⇒ 其逐项判据不可作基线。

| 判据 | 含义 | FAIL 条件 |
|---|---|---|
| G1 | 批次件完整 | 波次 JSON／rc／仪器戳／起止／现役签名单 有缺 |
| **G2** | ★**仪器字节现役** | 批次记录的 probe/oracle sha ≠ 当下现算 sha |
| **G3** | ★**舰队清单现役** | 批次记录的 registry sha ≠ 当下现算 sha ⇒ 覆盖陈旧 |
| G4 | 最近批次各波 rc==0 | 任一波 rc≠0 |
| **G5** | ★**无 rc 回退** | 对上一批逐波出现 0→1，或上一批有波而本批缺该波 |
| **G6** | ★**无覆盖缩水** | 上一批任一 (skill,param) 在本批查不到 |
| **G7** | ★**无未声明回退** | 逐项**证据强度下降**（EFFECT＞ECHO_ONLY＞OUT_NOT_LANDED＞不可判档）且未列入 `declared_changes.json` |
| **G8** | ★**现役四件零字节变化** | 批内 before≠after，或当下现算≠批后记录 |
| **G9** | ★**扫掠覆盖诚实** | 每波 `residual_total ≠ decided+undecidable+not_run`，或探针自报 `n_fail≠0` |
| **G10** | ★**端态终局洁净** | 每波残留未清空／孤儿进程未归零／contradictory_pids 非空 |

设计要点：
1. **判据与 IO 分层**（纯逻辑层 `run_checks(cur, prev, cur_inst, current_live)` ＋ IO 加载层）⇒ 自检可直接构造合成批次，**复用同一判据函数** ⇒ 闸有齿（非恒真检查）。
2. **★只认已完成批次**：发现阶段要求 `wave_rc.txt + probe_sha.txt + **batch_end.txt**` 三件齐 ⇒ **跑批进行中的目录不参与判定**（否则会读到写了一半的 sweep JSON ⇒ 假 FAIL）——★批次原子可见律。
3. **反退方向量化**：不只比「类」（已判/不可判），比**证据强度序** ⇒ 「同档但更弱」的翻转也计入回退。
4. **合法变化有出口**：批次目录内 `declared_changes.json` 可声明允许变化的 (skill,param) ⇒ 闸不把合法变化也判死（反向对照 NC-G）。
5. 结论行格式统一：`结论行: 总项数 N ／ FAIL n`；退出码 0/1。
