## 三、方法（s28 相干直读配方移植，全链不变式）

1. **激励与窗**：与 v015.1 前仿 deck 逐字一致（IF 10 MHz 单音 15.8 mV/边差分、LO 5.5 GHz、tran 时长取**基波与 IF 的公约数周期整倍数**，dt 打印步长与前仿一致）。
2. **相干 bin 直读**：rfft 后取激励频率对应 bin 幅值（不做窗函数、不做插值）；三节点（mixlv / drv1out / chainout）各取差分和 v(x+,t)−v(x−,t)。dBV→dBm 换算 dBm=dBV+10（50 Ω 峰值口径）沿 s28 存档。
3. **级增益分解**：mix=−(mixlv−in)、drv1=(drv1out−mixlv)、drv2=(chainout−drv1out)、链=chainout−in——各减法在**线性幅值域**做比值再取 dB（不做 dB 域减法，s28 已证一致性但按宪法写死）。
4. **基线重测**：PEX 件到货**前**，用最终 M5 版 ngspice + 原网表把上表基准全部实跑固化成 `sow6m5_baseline_typ.json`（27 角可选；判读主判 typ 角，PVT 角沿任务书不强制）。此后任何工具/参数变动都触发基线重锁。
5. **PEX 网表代入**：仅替换器件网表段（子电路实例化层级不变），deck 激励/分析/打印段逐字不动；替换后先跑 `.op` 对拍（A0′ 域相对差 ≤1e-5 判「PEX 未扰动直流」，超标先查 PEX 提取设置再谈后仿）。
6. **数据完整性**：到货 GDS/PEX/deck 一律 sha256 落账；判读脚本与原始输出 JSON/CSV 全留档 `workspace/sow6/m5/`，文件名 `sow6m5_*`。
