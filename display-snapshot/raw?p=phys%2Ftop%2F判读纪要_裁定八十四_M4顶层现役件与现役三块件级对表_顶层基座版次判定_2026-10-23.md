## 一、问题的真实形状：P4 的「真实合并件」其实在盘上

盘内已有 M4 顶层 v3 真合并件：`design/sow6/gds/m4_top_v3.out.gds`。**本轮现算** sha8 `88d5d9c4` / 237672B，与历史记载逐位一致；8510 发布面副本 `outbox_files/design/sow6/m4_top_v3.out.gds` sha8 同值（双读对拍）。

## 二、主体结论（六条，全部机器实测）

### 1. 顶层基座内嵌版次＝mix v29 / drv1 v20 / drv2 v20 —— 相对现役全面陈旧
顶层 cell `M4_TOP_V3`（顶层判定＝**被引用为 0**；gdstk `top_level()` 会把 `$$$CONTEXT_INFO$$$` 上下文 cell 误当顶层，已弃用）直接引用 3 个子块顶层：
`TX5G_M2_MIX_V29` / `TX5G_M3_DRV1_V20` / `TX5G_M3_DRV2_V20`。
**内容指纹多重集**（阶段 88 同源判据，改名不敏感／摆位不敏感／换版敏感）对表：

| 块 | 顶层内嵌 | 现役锚 | 共有指纹 | 仅顶层有 | 仅现役有 | 判定 |
|---|---|---|---|---|---|---|
| mix | TX5G_M2_MIX_V29（v29） | TX5G_M2_MIX_V35 | 18 | 2 | 2 | **DIFFERENT_VERSION** |
| drv1 | TX5G_M3_DRV1_V20（v20_r2） | TX5G_M3_DRV1_V23 | 13 | 1 | 2 | **DIFFERENT_VERSION** |
| drv2 | TX5G_M3_DRV2_V20（v20_r2） | TX5G_M3_DRV2_V22 | 18 | 1 | 1 | **DIFFERENT_VERSION** |

⇒ 三块全部陈旧（mix 落后 6 代、drv1 落后 3 代、drv2 落后 2 代）。**顶层件的 418 DRC 与任何现役结论无关**。

### 2. 逐层差：基座缺的东西是具体的
逐 (layer,datatype) bbox 对表（层名由 PDK `tech/sg13g2.lyp` 的 `<source>L/D</source>↔<name>` 现解析）：

- **mix：6 层不同。** 关键两项 —— `Metal4.drawing`(50/0) 上缘 117.99 → **211.00（+93.01µm）**；`TopMetal2.drawing`(134/0) 下缘 −39.20 → **−55.85（−16.65µm）**。⇒ 基座 mix **缺现役的 M4 立管与更长的 TOPM2 引出**（与裁定七十六 mix v35＝v34＋M4.b 根修同向）。另 4 层为 −0.025～−0.05µm 微差。
- **drv1：现役多一层 `Substrate.drawing`(40/0)**，bbox [0,0,0.78,0.78]µm；基座 v20 无此图形 ⇒ 与裁定二十七「drv1 pwell 接地 tap 回改」那件对得上（子树叶单元数 14→15）。
- **drv2：逐层 bbox 0 差**，但内容指纹仍差 1 ⇒ v20→v22 的改动**不在包围盒上**（内部结构/阵列级），只查 bbox 会漏判。

### 3. ★改名口径：顶层走的是「读入消歧」，**不是** P1 作用域化改名
- 顶层 cell 名单中含 P1 作用域后缀（`__MIX`/`__DRV1`/`__DRV2`）者＝**0**；等于 P1 改名表新名者＝**0** ⇒ **顶层装配未施 P1 改名表**。
- gen 脚本自述「子块引用名不重命名」（实测与该自述一致）。
- 顶层内存在 **6 组**同名消歧命名（`via_stack$1$1`／`npn13G2$1$2` 一类，klayout 读入时加 `$n` 后缀避碰）。
⇒ 阶段 88 预警的「同名跨块被静默改形」在**顶层装配路径上是真实敞口**，不是假想风险；P1 改名表在顶层路径上**尚无对应用处**。

### 4. 摆位三方对表：顶层实测＝gen 声明（Δ=0）；与 P2 候选摆位差 drv1 +9.65µm / drv2 +19.65µm
| 块 | 顶层实测 | gen 声明 | P2 候选（gap=30） | 实测−gen | 实测−P2 |
|---|---|---|---|---|---|
| mix | (79.20, 7.31) | (79.200, 7.310) | (79.20, 7.31) | 0 / 0 | 0 / 0 |
| drv1 | (247.20, 2.31) | (247.200, 2.310) | (237.55, 2.31) | 0 / 0 | **+9.65** / 0 |
| drv2 | (693.84, 11.00) | (693.840, 11.000) | (674.19, 11.00) | 0 / 0 | **+19.65** / 0 |

⇒ **M4 通道 40µm 口径与 P2 gap=30µm 口径不可混用**（footprint 801.84×281.34 vs 782.19×281.34）。这是管理员第③问的技术输入：改摆位基准＝顶层全部走线几何重算，不是坐标平移。

### 5. bbox：现役 mix/drv2 可直接落进核定摆位；**drv1 下缘差 −1.02µm 是声明口径差，不是版本差**
现役块局部 bbox ＋ M4 核定摆位 ⇒ 顶层系 bbox，与 gen 声明 `RULE_BBOX` 对表：
- mix：(0,0,145.55,281.34) vs 声明 (0,0,145.55,281.34) ⇒ **Δ 全 0**；
- drv2：(612.84,0,801.84,261.00) vs 同 ⇒ **Δ 全 0**；
- drv1：(185.20,**−1.02**,572.84,221.25) vs 声明 (185.20,**0.00**,572.84,221.25) ⇒ **Δy = −1.02µm**。
且 v20（基座）与 v23（现役）实测局部 bbox **逐位相同**（[−62,−3.33,325.64,218.94]）⇒ **该差是 gen 声明/读回口径差，非版本漂移**。
⇒ 后果：gen 的 A1 bbox 断言（容差 ±0.005）**在重装现役 drv1 时会被直接挡住**；要么先修声明值，要么改读回口径（裁定 21.6「全层读回」血训的延续）。

### 6. 历史顶层 DRC 口径复核：lyrdb **418 条目**，与记载逐位一致
`phys/sow6_run/run_v2/drc_m4top_v3_r1/m4_top_v3.out_M4_TOP_V3_full.lyrdb` 解析出 418 个 item（记载 418 ✔），违反规则 17 类。**该 418 对应 v29/v20/v20 基座**，本轮**未新跑 DRC**，不得当现役三块的回归结论。

## 三、对 P4 的结论：从「待真实合并件」变成「四件待决」

P4 回归段的输入条件拆成四件，当前状态：
1. **现役三块**（mix v35 / drv1 v23 / drv2 v22）——**具备**；
2. **P1 改名表在顶层装配中施用** —— **缺**（顶层现走读入消歧）；
3. **摆位基准单一**（M4 通道 40 vs P2 gap 30 差 9.65/19.65µm）—— **缺**；
4. **顶层走线净距按现役 bbox 重算**（drv1 下缘 −1.02µm 口径差 + 基座 mix 缺 M4 立管）—— **缺**。

⇒ P4 不再是一张白纸。管理员第②问「是否允许以 P1＋P2 生成候选合并件做 P4 回归段」现在有了具体口径：**必须同时答 ②③④**，否则候选合并件一出生就带着已知敞口（同名改形 ＋ 走线净距失配）。建议把候选合并件的口径定为：**P1 改名表 ＋ M4 核定摆位（通道 40）＋ 走线按现役 bbox 重算**。

## 六、新律三条

- ★**顶层基座版次须以顶层件 cell 名单实测判定、不得以生成脚本声明为准律**：脚本 `SUBS` 声明与实测一致只是巧合性佐证，判据须落在顶层件自身的 cell 名单＋内容指纹上。
- ★**顶层装配改名口径须与 P1 改名表对表、读入消歧不等于作用域化改名律**：`$n` 后缀消歧是工具行为，不是设计口径；未施 P1 改名表的顶层＝同名改形敞口。
- ★**顶层核定 bbox 声明值须以全层读回实测复核、声明与实测差超容差即阻断重装律**：版本无关的口径差（此处 −1.02µm）同样会挡住重装，且会被误读成版本漂移。

## 七、自纠一条（据实）

顶层判定初版用 gdstk `Library.top_level()`，实测把 `$$$CONTEXT_INFO$$$`（klayout 写出的上下文 cell，引用了 52 个单元）当成顶层，导致子块引用数为 0、全部对表落空；现役块顶层名亦受同一 API 污染（误取上下文 cell 的子树）。修正＝①顶层判定改「**被任何 cell 引用者为 0**」②现役块顶层名改用阶段 88 基线 json 的权威 `top_cell`。修正后子块引用 3、指纹对表成立。
