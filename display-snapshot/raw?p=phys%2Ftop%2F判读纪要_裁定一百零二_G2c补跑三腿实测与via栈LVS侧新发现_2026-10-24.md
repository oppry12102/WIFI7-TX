## 一、结论摘要（三行）

1. **腿①（密度规则补跑，可跑）**：via 栈（V-M3/V-M5）对金属密度违规**零影响**——规则类集合与条数不变（9 条：AFil.g/GFil.g/M1.j–M5.j/TM1.c/TM2.c），M2.j 比值 2.076 % → 2.077 %（**Δ=0.001 pp，低于报告分辨率**），M2 层面积 4683.752 → 4685.752 µm²（**Δ=恰好 2.000 µm²**＝2 个 1.0 µm 落焊盘）。
2. **腿③（可跑的那一半）**：LVS **布局侧**提取（deep/flat × BASE/V-M3/V-M5，全 rc=0）显示——既有 11 条「端口→网络绑定」**逐条不变**，新增的 2 根网**互不相同**、**不与既有网合并**；短接指标（gnd 合网 1、地–RF 跨块短接 3）与 BASE 相同；flat 侧网络组数/合并组数/器件数不变。
3. **★新发现（DRC 看不见、只有 LVS 侧看得见）**：**via 栈把 drv2 的 outp/outn 导出为顶层网络（顶层网数 4 → 6）**，两根新网**无 label（自动名 `\$3`/`\$4`）** ⇒ ①证明 via 栈与 drv2 输出 M1 焊盘**电气连通**（否则不会成为 drv2 的 pin）；②但顶层侧仍**没有片级引脚**（top_pins 仍 4 条块间内部网）⇒ 顶层 LVS 腿仍被**待决 ㉒（顶层网表与 pin 层）/㉖（片级接入层宽口径）**挡住。

## 二、腿①：密度规则补跑（`--density_only`，可跑）

### 2.1 做法
在**同一个候选装配件**（现役 mix v35 / drv1 v23 / drv2 v22 装进顶层基座 + 作用域化改名，承继裁定八十八口径）上造 4 个变体并各跑一次密度补跑：

| 变体 | 几何 | 跑批 | 结果 |
|---|---|---|---|
| BASE | 无 via 栈 | `--density_only` | 9 条（2.6 s） |
| V-M3 | via 栈到 M3（M2 落焊盘 + Via1 + Via2 + M3 落焊盘） | 同上 | 9 条（2.3 s） |
| V-M5 | via 栈到 M5（再加 M4/M5 落焊盘与 Via3/Via4） | 同上 | 9 条（2.4 s） |
| **NC-C**（负控） | BASE ＋ 人为 120×120 µm 的 M2 大块 | 同上 | 9 条（2.3 s） |

落点、pad 边长、cut 边长全部**现取自 g2c（阶段 106/107 同款）**，不采信记载；并复核落点在**候选件（drv2 v22）**里仍被本引脚 M1 金属覆盖（K03 PASS，覆盖数 > 0）。

### 2.2 实测数据（机检 K05–K08）
* **规则类与条数不变**：BASE/V-M3/V-M5/NC-C 四件同为 9 条、规则类集合逐字相同；V-M3/V-M5 相对 BASE **新增 0、消失 0**（K05）。
* **数值级影响**：V-M3 相对 BASE —— `M2.j` Δratio **+0.001 pp**、Δarea **+2.000 µm²**；`M3.j` Δratio +0.001 pp、Δarea +2.000 µm²；其余层 0（K06）。
* **解析交叉复核（互校）**：现算 via 栈新增 M2 面积 = 2 pin × 1.0² = **2.00 µm²**；芯片面积 225 589.666 µm² ⇒ Δratio 计算值 **0.000887 pp**，DRC 报告值 **0.001 pp**，**差 ≤ 0.01 pp**（K07）。另：芯片框现算 801.84×281.34 = **225 589.666 µm²**，与密度报告的 chip_area **逐位相同（差 0.0）** ⇒ 坐标系/单位口径互证。
* **负控 NC-C（闸有牙）**：人为 M2 大块 ⇒ `M2.j` Δratio **+5.138 pp**、Δarea **+13 999.916 µm²**（K08）⇒ 密度量测对金属面积**灵敏**，前一条「Δ=0.001 pp」不是盲闸读数。

### 2.3 结论
**via 栈对密度状态零影响**：via 栈只增加 2 µm²/层（相对 225 590 µm² 芯片面积约 0.0009 %），低于密度报告的 0.001 pp 分辨率，**不会把任何密度违规从「违规」推向「合规」或反之**（现状 9 条密度违规全部为 **global min-density**，limit 35 %（min），实测比值 2–5 % ⇒ 全部**远低于**下限，属既有基线状态，与 via 栈无关）。

## 三、腿②：走线本体 DRC（**不可跑**，缺口已量化）

### 3.1 为什么不可跑（本口 live 实测，非引用）
* 顶层 **pin marker（datatype 2）计数 = 0** ⇒ **未建 pin 层**。
* 顶层**自有走线**足迹（仅 M2/M4 两层路由盒）：`(165.000, 7.310) – (656.340, 174.310) µm`；芯片框 `(0,0) – (801.840, 281.340) µm` ⇒ **四边间隙 left 165.0 / bottom 7.31 / right 145.5 / top 107.03 µm** ⇒ **没有任何一条顶层走线走到片边** ⇒ 「落点→片边」的片级接入走线**几何不存在**，无可跑对象。
* via 栈两个落点 `(664.84, 217.005)` / `(722.84, 217.005)` **落在顶层走线足迹之外**（实测 outp/outn 均 false）⇒ 栈与现有顶层路由之间**还差一段接入走线**。

### 3.2 依赖与待决
腿②要跑起来需先有：①顶层片级引脚与命名（**待决 ㉒** 顶层网表与 pin 层同批授权；命名口径见阶段 99 GAP「顶层 pin 命名口径与 marker 所在层」）②片级接入走线的层/宽口径（**待决 ㉖**，名义 2.0 µm）③via 栈实施授权与跑批次序（**待决 ㉙**）④顶层 v4 与 DRC 基线重签（**待决 ㉑**）。⇒ **在 ㉒/㉖/㉙ 未回前，腿②只能停在缺口量化，不得产出「腿②已过」的结论。**

## 四、腿③：LVS 腿（拆两半：布局侧可跑 / schematic 侧不可跑）

### 4.1 布局侧（可跑，本口真跑）
在 BASE / V-M3 / V-M5 三个候选装配件上真跑 IHP-SG13G2 `LVS --net_only`（deep + flat，共 5 次提取，全 rc=0、5.0–6.2 s/次），用阶段 103 同款解析器（`p4.parse_deep/parse_flat` + 我方自建连接表/短接指标）逐条对拍：

| 项 | BASE | V-M3 | V-M5 |
|---|---|---|---|
| 顶层网络数 | 4 | **6** | **6** |
| 端口→网络绑定（11 条既有） | — | **逐条不变** | **逐条不变** |
| 新增绑定 | — | `drv2.outp→\$3`、`drv2.outn→\$4` | 同 |
| 新增网是否互不相同 / 是否与既有网合并 | — | **是 / 否** | 是 / 否 |
| gnd 合网 / 地–RF 跨块短接 | 1 / 3 | 1 / 3 | 1 / 3 |
| flat：网络组数 / 合并组数 / 器件数 | 54 / 4 / 73 | 54 / 4 / 73 | 54 / 4 / 73 |
| top_pins（顶层片级引脚） | 4（块间内部网） | **4（不变）** | 4（不变） |

### 4.2 ★定量新发现（DRC 侧不可见）
1. **via 栈与 drv2 输出焊盘电气连通**：BASE 时 drv2 的 `outp/outn` **根本不在提取出的子电路 pin 表里**（因为它们的 M1 焊盘在块内、未跨界）；加了 via 栈后，M2 落焊盘压在 drv2 的 M1 焊盘上并经 Via1 cut 跨层连接 ⇒ 提取器把这两根网**导出为 drv2 的 pin**（`outp`/`outn`），顶层网数 **4 → 6**。⇒ **「㉕ 顶层自建 via 栈」路线在电路层面确实把两个输出口变成了顶层可接入的网**（此前只有几何与 DRC 两层证据，本口补上第三层：网表层）。
2. **但这两根网无 label（自动名 `\$3`/`\$4`）**：顶层 `top_pins` 仍是 4 条块间内部网 ⇒ **顶层片级引脚数仍为 0**（与阶段 100/103 一致）⇒ **LVS 腿的 schematic 侧仍缺顶层网表与 pin 层**（**待决 ㉒**），且**顶层 LVS 侧还需给这两根新网定名**（命名口径随 ㉒/㉖）。
3. **无短接、无并网**：新增两根网彼此不同、与既有 11 根网不同名，gnd 合网与地–RF 跨块短接指标与 BASE 相同 ⇒ via 栈新件金属**没有把任何两根网并成一根**（这是 DRC 查不出的那一类风险，本口补上了网表层证据）。

### 4.3 负控 NC-D（闸有牙）
人为在 via 栈 M2 落焊盘上注入**别根网的同名 label**（`nmixn`）⇒ 再跑 deep 提取 ⇒ `drv2.outp` 的网络名落进既有地网 `nmixn`（既有 gnd 网络被重命名为 `nmixn$1`）⇒ 差分闸**报出并网**（K14 PASS）⇒ 4.2 的「无并网」结论不是闸失灵。

### 4.4 schematic 侧（不可跑，缺口已量化）
顶层网表未建、pin 层未建 ⇒ 不可跑。缺口清单共 **12 条**（阶段 103 的 GAP1–GAP6 ＋ 阶段 99 的 6 条；**引自归档证据，本口未重跑该两腿**，来源已在证据 json 中标注）。⇒ **待决 ㉒ 未回前，LVS 腿只能停在「布局侧已闭合、schematic 侧仍缺」这一句。**

## 七、本立两律（入律库）

1. **★★跨规则族的补跑分层律**：一条 DRC 侧结论不能替代网表侧结论——**几何层（可行/不可行）、规则层（DRC 违例）、网表层（连通/短接/接口）是三层独立证据**；本例中「via 栈 DRC 干净」并不蕴含「via 栈网表无副作用」，反之亦然。**每层各配一个负控**。
2. **★接口变更量化律**：候选新件若**改变了子电路接口**（本例：drv2 由 3 个提取 pin 变为 5 个），必须**显式量化并报告**（新增/消失/改名各多少），否则「无短接」会被误读为「无变化」。⇒ 本例新增 2 根自动名网（`\$3`/`\$4`）已量化并入 ㉒ 的命名范围。
