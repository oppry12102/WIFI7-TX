M4 顶层 · 设计输入预案 v0.2（未立项，攒输入不抢跑）

作者：b7e7 · 2026-10-17 · 状态：等任务书；本文只攒已裁定的设计输入。 v0.2 变更：§2 幻影焊规避按 deck dump 4 数真值精确化（定律 v2，组长裁决信 inbox 第 74 行）；§3 状态更新（v18 五关全绿、tap 密度/psd 条款终裁全绿）。

  • 核内净空：freemap @3µm 净距 → 净自由 16772µm²，最大净空矩形见 dryrun/freemap.py 输出。
  • 外置电容条带坐标、上环 TM2→TM1 馈电预案（电容区规划 §裁定2）。

2. ★硬约束：幻影焊规避（定律 v2 精确化版）

deck 机制（dump 真值，非推断）：npn13G2 端子指派按金属连通域进行： E 通道=M1 域骑 emwind 窗即焊（每指 0.070×0.900µm 竖窗，y_cell −0.45..+0.45，无需 cont）； C/B 通道=M1 域骑 c_pin/b_pin 带 ∧ 域内有 cont 落点（孔带 y_cell 1.05..1.21 / −1.22..−1.06）才焊； M2~M5 无半导体通道，骑体永不直接焊；tb（body 全矩形 −2.43..+1.28）经 cont 参与 base。 识别区几何互不相交（tc/te 间隙 0.53µm），但大域可同时命中多通道（ccas1 大域 = C+E 双通道 = 簇甲）。 详见 knife_骑体对照表与指派定律_v2_2026-10-17.md（v1 判例驱动版已被真值修订）。

危险面（v2 精确）： ① 勿覆盖 emwind 窗列——各指中轴 ±0.35（窗本体 ±0.035，±0.35 为 E 指 M1 物理占位）、y_cell ±0.45； ② 勿覆盖 c_pin/b_pin 带上的 cont 落区——y_cell 1.05..1.21 / −1.22..−1.06； ③ 高层（M2~M5）骑体无害，但 via/cont 链下探终点是 M1——凡下探接 M1 的柱，落点按 ①② 查。

执行口径（deck 修复前）：仍按 v0.1 充分条件执行——外部金属一律不覆盖任何 npn13G2 PCell body bbox（M2 回流臂/立管/立线绕体走，拓扑不动）。deck 修复（粘连 covering-bbox 语义修正）后可按 v2 收紧至「只避 ①②」。两口径下 M4 设计期一律不利用灰色地带。

已定案判例（不再当灰色地带）：drv2 gnd M4 立线（x_cell 3.85~4.15 骑 E 带）不焊 = M4 无通道（定律 v2 反例已收编）；drv1 bb1 M5 横带骑 XQr body 预测必不焊（M5 无通道，留作 drv1 LVS 验证点）。

body bbox 快查（gen 里 mkpc_at 后）：body = 锚 + (−3.35,−3.33) ~ (3.35+1.85·(Nx−1), +3.78)； 镜像排 XQo(Nx=8) 右缘 = 锚_x+16.30、XQr(Nx=1) 右缘 = 锚_x+3.35；行 y：body 底 = 锚_y−3.33、 顶 = 锚_y+3.78。镜像排管 body（drv2 v17）：XBI1_XQo y 104.67~111.78 … XBI4_XQr x 67.15~73.85。
