WiFi7-TX 电路设计（SOW-1 交付）

项目：Wi-Fi 7（802.11be）射频发射 TX 模组 ASIC — 电路设计岗 交付：design_circuit.md（本文）、budget_check.py、params.csv 依据：spec.md v1.0 / architecture.md v1.0 摘录（组长 b7a0 任务书 SOW-1，2026-10-15） 复跑：cd design_circuit && python3 budget_check.py（详见 §7）

0. 结论摘要

项 结论
预算是否闭环 闭环，且有裕量。全链 EVM：6G −44.7 dB、2.4G −44.9 dB（目标 −41 dB，裕量 3.7/3.9 dB）；功耗 6G 881 mW（上限 1000）、2.4G 731 mW（上限 800）。7 个 EVM 分配块全部达标，每块裕量 ≥2.1 dB。
有无超差项 无超差项，但有 1 个硬依赖 + 6 项待裁决（§5）：本设计闭环依赖架构未列的 DPD（6G 需 13 dB、2.4G 需 24 dB 三阶 IM3 对消，已把 60 mW 计入预算）；§7 已把「不引入 DPD」的代价算清——加大 PA 要全链 1818 mW（上限 800）、偏置回退救不了 EVM、只剩降输出功率一条路（2.4G 降 7.0 dB / 6G 降 3.5 dB）。若 DPD 对消能力只有 15 dB，2.4G 全链 EVM 仅 −39.5 dB（不达标）。
风险头条 LO 近带相噪是 EVM 的第一限制项（6G 仅 2.1 dB 裕量）：参考源用常规 40 MHz TCXO 会使 LO_IPN 恶化 14 dB（−50.1 → −36.2 dB），直接击穿 −48 dB 分配。参考源规格必须写进 spec。

1. 口径与假设（复算的前提，全部显式声明）

1.1 EVM 口径（关键：与任务书一致）

  • EVM_dB ≡ 10·log10(P_err / P_sig)（功率比口径）。 用任务书给定分配表复算：DAC −50 / 重构滤波 −55 / VGA+混频 −48 / LO IPN −48 / IQ −52 / LOFT −52 / PA −46， RSS = −41.2 dB，与任务书标注的 −40.8 dB 一致（差异来自取整），故确认组长采用的是功率比口径，本文与脚本均沿用。 若误用幅度口径（20log10），同一张表 RSS 会变成 −32.8 dB —— 差 8 dB，这是对账时最容易出错的地方。

1.2 计算公式

项 公式 说明
三次方失真（单级） P_IM3 = k·(P_out/OIP3)³·P_out，k = 0.75 双音三次方，每级失真按其后各级增益折算到链输出后 RSS
OIP3 级联 1/IIP3_tot = Σ_i G_prefix,i² / OIP3_i；OIP3_tot = IIP3_tot + G_tot dB 域：10^((2·prefix − OIP3_i)/10) 求和
OP1dB 级联（简化） P1dB_tot = min_i ( P1dB_i + 其后各级增益之和 ) 任务书要求的"简化级联公式"；忽略压缩累加，偏乐观
相噪 → EVM σ² = 2∫₁ₖ^₁₀₀ᴹ L(f) df；EVM = σ²/2 L(f) 为单边带相噪 dBc/Hz；理想 1/N 分频保持 dBc/Hz 不变，只叠加分频器自身底噪

1.3 显式假设清单

# 假设 依据/影响
A1 工艺：40 nm CMOS 典型角（TT, 25 °C, 1.1/1.8/2.0 V） spec 给定工艺，未给 PDK；所有器件级数字为估算级
A2 内部基带参考电平：链入（DAC 满量程）= −5 dBm @50 Ω（0.5 Vpp） 定义基准；决定各前级工作点
A3 PA 在 P1dB 点的效率：6 GHz 25%、2.4 GHz 45% 由 P1dB = P_dc × η 推出 P1dB；6 GHz 效率取 40 nm 常见 P1dB 效率（峰值效率 30–35% 的 0.7 倍）
A4 OIP3 = P1dB + 8 dB 40 nm CMOS PA 典型值（宽带共源共栅）
A5 PA 输出回退：6G 3.8 dB、2.4G 0.1 dB（均在 P1dB 回退定义下） 由 A3+A4 与分配的直流推出，是本设计的紧约束
A6 DPD 三阶 IM3 对消：6G 13 dB、2.4G 24 dB；DPD 功耗 60 mW 架构未列 DPD；见 OQ-4。作为纯 IM3 对消建模，未含 AM/PM 相位线性化（偏乐观）
A7 参考源 100 MHz VCXO，L(100 kHz) = −158 dBc/Hz，20 dB/dec 见 §6 R6 敏感性表
A8 VCO：L(100 kHz) = −125 dBc/Hz，1/f³–1/f² 转折 500 kHz 40 nm LC VCO 常见区间
A9 4 阶重构滤波：fc = 420 MHz 定义为 −3 dB 点，Q = 0.707（Butterworth） architecture 的"fc≈420M, −2dB"口径不明，按 Butterworth 解释（160 MHz 处 −0.16 dB，1.12 GHz 处 −34 dB）
A10 VGA/MIX 在满功率档增益取 0 dB（最坏线性度工况） VGA 0–15 dB 用于低功率档
A11 电感 Q ≈ 15–20 @6 GHz（片上，含衬底/AC 损耗）；变压器 k ≈ 0.88 片上无源估算
A12 模型保守性：三次方模型未计入 OFDM 带内 IM3 稀释（偏保守 6–10 dB），也未计入 AM/AM、AM/PM、记忆效应与 DPD 收敛残差（偏乐观）。综合预计实测 EVM 落在 −41 ~ −45 dB 本模型最大的不确定性，须由仿真/实测闭环

2.7 LO / PLL（55 mW）

  • ΣΔ 分数 N PLL，环路 BW 800 kHz；VCO 4.8–7.2 GHz 双子带（核心电感 + 变容切换子带）；6 GHz 直通 / 2.4 GHz ÷2。
  • ÷2 保持 dBc/Hz 相噪不变，仅叠加分频器自身 1/f 底噪（假设 −140 dBc/Hz）。
  • 功耗拆分（估算）：VCO 25 mA@1.8 V = 45 mW + 分频/LO 驱动 ≈ 10 mW。
  • 正交 LO：I/Q 由 90° RC 网络（2 路极对称）；25% 占空误差 δ → IQ 不平衡 ≈ δ/2；要达校准后 −55 dB，需 δ ≤ 0.22%（两级整形 LO 缓冲可达 ±0.1%）。

2.8 辅助路与校准（40 mW）

项 值 说明
耦合器 −25 dB，变压器耦合（1:4 匝比） 输出端并联，强耦合需注意对 PA 输出的负载
RF 检波 平方律 MOS 检波 + 对数放大，动态范围 ≥70 dB（要看 −55 dBc 的校准残差）→ 两段式（粗平均 + 峰值保持） 4096-QAM PAPR ≈ 11 dB，纯平均检波会低估
ADC 10-bit、20 MS/s（320 MHz 包络采样），功控闭环 ±1.5 dB
校准 LOFT / IQ 失配 / PA 温漂；观测口复用同一耦合器 + 检波 建议 DPD 反馈用独立耦合器或时分复用，避免互相拖累

2.9 DPD（60 mW，架构未列，见 OQ-4）

  • 三阶 IM3 对消（记忆多项式长度 5），1.28 Gsps 等效多相累加，40 nm 数字逻辑 ≈50–70 mW。
  • 本设计只对消 IM3，未含 AM/PM 相位线性化（偏乐观，见 A12 / R1）。
  • 取舍的完整量化见 §7（dpd_study.py）：满功率下 2.4G 需 ≥23 dB、6G 需 ≥12 dB 三阶对消；不上的话只有「降输出功率」一条现实路线。

7. DPD 取舍量化研究（dpd_study.py，支撑 OQ-4 裁决）

7.1 为什么要单列

OQ-4 问的是「架构没列 DPD，要不要加进来」。这个问题不能靠感觉答：DPD 值 60 mW，不值那 1300 mW 吗？ 本节把这个问题算成四张表——DPD 拿掉会怎样、拿掉后有哪些替代路线、每条路线各付多少 dB / 多少 mW / 是否还守得住输出功率规格。

方法上不引入新的失真模型：全部数字来自 budget_check.py 的同一套公式与同一份 params.csv，只是换着问不同的问题。判定口径与 budget_check.py 完全一致：

  • EVM 口径：全链 EVM ≤ 设计目标 − 自设裕量（2.4G/6G 均 ≤ −43 dB）
  • 总体口径：EVM 口径 ∧ 每块 EVM 优于分配值 ≥ 2 dB ∧ 功耗 ≤ 上限 ∧ 输出功率 = 规格

7.2 结论速览（两带）

三条一句话结论

  1. 加大 PA 换线性度在两条带都不成立——三档电流标度指数（OIP3 ∝ I^1.0 / 1.5 / 2.0）算下来都要超功耗上限 1.4–2.3 倍。这条路可以排除。
  2. 省电式的偏置回退救不了 EVM——OIP3 随电流下降，每 1 dB 输出回退只换来 0.75 dB IM3 改善（而固定偏置下的驱动回退是 3 dB/dB）。想同时省电又保线性度，只能上 DPD。
  3. DPD 确实是本架构的关键件，但 2.4G 需要 23 dB 三阶对消是激进的（宽带 DPD 实测常见 10–15 dB）。所以我的建议不是「无脑加 DPD」，而是 7.5 的三选一。

7.8 本节的局限（必须一起读）

  • 数字仍基于三次方 IM3 模型（无 OFDM 带内稀释、无 AM/PM、无记忆效应），是分配检查级不是签核级；2.4G 的 23 dB 需求尤其要以 PA 实测 + 320 MHz/40 MHz OFDM 仿真复核。
  • 「驱动回退」按 VGA 增益下调建模，未建模功控环的实际响应时间（MAC 降功率到 EVM 稳定有数 ms 级延迟，对突发包 EVM 有影响）。
  • M2 的 OIP3 ∝ I^1.5、表 C 的三档指数都是工程近似，已在脚本里显式参数化，可改可复跑。
