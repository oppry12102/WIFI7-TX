二、deck 通道真值（bjt_connections.lvs L34-42 + dump 佐证）

  1. connect(e_pin, emwind_drw) + connect(emwind_drw, metal1_con) —— E 通道=emwind 窗直连 M1，无需 cont（dump 证实：cont∩e_pin=0 域）
  2. connect(e_pin/c_pin/b_pin, cont_drw) —— C/B 通道需 cont 孔落点： collector 孔带 y_cell +1.05..+1.21（骑 c_pin 带）、base 孔带 y_cell −1.22..−1.06（骑 b_pin 带）
  3. connect(te,tb,tc ↔ e,b,c_pin) 半导体侧同网；connect(npn_sub, pwell) 衬底侧
  4. M2~M5 无半导体通道 —— 纯高层骑体永不直接焊（gnd M4 立线反例真机制=层敏感非 x 敏感）

三、幻影焊桥元素实锤（knife 复现件）

ct_XQ1only（簇甲 ccas1⊕e1）

桥=ccas1 立管汇流 M1 大域 (−33.300,177.215)..(−14.700,190.770)（18.6×13.6µm，跨两行主管位）： - 骑 dy178 行 c_pin 带（y 178.98..179.28 在域内）+ 域上 collector cont 孔 20 只（y_cell 1.05..1.21）⇒ 入 collector（正常，ccas1=C 网） - 骑两行管 emwind 窗列（E 窗 y_cell ±0.45 在域 y 范围内，x 窗列 −32.7..−15.3 被域覆盖）⇒ E 直连通道 ⇒ 整域拽进 e1 —— 焊 - 骑 dy190 行 b_pin 全带 + base 孔（188.78..188.94 在域内）⇒ 入 base - 机制链：cascode 中点网（XQ1.C+XQ3.E）立管汇流横穿 body ⇒ 骑过 XQ1 自己的 E 窗 ⇒ ccas1⊕e1。

「骑带≠焊」精确定律（新增实证）

正常 E 指 M1（0.7×1.555，y_cell −0.785..0.770）底缘骑入 b_pin 带顶缘 0.165µm（−0.785<−0.62），却不焊 e1⊕bin —— 因 E 指域内无 base cont 落点（孔带 −1.22..−1.06 在其下方）。 ⇒ C/B 通道：骑带 ∧ cont 落点在域内 ⇒ 焊；E 通道：骑 emwind 窗即焊（无需 cont）。

判例全解（6 幸免+2 焊对+1 反例全部自洽）

  • ntail/bin/bb1/outp/outn 幸免：骑自身网对应端子带（正常连接）或骑带无 cont 落点
  • gnd M4 立线反例（x_cell 3.85..4.15 不焊）：M4 无半导体通道——x 位置无关
  • bb1 M5 横带（drv1 观察点）：M5 无通道 ⇒ 定律 v2 预测必不焊（drv1 代跑 LVS 验证点）
  • e1 M2 平台不焊 bin：M2 无通道 + e1 域 M1（E 指）骑 b_pin 带但无 cont 落点

四、定律 v2（修正 b7e7 v1）

  1. 金属连通域的 M1 元素（直接或经 via 链下探至 M1）： - 与 emwind 窗相交 ⇒ 整域拽进 emitter（域级，无矩形级切割）——v1 判例全部吻合 - 与 c_pin/b_pin 带相交且域上有 cont 落点 ⇒ 整域拽进 collector/base
  2. M2~M5 骑体本身永不焊（层敏感）——v1 的「x 半宽<3.85」边界作废，x 只决定 E 窗列（每指 ±0.035）与孔位
  3. npn13G2_b/tb（body 全矩形）确实参与 base 通道（v1 判 4 修正）——经 cont 起作用；body 上任何带 cont 的外部 M1 ⇒ 拽进 base
  4. C/E 永焊带不存在（tc-te 不相交）；「B 区顶<−0.01」真值 −0.62 更紧

五、M4 设计输入精确化（替换原「充分保守」条款）

  • 真值面：M2~M5 走线骑 body bbox 本身无害；危险面=M1 落点与 via 链下探终点： 勿覆盖 emwind 窗列（各指中轴 ±0.35、y_cell ±0.45）与 c_pin/b_pin 带上的 cont 落区（y_cell 1.05..1.21 / −1.22..−1.06 带）
  • deck 修复前仍建议按充分条件执行（全带避开）；deck 修复后可按 v2 真值收紧走线自由度
  • v18 新画外部金属（落地柱/地轨/搭桥）在管 bbox 外零骑体 ✓ 维持 b7e7 存量审计结论
