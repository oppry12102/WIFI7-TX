1. 范围与定位

本模块为 Wi-Fi 7 接入点/终端 SoC 的射频发射（TX）通路：数字前端输出基带 I/Q， 经 DAC、重构滤波、增益控制、上变频、驱动与功率放大，至天线端口。 不包含：接收通路、数字基带 MAC/PHY 上层、电源管理完整方案（仅给电源需求）。

三频段：2.4 GHz（2.400–2.4835）、5 GHz（4.9–5.945）、6 GHz（5.925–7.125）。

3. 工艺与电源（假设声明）

v1.3 勘误注记（2026-10-16，PDK 落地）：工艺假设已落地为 IHP SG13G2 130nm SiGe BiCMOS （开源，Apache 2.0）——本节「40nm CMOS 假设」保留为历史口径不再作为设计依据；电压域映射 与已实测器件锚点（HBT fT 434GHz 等）见 architecture.md §0（v1.1），本节「不锁死电压档」原则 不变，晶体管级实测后逐项回填。

  • 工艺：40 nm CMOS RF 工艺（TSMC 40LP/40NM 级别）——假设。理由：厚氧化器件可用 （1.8/2.5/3.3 V），无源（MIM 电容、多层金属 transformer）成熟，Wi-Fi SoC 主流平台。
  • 电源域假设：核心数字 0.9 V；模拟/RF 1.1 V；驱动级 1.8 V；功率级 2.0 V（厚氧高频管，v1.1 采纳 b7e7 OQ-3）； PDK 落地后校核，spec 不锁死电压档。
  • 封装假设：FCBGA 或 QFN，片上 transformer 做差分-单端与阻抗变换；输出匹配部分片外 （π 型网络 + 双工器/滤波器组在主板上）。天线口回损假设 ≥ 10 dB（系统侧提供）。

5. 频谱与杂散

  • SEM：按 802.11be 对应带宽掩模；本设计内部目标：掩模各折点 ≥3 dB 裕量。
  • ACLR（相邻信道，同带宽）：≥45 dBc（自设，S6）。
  • 杂散发射：谐波（2f0/3f0）≤ −40 dBm 天线口；本振馈通按 S10。
  • 320 MHz 档滚降：FAgger 内（±160 MHz 处）起步，−28 dBr 点由重构滤波+PA 带宽联合保证。

6. 数字前端 / DAC 接口（假设；v1.2 补资源结论 R-09）

  • DAC：12-bit、1280 Msps（4×插值后）、双源 I/Q、电流舵——假设。Fs = 4×320 MHz。
  • 数字前端：基带 I/Q（320 Msps 复数，16-bit）→ 成形/插值 ×4 → 可选 CFR（v1 不启用）→ DAC。
  • 谱成形 FIR 资源结论（v1.2，采纳 b7e7 R-09）：320M 档 911 tap 全速 1.28GS/s 6b 方案否决 （350 mW / 2.83 mm²，占整链 35% 不可行）；对称折叠 + 4b 量化 = 88 mW / 0.91 mm² 采纳 （等效 130 tap 参数留裕量）；2.4G 档多速率 160 MS/s = 11~22 mW。
  • 接口假设：并行 DDR @640 MHz（I/Q 各 12-bit）；或串行 8 lane ×640 Mbps（二选一，集成时定）。
  • 增益/补偿控制字：LO 泄漏补偿（DC I/Q）、IQ 增益/相位预失真系数接口。

8. 本振（LO）相位噪声要求

  • B 口径等价声明（v1.2，R-01）：全链预算中 LO 行 EVM = IPN_dBc + 3.0 dB； §7 分配 −45 dB ↔ 本节 IPN ≤ −48 dBc，两者同义（v1.0 的「直接当」含混已纠正，责任记组长）。
  • 参考源规格（v1.1 采纳 b7e7 OQ-5）：f_ref ≥ 100 MHz 且 L(100 kHz) ≤ −158 dBc/Hz （如 125 MHz @ −160 dBc/Hz 达标）；常规 40 MHz TCXO（−150 dBc/Hz@100k）使 LO_IPN 恶化 13.9 dB 直接击穿分配，禁用——LO 近带相噪是全链 EVM 第一限制项。
  • 6 GHz 频段：IPN（1 kHz–100 MHz）≤ −48 dBc；带内（<PLL 带宽）≤ −95 dBc/Hz， VCO @1 MHz 偏移 ≤ −129 dBc/Hz（假设、由 PLL 任务书细化）。
  • 2.4 GHz 换算放宽 8 dB；5 GHz 放宽 1.6 dB（20log 比例）。
  • PLL 环路带宽假设 800 kHz（整数/N 分数混合，N 分数 Σ-Δ 三阶）。
  • （待收：b7e7 B 口径参考源敏感性终结论——维持或加严本节；fde9 LO 行标定值交叉验证。）

9. 校准与检测（辅助路）要求

  • 校准项：LO 馈通（DC offset）、IQ 增益/相位不平衡、PA 温度漂移功率闭环、DPD 系数自适应 （须跟踪温漂与老化，收敛性由仿真岗行为级验证）。
  • 功控出厂校准（v1.1 采纳 fde9）：不校准闭环精度 ≈ 检测精度（±1.5 dB 直通，MC max 1.92 dB 不达标）； 出厂两点温补校准后口径 1.42 dB（p99 1.14 dB）PASS——流程写入产测要求。
  • 辅助路：片上 RF 功率检测器（耦合度 −25 dB 假设），覆盖回退 20 dB，±1.5 dB（S12）； 耦合器兼作 DPD 反馈路（独立耦合器或时分复用，v1.2：反馈链功耗已入 S13 105 mW 口径）。
  • 校准触发：出厂产测 + 运行时温漂跟踪（周期 ≥100 ms，声明）。
  • 校准算法（数字侧）归仿真验证岗行为级验证收敛性与时间。

12.1 测量方法学（口径冻结，fde9 可独立复核）

  • 激励：v014 定稿板器件拓扑零改动，仅把 IF 端当基带包络驱动——64 音等幅多载波 （5…320 MHz，间隔 5 MHz）经 LO 5.5 GHz 上变频，得到 5.5 GHz ± (5…320) MHz 的 320 MHz 信道 DSB 表示；逐级探针取 混频器出 / DRV1 出 / 链出。
  • 相干窗直读（零泄漏）：分析窗 200 ns（= 基带周期整数倍），采样 2 ps，Δf = 5 MHz， 载波正落 FFT 栅格 → 矩形窗无泄漏，逐 bin 复幅度即真值，ACPR/EVM 直接读 bin 不做拟合； 实测杂散底 −113 dBV（低于载波 70 dB），相干性已验证。
  • 交叉校验（必过项）：B 源激励 ≡ 原解析 sin 源（同工况差 0.0006 dB）； LO 摆幅 0.4067 Vpp 与 SOW-2 记录一致；SOW-2 的 fourband 回归在同一份数据上复现 （−47.12 vs 记录 −47.17 dBV）——证明后续差异是口径差异，不是仿真差异。
  • EVM 口径：逐音等幅化 + 去纯延时（线性相位）后余量即失真 EVM；带内幅频不平度单列（纹波），不混进 EVM。

12.3 两条硬结论（决定后续优先级）

① SOW-2 链级 CG 口径偏低 6.0 dB —— 链路预算须更正 SOW-2 的 fourband 回归把 4 个基波取在 ±9/±11 MHz（不是 ±10 MHz）， 500 ns 窗上与真实音不正交 → 24 频最小二乘把一根拆成两根（−3.9 dB）； 且回归里 2*ifamp 传 20 mV（v014 实际 15.8 mV）→ 再差 2.05 dB。 相干 bin 直读真值：链级 CG = −13.19 dB（时域包络 14.0 mV = 两边带各 6.89 mV，自洽）。 影响：§4 输出功率档位按 +16~+19 dBm 目标，但当前拓扑链级 CG 为负，到不了； 先修级间阻抗（结论②），再谈 DPD 与功率档。

② drv1+drv2 实测是净损耗，根因是级间阻抗未匹配 单音逐级：混频器出 −39.85 dBV → DRV1 −1.25 dB → DRV2 −2.09 dB（净 −3.3 dB）； 与 SOW-2 逐级功率完全一致、与 AC 读数 Gdd −3.5 dB 同量级 → 三次独立测量同一结论， 而链板头注规划 drv1+drv2 应有 +14~16 dB → 差约 18 dB。 排除项：Vbcas 1.80→2.05 V 五点扫，链出只动 0.05 dB（共基管准饱和嫌疑排除）。 机理：级间 Zin≈1/gm（2.6 / 9.1 Ω）+ 下一级 Rin 50 Ω + Cin 1 p（2.9 Ω）逐级吃电压。 验证：只改阻值（Rin 50→1 kΩ、RL 25→100 Ω），链级单音增益 −13.19 → +8.34 dB（+21.5 dB）， 各级由负转正。处方已派 b7e7 做级间阻抗匹配联合优化（边界：Vce > 1.2 V、i_vcc ≤ 45 mA）。

12.5 ACPR 的下一步（v2.4 参数扫描，已派工）

混频器是 ACPR 第一限制级（×1 档：链出 −27.7 dBc 时，混频器出即 −36.9 dBc）。 v2.4 对六个物理旋钮做一次一因子扫描：gm 对管尺寸 / gm 退化电阻 / LO 开关对尺寸 / LO 口串阻 Rd / LO 交流耦合 Cc / RF 负载 RL，并在等输出功率上复核（不给 b7e7 不可复现的处方）。

S11 为什么在本 bench 测不了（口径澄清，勿误读）：镜像抑制是复基带 I/Q 不平衡项， 需要「I 路 + Q 路正交激励 → 观察对边带」才能测。本链路的 IF 口是实差分驱动， 单个实端口激励在数学上必然在 LO+f 与 LO−f 同时产生能量，二者无法区分—— DSB 激励下量到的「上下边带功率差」（×0.5 档 −0.48 dB）含 320 MHz 内幅频倾斜，不是镜像抑制， 不得当 S11 读数。要闭合 S11 需在 bench 里加 I/Q 激励器（两组正交实源）， 属开放项；S11 的保证路径目前是 §7 的 IQ 不平衡预算行 + §9 校准。
