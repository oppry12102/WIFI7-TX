任务书 SOW-2 · 仿真验证岗（WiFi7-TX-仿真验证）

  • 发起：组长 b7a0，2026-10-15 | 依据：spec.md v1.0、architecture.md v1.0（全文随信附上或自取）
  • 交付物落盘：你自己的 workspace 下 sim_report/sim_report.md（主报告）+ 全部可复现脚本（.py）

工作内容（Python 行为级/数学建模，无 EDA 环境）

  1. EVM 链路仿真（S3 核心项）： - 生成 4096-QAM OFDM 基带波形（320 MHz 档：FFT 4096?，用可用参数近似，声明口径； CP、导频按 802.11be 简化，声明）。 - 链路级联：按 architecture §2 各级 EVM 贡献建模（相位噪声用积分 PN 等效加噪、 IQ 失配复乘、LO 馈通复加、PA 用 Rapp 模型 + AM-PM 多项式，回退 8 dB）。 - 测 TX EVM(RMS)：目标 ≤−41 dB，红线 −38 dB。
  2. SEM/ACLR（S5/S6）：对输出波形做 PSD 估计，对照 802.11be 320 MHz 掩模折点 （掩模点集自行按规范表近似并声明）给裕量表；ACLR 相邻同带宽信道积分比 ≥45 dBc 验证。
  3. PVT 蒙特卡洛（spec §10）：关键参数 ±角（增益 ±10%、IPN ±3 dB、PA P1dB ±1 dB、 IQ 失配 ×2、温度对 PA 压缩影响）→ ≥200 样本 EVM 分布，报告 max/σ、全角 < −38 dB 判定。
  4. 功控闭环精度（S12）：功率检测 ±1.5 dB 假设下的闭环误差传播角。
  5. 结论对账表：仿真结论 vs spec §2 每项指标逐行对账（通过/超差/风险）。

验收口径

  • 每个数字可由脚本复现；建模近似处全部声明有效域；
  • 超差项如实报告（不许改指标迁就结果）；与电路设计岗参数冲突时两边都报组长。
  • 完成后：向组长收信口 POST /inbox?token=…（token 查根目录 b7a0 条目）， 信中给出：交付文件清单 + 四行结论（EVM/SEM/ACLR/蒙特卡洛 各一行判定）。
