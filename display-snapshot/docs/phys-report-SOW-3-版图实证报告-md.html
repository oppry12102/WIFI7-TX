1. 目标块与口径

  • 块：TX5G_HBTDIFF = HBT 差分放大级（差分对 npn13G2 Nx=2 + rsil 发射极退化 + rppd 负载 + npn13G2 尾流镜 + rhigh 馈电）。 选它的理由：TX 链同族器件（SOW-2 混频器同款 npn13G2）、版图敏感点典型（对称性/引线 R/C）、器件数可控。
  • 器件值一律用 PDK PCell 按 l/w 算出的实值（rsil l2u/w1u=22.9Ω、rppd l4u/w1u=1.104k、rhigh l1u/w1u=1.577k）， 前仿真网表与后仿真网表器件零差异，唯一差别 = 版图提取的 R/C —— 这就是对拍能成立的前提。
  • 版图对称：Q2/RE2/RL2 相对 x=6 轴做镜像摆放（gen_hbtdiff.py 的 mkpc_at(mirror=True)）。

4. 口径与边界（务必随结果引用）

  1. KLayout 版本：PDK 官方 pin 0.30.5（versions.txt）。本机用的是 debian trixie 官方 deb 0.30.0 （已把本地 pdk/ihp_open/versions.txt 的 pin 改成 0.30.0，原件留 versions.txt.orig）。 官方 0.30.12 的 Ubuntu-24 deb 已下到 pdk/klroot312 + pdk/klu，但起不来：KLayout 启动时清 PYTHONPATH， 内嵌 python3.12 找不到 stdlib（无 root 写不了 /usr，user namespace 也被容器禁掉）。 LVS 在 0.30.0 上必须加 --ignore_top_ports_mismatch（deck 用了 0.30.5+ 的 flag_missing_ports）。
  2. DRC 密度规则：AFil.g / GFil.g / M1.j…TM2.c 是全芯片级最小金属/栅密度，子块无填充不适用， 本次以 --no_density 关闭；块级 demo 不背这个口径，全芯片/正式项目必须补 filler。
  3. PEX 是一阶：只算金属走线 R + 对衬底/耦合 C，未含 ①HBT 内部（基极/发射极/集电极 spreading R、多晶电阻本身阻）——模型卡其实预留了 trise/postsim 参数可接； ②晶体管结电容随版图变化；③via/contact 阵列电阻。RSH 与 C 密度是工程估值（PDK 未随附金属层 R/C 数据）， 故给出 ×4/×16 敏感性扫描；多晶 rsh 用的是 PDK 真值（rsil=7 / rppd=260 / rhigh=1360 Ω/□）。
  4. 电阻模型：rsil/rppd/rhigh 的紧凑模型是 r3_cmc（OSDI/Verilog-A），本机 ngspice 无 OSDI （openvaf 预编译包取不到，官方 0.30.12 也带不起 OSDI 依赖）→ 前/后仿真里电阻一律用理想 R， 取值 = PCell 按 l/w 算出的实值，两侧一致。CMOS（sg13_lv_nmos/pmos）同理走 PSP，本机 ngspice 不带 PSP， 故本轮演示块选 HBT 器件族（VBIC 原生可用，也是 TX 链同族）。
  5. 不等于流片签核：这是设计闭环级实证（版图→DRC→LVS→PEX→后仿真→对拍，可复现、有数据有图）， 不替代 foundry 全套规则、EM/IR-drop、天线、LVS 签核流程与 PDK 商用支持。

5. 下一步（按优先级）

  1. 器件级寄生接上：用模型卡的 trise/postsim 把 HBT 的 spreading R 接进后仿真（Q1/Q2 漏极/基极电阻 对 f3dB 的影响通常大于几十微米走线）。
  2. 换个更吃寄生的块重跑同一管线（建议：SOW-2 混频器的 Gilbert 开关四管 + 变压器/匹配网络）， 让 ΔA/Δf3dB 进入有意义的量级，并补 ACPR/LOFT 前后对比（那是 TX 链真正的验收指标）。
  3. 把 SOW-3 的 GDS 图/指标并入交付全景 WebUI（任务书 #43 的管线现成：webui/data/site.json + 15 页冒烟）。
  4. 若拿到 openvaf（OSDI 编译器）→ 解锁 CMOS 器件族，CMOS OTA 版块可整条重跑。
