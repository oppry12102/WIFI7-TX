HBT 级版图准则 · 发射极路径与地轨回流（v1）

发布人：WiFi7-TX-组长 b7a0　日期：2026-10-16　状态：v1（并入设计手册的强制条款） 证据来源：SOW-3 v2.0 / v2.1 版图实证（phys/gilbert/report/SOW-3_v2*.md）， 真实 GDS → DRC/LVS → 第一阶 PEX → 后仿真全链，非经验估计。 适用范围：本项目所有 npn13G2 HBT 共射/共基级（混频器 gm 对、LO BUF、DRV1/DRV2、PA）。

一、为什么要有这条准则

SOW-3 在 TX5G_AMP2（两级 HBT 放大级，39×21µm，DRC 零违规、LVS PASS）上实测到：

电压增益
前仿真（零寄生） +30.43 dB
后仿真（真实版图第一阶 PEX） −3.04 dB
落差 33.5 dB

把 PEX 网表所有串联电阻归零后，增益逐位回到 +30.43 dB——证明落差全部来自提取出的真实版图电阻。 机理判定（mech_amp2.py 单因子实验）：发射极节点的小信号阻抗 Ze≈Re∥1/gm 只有几欧姆， 版图回流路径的几欧姆金属电阻不是「小寄生」，而是直接进分母。 电流只漂了 3.4%、Vce 没有塌陷 → 不是直流偏置问题，是小信号阻抗失配。

换句话说：在 HBT 共射级里，「几欧姆」不是小数目。 教科书级的「寄生按 5% 估」在这里是错的。

二、三条强制准则

R-EMIT-01　发射极路径电阻预算

发射极回流路径的串联电阻总和（金属 + via + 地轨回流）≤ 0.1 × Ze，其中 Ze = Re ∥ 1/gm。

代入本项目各级（Ic 取 design_circuit/sow2_tx5g/design_notes_v092.md 的工作点，VT=25.85mV）：

级 Ic/边 gm 1/gm Re Ze=Re∥1/gm R 预算 折算金属方数（RSH=0.125Ω/□）
mixer gm 对 8 mA 310 mS 3.23 Ω 15 Ω（实测口径） 2.66 Ω ≤ 0.27 Ω ≤ 2.2 □
LO BUF 限幅对 10 mA 387 mS 2.58 Ω ≈5×1/gm（待设计侧确认） ≈2.2 Ω ≤ 0.22 Ω ≤ 1.8 □
drv1 4 mA 155 mS 6.45 Ω ≈5×1/gm（待设计侧确认） ≈5.4 Ω ≤ 0.54 Ω ≤ 4.3 □
drv2 / PA 15 mA 580 mS 1.72 Ω 8.7 Ω（由 gm_eff=96mS 反解） 1.44 Ω ≤ 0.14 Ω ≤ 1.2 □

Ic/边 取自 design_notes_v092.md §级表；gm=Ic/VT（VT=25.85mV）。 drv2 的 Re 是反解出来的：gm_eff=96mS、gm=580mS → 1+gm·Re=6.04 → Re≈8.7Ω。 两处「待确认」的 Re 取 5×1/gm 的经验值——b7e7 若给出实测 Re，本表预算按实测重算。 预算公式对 Re 并不敏感（Re≥5/gm 时 Ze≈(0.83~0.9)×1/gm），但对 Ic 极其敏感： Ic 翻倍 → 1/gm 减半 → 预算减半。

落地要求（DRV/PA 尤其致命）：

  1. 发射极走线只用 TopMetal1/TopMetal2 或双层并联，长度 × 宽度 ≤ 1.2 方块； 用 M1/M2（RSH≈0.125Ω/□）时，2Ω 预算只能走 ≤ 2.2 方块 ≈ 2µm×2.4µm —— 基本不可行， 说明高电流 HBT 级的发射极回流在 M1/M2 上做不出来，必须上厚金属。
  2. via 用 ≥4×4 阵列（2×2 单阵列 0.15Ω 只值 1.94dB，但预算要求 ≤0.05Ω 量级时 2×2 不够）。
  3. 退化电阻与发射极走线的过孔串尽量少：每多一个串联节点就多一份 R，直接进分母。
  4. 走线不要「先横后拐」再拉回来——回折长度是纯浪费，实测 et1m2 一条 14µm 的 M2 线就有 1.75Ω。

R-GND-01　地轨回流压降预算

每一级的地轨回流压降 I×R ≤ 5mV（发射极电位抬升会改变 Vbe→Ic，且各发射极电位不齐会引入共模误差）。

TX5G_AMP2 实测反例：vss 网 4 个引脚各 R/2=3.82Ω，stage1 回流 2.45mA→9mV、stage2 回流 6.76mA→26mV， 两级发射极合计抬高 35mV；只把这一条地轨的电阻归零，增益就回收 12.2 dB。

落地要求： - 地轨在每个功率/驱动级的发射极回流点就近打地，不要用一条细长地轨串起全块； - 回流电流路径按 max(I_peak)×2 估（正弦瞬时峰值可达均值的 2 倍以上，PA 级尤其）； - 地轨过孔阵列 ≥ 发射极过孔阵列（地轨压降与 via 阵列同数量级）。

R-CHK-01　PEX 敏感度必须逐网实测

任何多级有源块，PEX 提取后必须做逐网归零敏感度扫描，并入设计签核。禁止用「几欧姆可以忽略」推断。

理由（v2.1 实测的非单调性）：在「地轨+发射极已归零」的基础上继续把集电极侧 rc / 供电 vcc 的串联电阻归零，增益反而再掉 5dB（36.99 → 31.69 / 31.82 dB）。也就是说：

  • 增益不是「gm×RL」单级模型能描述的，被发射极退化 + 级间耦合 + 共用供电的反馈环路支配；
  • 各网贡献不可相加，渐进归零的顺序会改变结论；
  • 小电阻 ≠ 小影响。这条准则对任何多级有源电路都成立，不限于 HBT。

扫描工具已就绪，可直接复用： phys/gilbert/sim/attrib_amp2.py（逐网/渐进）、mech_amp2.py（单因子缩放）、opcheck_amp2.py（直流工作点）。

三、两条被实测推翻的「常识」（不要再按老经验做）

常见做法 实测结果 正确做法
加大发射极退化电阻 Re 来「压住」寄生 45.8Ω→×2/×4/×8：增益 −3.04→−8.36/−9.13/−11.77 dB，Ic1 从 2.45 掉到 0.90 mA 降低回流路径 R；确需大 Re 必须同时改基极偏置为电流源/带隙，否则是拿增益换偏置稳定度
via 电阻是版图寄生的大头 0.15Ω→0 只值 1.94 dB via 不是重点；回流路径的金属长度才是
