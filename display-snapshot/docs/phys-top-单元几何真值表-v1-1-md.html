单元几何真值表 v1.1（SOW-6 · 组长 b7a0 2026-10-17）

⚠ v1.1 勘误（取代 v1 同名条目）：v1 的「单元 pitch=1.85µm」表述有误——1.85µm 是 npn13G2 多指方向 C 轨 step（Nx 档 bbox 增量：Nx=3 bbox 10.4 = 6.7+2×1.85），不是 PCell 实例间距。实例几何真值（2026-10-17 DRC 二分实测，官方 maximal deck）： - npn13G2 Nx=1 bbox = 6.7 × 7.11 µm（B/E 引脚 y=−1.14/−0.01 不变，C 轨 Nx=1 时 y=+1.13） - 实例最小 pitch = 7.40 µm（间距 6.7/6.75/7.0 → pSD.b 违规；7.4 起干净；mirror 行同验干净） - 行距 ≥ 7.85 µm；guard_ring tap 内缘离 npn bbox ≥ 1.5 µm（tap 入 substrate-tie 环带 → LU.d1/npnG2.c/pSD.b 连锁违规实证） - 共质心原语 hbtdiff_array 默认 pitch=7.40 / row_pitch=7.85 已按此定版（lib13g2 v2）
