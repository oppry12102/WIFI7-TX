0. 先更正两处口径/处方（v2.0 的错，以本报告为准）

更正①：「A0 = +4.41 dB 增益」是绝对电平，不是电压增益

Vb1 ... AC 0.05（50mV 激励），报告里的 A0 取的是 20log10|v(out)|，即 dBV。 同口径的电压增益 = A0 − (−26.02) = A0 + 26.02：

口径 前仿真 后仿真（标称 PEX） 落差
dBV（v2.0 报告写的数） +4.41 −29.06 33.47 dB
电压增益（除掉 50mV） +30.43 dB −3.04 dB 33.47 dB

落差不受影响（前后同参），但任何拿「+4.41dB 增益」去对增益指标的人会差 26dB。 mech_amp2.py 起一律输出 gain_dB（电压增益）与 out_dBV（绝对电平）两个字段。

更正②：「把退化电阻加大到 ≫ 金属 R」是错处方（本拓扑下）

v2.0 结论写的是「要么加大退化、要么当大电流线布」。固定 Vbe 偏置下加大 Re 实测是反效果：

RRS1/RRE2 缩放 45.8×1 ×2 ×4 ×8
电压增益 (dB) −3.04 −8.36 −9.13 −11.77
Ic1 (mA) 2.450 2.028 1.501 0.897

加大 Re → 电流被饿（Ic1 掉到 0.9mA）→ 增益更差。正确处方只有一条：把回流路径电阻降下来。 （若确实需要大 Re，必须同时把基极偏置改成电流源/带隙基准，否则就是拿增益换偏置稳定度。）

1. 结构等价性已证明：33.5dB 是真落差，不是 PEX 建模范式带来的

把 PEX 网表的所有串联电阻和 via 电阻全部置零，得到的增益：

前仿真（零寄生理想网表）      = +30.43 dB
PEX 网表全 R 归零（含 via）   = +30.43 dB     ← 逐位一致

即 PEX 的集总建模范式（每网一 hub、每引脚 R/2、C/2）与理想网表完全等价， 33.47dB 的落差全部来自提取出来的真实版图电阻，没有建模范式误差、没有口径陷阱。 （顺带查过：前仿真 HBT 衬底接 0、后仿真接内部 vss 引脚，两者对结果无影响，衬底不取流。）

2. 机理判定：(a) 小信号发射极阻抗失配，不是 (b) 直流偏置漂移

判据 1：只缩放发射极路径电阻（E1）

发射极路径 R ×k ×1 ×0.5 ×0.25 ×0.1 ×0.05 ×0
电压增益 (dB) −3.04 +4.11 +8.00 +10.50 +11.37 +13.96
Ic1 (mA) 2.450 2.483 2.503 2.515 2.519 2.533
  • 电流只动了 3.4%（2.45→2.53mA），Vce 始终 1.2~1.36V，没有 quasi-sat、没有塌陷 → 排除 (b)。
  • 增益随 R 缩小单调回升并在 ~+14dB 饱和 → 确认是小信号分压：这一级发射极节点的小信号阻抗 Ze ≈ Re∥1/gm = 45.8∥(1/gm)，金属 R 直接进分母。
  • 注意饱和值 +13.96dB 仍比前仿真 +30.43dB 低 16.5dB → 发射极路径只解释了一半。

判据 2：分离「地轨回流」与「发射极走线」（E3）

工况 电压增益 (dB) 相对标称
标称 −3.04 —
只归零 vss 地轨（7.64Ω） +9.17 +12.2 dB
只归零 et1m2（M2 发射极走线 3.50Ω） +11.03 +14.1 dB
vss + 全部发射极网络 +36.99 +40.0 dB

单网归零（其余保留）全表见 phys/gilbert/sim/attrib_amp2.md：最大两项是 et1m2 +14.1dB、vss +12.2dB，其余每网都在 ±3dB 以内 （et1m1 +4.3、out +0.7、cb2 −0.1、vcc −1.1、rc −1.4、et2m1 −0.8、et2m2 −2.5 dB）。

vss 地轨的直流账：4 个引脚各 R/2 = 3.82Ω；stage1 回流 2.45mA → 9mV、stage2 回流 6.76mA → 26mV， 两级发射极电位合计被抬高约 35mV（v2.0 报的 35mV 就是这个数）。

判据 3：非单调性——集电极/供电路径的电阻也会大幅影响增益（重要方法论）

在「vss + 发射极已归零」的基础上继续归零别的网：

再归零 不动 归零 rc 归零 vcc 归零 out 归零 cb2
电压增益 (dB) 36.99 31.69 31.82 37.78 36.98

把 rc / vcc 的串联电阻归零，增益反而掉 5dB。 这说明本级增益不是「gm×RL」单级模型能描述的， 而是被「发射极退化 + 级间耦合电阻 RC + 共用供电」构成的反馈环路支配， 环路阻抗变了增益就变，方向甚至与直觉相反。

方法论结论（比结论本身更重要）： 「电阻小 = 影响小」在多级有源电路里是错的；PEX 敏感度必须逐网实测， 而且渐进归零的顺序会影响结论——各网贡献不可相加。

via 不是问题

via_stack 0.15Ω → 0 只值 1.94dB（+30.43 → +28.49）。v2.0 里「via 扫到 1.0Ω 再掉 2.6dB」 是对的，但它不是主因，别把它当设计重点。

3. 修正后的结论（可直接引用的版本）

TX5G_AMP2 两级 HBT 放大级：前仿真 +30.43 dB → 后仿真（第一阶几何 PEX）−3.04 dB，落差 33.5 dB。 机理是发射极节点小信号阻抗被版图回流电阻分压（Ze ≈ Re∥1/gm，只有几欧姆）， 不是直流偏置漂移（Ic 仅漂 3.4%，无 quasi-sat）。 其中 M2 发射极走线（3.5Ω）单网归零回收 +14.1dB、vss 地轨（7.64Ω）回收 +12.2dB， 发射极路径整体归零回收 17.0dB；剩余约 16.5dB 来自级间/集电极/供电路径与反馈环路的相互作用 （这部分非单调：归零 rc/vcc 反而再掉 5dB，需逐网实测）。 唯一有效处方：降低发射极回流路径（含地轨）电阻；加大退化电阻在本拓扑下是反效果。

4. 由此推出的版图准则（已同步进设计手册）

见 design_circuit/HBT级版图准则_发射极路径与地轨回流_v1.md（组长发布，v1）。 核心三条：

  • R-EMIT-01 发射极路径（金属 + via + 地轨回流）总串联电阻 ≤ 0.1×Ze，Ze = Re∥1/gm； 代入本项目各级：mixer gm 对 ≤0.27Ω、drv1 ≤0.54Ω、drv2 ≤0.14Ω。
  • R-GND-01 地轨回流电阻压降 I×R ≤ 5mV/级（本块实测 2.45mA×3.82Ω = 9mV、6.76mA×3.82Ω = 26mV， 两级合计 35mV 的直流抬升；vss 单网归零值 +12.2dB）。
  • R-CHK-01 任何多级有源块的 PEX 敏感度逐网实测并入签核，禁止用「几欧姆可以忽略」推断。
