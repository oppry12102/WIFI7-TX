SOW-3 v2.0 · 附：Gilbert 双平衡混频级电路级试跑记录（未做成版图块，转文档）

试跑目标：换一个「更吃寄生的块」，首选 TX 链里的 Gilbert 混频级，同时补 ACPR / LOFT 前后对比。 结论：电路级没跑出合格的混频器，改为记录踩坑与结论，v2.0 的版图块换成两级 HBT 放大级 （见 report/SOW-3_v2_TX5G_AMP2_版图实证.md）。以下是可复用的知识，别再踩第二遍。

1. 试过的拓扑（都试过）

# 拓扑 结果
1 四个发射极并在一节点 + 集电极交叉（inp/inn 进 RF 对、lop/lon 进 LO 对） 出 RF 直通 + LO 奇次谐波，无 f_RF±f_LO 乘积
2 LO 对集电极驱动 RF 对发射极（经典 Gilbert 交叉），尾理想电流源 有强开关（±600mA），但 RF 直通几乎不被门控，乘积仍不出现
3 同上但尾电流源换 80Ω 电阻 发射极退化把 gm 从 180mS 压到 12mS，混频彻底消失
4 同 2，但把四管基极都接 v_rf ± v_lo（Gilbert 线性区乘法） 出了乘积，但差分输出对 v_lo 是偶对称（cosh），只出 2f_LO±f_RF（5/7 GHz），没有 f_LO 项

2. 三个硬结论

  1. 尾电流源必须是高阻（理想电流源）。用低阻电阻（80Ω 级）当下拉，发射极退化把 gm 压掉 一个数量级，混频完全消失——这是开关型 Gilbert 的第一性条件，不是调参能救的。
  2. 线性区四管乘法器的差分输出对 LO 是偶对称的：I_diff ∝ sinh(v_rf/Vt)·cosh(v_lo/Vt) → 只有 2f_LO 及偶次，f_LO 项在双平衡里被抵消。想要 f_LO 乘积只能靠开关（拓扑 2）， 而开关型要求 LO 对把发射极电位真正拉下来（LO 对要比 RF 对大、驱动要够硬）。
  3. npn13G2 模型卡带器件自热（selft=1，thermal node 外接 Rt=1e9）时，3GHz 开关瞬态必炸： Timestep too small; trouble with xq4 + temperature limiting function received NaN， 换 reltol/trtol/method/trap/gear 都无解（连 ×16 参数扫描都失败）。selft=0 等温卡立刻跑通。 → 口径：瞬态用等温卡，前后一致；自热另做 DC 单测（ΔT≈15K @ RF 对）。

3. ACPR/LOFT 测量方法（下次直接用，已经跑通）

  • 20ns 观测窗、0.5ps 均匀步进（tran 后必须 linearize 再 wrdata，否则时间轴不均匀）， 频率栅格 50MHz；激励频率全部取 0.5GHz 整数倍 → 谱线正落栅格，无泄漏。
  • AM 驱动（载波 ×(1+m·cos2πfm t)）出载波+两个边带；FFT 取 bin 幅度 → 50Ω 上的 dBm。
  • ACPR = 10log10[(P_上边带+P_下边带)/P_载波]；LOFT = 10log10[P_LO/P_载波]。
  • 差分输出要在后处理里做相减（v(rfout1)-v(rfout2)）：单端口看会多出共模的 LO 馈通， 比差分口径差 20dB 以上，差点误判成「双平衡没工作」。

4. 下一版如果还要做混频，建议

  • 用线性区四管乘法器（拓扑 4），但把 LO 拆成 ±90° 的两路分别进两对管子的基极， 让差分输出对 v_lo 变成奇对称；或者
  • 直接做开关型，LO 对取 Nx=16（RF 对的 2~4 倍）、驱动摆幅 0.8Vpp、尾源理想， 并先把 LO 对能否把 RF 对发射极拉低 0.3V 以上验证掉再排版图。
  • 频率规划建议 RF=1GHz / fm=0.5GHz / LO=3GHz → 载波 4GHz、边带 3.5/4.5、LO 泄漏 3、镜像 2、2f_LO 杂散 6， 全部落在 50MHz 栅格上。
