1. 执行摘要

本项目交付 Wi-Fi 7（802.11be）三频段（2.4/5/6 GHz）射频发射通路的完整设计文档与仿真报告。 直接变频（zero-IF）架构、40 nm CMOS（假设）、双功率路（2.4G 独立 + 5/6G 宽带共用）， 最高 320 MHz 信道 / 4096-QAM（MCS13）。

核心结论： 1. 6 GHz 320 MHz 旗舰档成立：+16 dBm / 4096-QAM，全链 RSS EVM −44.9 dB （v1.3 波形级锚定口径，目标 −41 裕 3.9；fde9 波形级 −41.8，模型保真度差异内一致）； PVT 蒙特卡洛 max −39.7 过红线 −38（裕 1.7）；功耗 564 mW（β=1.0，v1.3）≤ 1.0 W。 2. 评审纠正了两处口径级错误：旧「PA 分配 −46 dB」数错项（漏增益变形项，物理不可达）→ 重分配 −43 dB（DPD 后）；EVM 判据确立按调制档分级（256/1024-QAM −35/−38、4096-QAM −38/−41）， 禁止跨档套用（R-05/R-06）。 3. DPD 纳入架构（v1.2→v1.3 终裁①）：验收门限 6G 20 / 2.4G 22 dB（15/20 为工程目标不计验收、 2.4G 21 底线），预算 105 mW（记忆 GMP 剪枝版 44 mW 备选，§9.8）。锚定口径下无 DPD 6G 全链 −39.5： 红线 −38 过（裕 1.5）但目标 −41 与 PA 分配 −43 FAIL；DPD15 后 −44.9 双过——DPD 工程必要性维持。 4. 2.4G 分档修订：4096-QAM 档 +20→+19 dBm（EVM/功耗双裕量）；功耗上限 0.8→1.0 W （β=0.6 保守基线 +23 档 944 mW）；满功率档 +23（≤256-QAM）红线 −35 PASS（解析裕 5.7；v1.1 勘误：波形级锚定真实裕 0.85 dB，见 §8#10）。 5. 参考源规格：f_ref ≥ 100 MHz 且 L(100 kHz) ≤ −158 dBc/Hz；常规 40 MHz TCXO 使 LO 相噪 恶化 13.9 dB 击穿全链分配，禁用——LO 近带相噪为全链 EVM 第一限制项。 6. 2.4G 记忆效应终判（v1.0 收口，§9.8 协议执行完毕）：s7d 证据包确认行为级记忆核为 M2（失真路径记忆， 构造性）；ACPR 不对称 ≤0.15 dB（非病态，佐证硅实测判别式：>1 dB 不对称⇒换核重跑）；静态 DPD 在 ρ≥0.4 工况残 ~6 dB 不可均衡（线性均衡回收：fde9 报 ~1/3——v1.1.2 澄清=genie 估计上界口径、非工程可入账； b7e7 F 核复现 0.1 dB=真实 CSI 口径，口径已闭环，GMP 正解结论两方一致）→ 记忆 DPD（GMP）为正解：GMP DPD22 下 2.4G 4096Q@+19 档 typ −40.9/max −39.2 双 PASS（红线 −38 裕 1.2）、256Q@+23 满功率档双 PASS（静态口径裕 1.9； v1.1 波形级锚定真实裕 0.85 dB，§8#10），剪枝版 44 mW 备选成立。2.4G EVM 判定由挂起转 PASS（GMP 口径）。
