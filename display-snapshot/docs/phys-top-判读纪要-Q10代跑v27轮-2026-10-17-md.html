四、组长三裁（对 CHANGELOG_Q10 §三问/§4）

裁①（drv1 四只 cmim 落不下）：拆分并联 + 电容专用区重规划

  • 方向：接受"拆分"，否决"接受 81.65µm 大电容"（M5 大平面宽度规则风险未探，不做试验区）与"换型号"（SG13G2 密度 1.5 fF/µm² 唯一 MIM，无更优解）。
  • 约束（四条）： 1. 单只 ≤30µm 见方（对齐你面积闸；Slt.c.M1 教训的边界内档）。Cin 10p → 拆 9×1.11p（27.2µm 见方） 或 16×0.625p（20.4µm 见方），只数你按布局自由度定； Ct 0.84p 单只 23.66 见方本就 ≤30，随专用区重排即可。 2. 电容专用区：drv1 岛内划专门条带（建议 y≥180 非器件区），行距 = 见方+3µm 净距重排， 不再挤 14µm 三行位。 3. 总量守恒：拆分并联合效值 = 网表锚值（10p/0.84p），DEV_NETS 表同步加拆分行 （你自检台 ⑪ 项的逐只核对会替你把关）。 4. 落件后 stdout NOTES 报只数+坐标，我在下轮代跑复核。
  • tank L1 两只占位 keepout (235,5) 同口径维持，待 M4 顶层规划时一并收编。

裁②（drv2 vcc 馈电桶）：vt1 = 37×1（单排 37 颗），否决 7×6=42

依据三条： 1. R-VIA-01 v1.2：EM 底线 22 颗（1.4mA/件×22≈30.8mA ≥ 30mA 馈电）、0.2Ω 档 37 颗 （≈5.4mΩ，120mV 压降根治）——37 颗同时满足电流与压降。 2. 官方实证唯一档：Q8 轮 v13（lib2.2 继承）意外实落 37×1，官方 maximal deck 零新增 （判读纪要在案）——37×1 是唯一有官方 DRC 背书的 ≥37 档位；42=7×6 无实证，按 "未实测档不落地"原则不取。 3. 平台尺寸：TM1 = 0.84×36+1.26 = 31.5µm（长）×1.64µm、M5 = 30.86µm——单排细长条， drv2 岛 x 向放得下（桶原位 y≈19–21 一带横向展开）。 落地：vt1_cols=37, vt1_rows=1（v2.2 即支持 cols/rows）；自检台 37×1 档平台真值按 律给出（31.5/30.86）+ 官方 v13 轮 lyrdb 实落坐标对照即可，无需新测。

裁③（平台律口径）：分段口径

  • n=1 走单孔规则：cut 0.42 + 2×0.61 = 1.64µm 见方；
  • n≥2 走实测线性律：TM1 = 0.84(n−1)+1.26、M5 = 0.84(n−1)+0.62，pitch 0.84；
  • 两者不连续是规则结构使然（单孔/阵列两套规则域），不是矛盾；律只在 n≥2 域内 使用（七档实测支撑内插+适度外推），永不外推到 n=1。自检台 ⑲/⑳ 按此分段实现。 （1×1 强套律得 1.26<1.64 即为越域误用——你指出的"不自洽"正解是分段。）
