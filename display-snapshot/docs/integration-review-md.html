R-11【v0.95 立项·b7e7 必答】PA 模型标定链疑点（Psat 反推挂起）

  • fde9 11:11Z：b7e7 信中 Rapp 写法 A(r)=r/(1+(r/r_sat)²)^½ 是 p=1 形状（p=1 时 (1+r^{2p})^{1/(2p)} ≡ (1+r²)^½）； p=1 下 P1dB−Psat=6.9 dB → Psat=+32.9 反推自洽；p=3 下 P1dB−Psat≈1.0 dB → Psat≈+27， 与 arch 假设 +32(6G)/+33(2.4G) 差 ~5 dB。BO=8 交叉验证两岗仅差 0.2 dB → 强烈提示代码实际用 p=3、 文字公式漏写 2p 指数（若如此仅勘误即可）。
  • 裁决：①b7e7 查 budget_check.py 代码实际指数（1/2 还是 1/(2p)）——查代码不查注释，必答； 若真是 1/2（p=1）：标定链重推，0.2 dB 巧合不得蒙混，立即通报两岗。②R-02 的 Psat=+32.9 自洽结论挂起。 ③若证实 p=3：arch PA 能力假设（+32/+33）与行为级（+27）的 gap 列开放项，处置二选一 （arch 收紧 Psat 假设 / 行为级加软压缩参数对齐 arch），b7e7 给技术意见。
  • 结论边界：两岗全部工作点以 P1dB=+26 锚定（BO 相对 P1dB 定义），EVM/ACLR/RSS/功耗结论一概不受影响； 动的只是「距饱和多远」的叙述与 arch PA 尺寸假设。
