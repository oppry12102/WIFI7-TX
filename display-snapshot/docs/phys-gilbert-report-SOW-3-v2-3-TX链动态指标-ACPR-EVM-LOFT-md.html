SOW-3 v2.3 · TX 链动态指标实测：ACPR / EVM / LOFT / OOB 谱廓

日期：2026-10-16 12:0x–12:5xZ　组长：b7a0　状态：已完成，可复核 数据源：pdk/sim/v014/chain_top_tb_v014.sp（b7e7 v014 定稿板，器件与拓扑零改动） 脚本：phys/gilbert/sim/dyn_metrics.py（gen/run/judge/all）　数据：pdk/sim/dyn/{decks,raw}/（10 个可复现 deck + CSV） WebUI：http://62.234.172.57:8600/dyn

0. 一句话

SOW-1～SOW-2 与 v2.2 全部是静态/小信号指标；802.11be TX 的验收指标（EVM / ACPR / LOFT）从未实测。 本轮第一次把全链瞬态跑成「多载波信号 → 输出频谱 → 逐 bin 判读」，给出三条验收曲线， 并在扫描中挖出两个硬结论：①链级增益的 fourband 口径系统性偏低 6.0 dB；②现设计的级间阻抗未匹配， 整链 drv 段实测为净损耗（−3.3 dB），与规划 +14~16 dB 差 18 dB。

1. 方法学（口径冻结，供 fde9 独立复核）

1.1 为什么能在 IF 端调幅

v014 链板里 IF = 10 MHz 单音、LO = 5.5 GHz，出 5.49/5.51 GHz —— 即混频器把 IF 当基带包络用（LO±IF）。 把 10 MHz 换成「5…320 MHz 的 64 个等幅正弦和（间隔 5 MHz）」，射频侧就是 5.5 GHz ± (5…320 MHz) 的 64 音多载波，即 320 MHz 信道的 DSB 表示。这不是补丁式凑数： 链路本身（Cin=1p 耦合 + Gilbert 开关对 + 无 tank 的宽带级）就是宽带变频结构。

1.2 相干窗 = 零泄漏

  • 64 音间隔 5 MHz → 基带周期 200 ns；LO 5.5 GHz = 1100 × 5 MHz。
  • 取 T = 200 ns 整窗、采样 2 ps（100 000 点）→ 所有谱线正落 FFT 栅格 Δf = 5 MHz， 矩形窗零泄漏，逐 bin 复幅度即真实正弦幅度 → ACPR/EVM 直接读 bin，无需拟合/窗函数修正。
  • 实测杂散底：载波附近 99 分位杂散 −113 dBV（比载波低 70 dB）→ 相干性已验证。
  • 差分口径：vr = v(noutp) − v(noutn)，负载 25 Ω/边 → 差分 50 Ω，P = A_pk²/(2·50)， 与 SOW-2/fde9 的「峰值幅度 @50Ω（dBm = dBV+10）」同一口径。

1.3 激励源的坑（本 ngspice-47）

V… file("…") 被静默忽略（源停在 dc 值上，链出差分 ≈ 1e-13 V，查了半天才发现）； pwl(file="…") 直接解析报错。故改用 B 源 B… V = {1.532 + Σ a_k·sin(2πf_k t+φ_k)}。 等效性由 case cal1tone vs calorig 证明（同工况差 0.0006 dB，见 §2）。

1.4 EVM 口径（按 802.11 测量实践）

先逐音等幅（per-tone equalization，等价于用导引做信道估计）+ 去线性相位（纯延时，本例 −26.5 ns） → 余下才是失真 EVM。带内幅频不平度单列 ripple，不混进 EVM；同时给出未等幅的 EVM_flat 作对照。

1.5 逐级探针

混频器出 nmixp−nmixn / DRV1 出 nd1p−nd1n / 链出 noutp−noutn，三处同法判读 → 失真归属。

两处偏差来源（均可查证）： 1. FB4 = [5.5G∓11M, 5.5G∓9M] —— 四个基波取在 ±9/±11 MHz，不是 ±10 MHz。在 500 ns 窗上 （正交长度 1/2 MHz = 500 ns = 窗长）它们与真实 ±10 MHz 音不正交，24 频最小二乘把一根 拆到两根上，系统性低估 3.9 dB；该回归 fit_resid = 0.2976（30% 残差）本就不干净。 2. 回归里 cg = dBV(A0) − dBV(2*ifamp) 传的是 ifamp=20mV，而 v014 链板实际 ifamp=15.8mV → 再差 2.05 dB。

物理侧自洽：vr 时域包络峰值 14.0 mV = 两个边带各 6.89 mV ×2 ✓。

影响：mixA(−19.15) / mixlv(−15.86) / drv1out(−17.11) / chain(−19.22) 四个 CG 读数同源偏低； IM3/IM2/OIP3 是比值，基函数错位对同侧产物影响较小，是否仍可用由 fde9 判。 建议：今后链级 CG 一律用相干 bin 直读；fourband 值留档，不再作 CG 判读依据。

3. 实测结果

3.1 LO 馈通单测（IF 关，仅 LO 驱动）

链出 5.5 GHz −278 dBV（≈0，低于数值底） → LO 自身不向链出馈通。 因此多音工况里那条 5.5 GHz CW 线（LOFT −7…−31 dBc）不是 LO 直馈，而是偶阶互调落回基带 0 （多音本身无 DC 分量）→ 这是本架构 LOFT 的真实机理，与「LO 隔离不够」的传统解释不同。

4. 扫描中挖出的第二个硬结论：链级 drv 段是净损耗

4.1 现象

单音（15.8 mV/10 MHz）下逐级读数（相干 bin 直读）：

级 幅度 (dBV) 本级增益
混频器出 −39.85 —
DRV1 出 −41.10 −1.25 dB
DRV2/PA 出（链出） −43.19 −2.09 dB
  • 与 SOW-2 逐级功率完全一致（mixout −33.82 / drv1out −35.07 = −1.25 ✓ / chainout −37.18 = −2.11 ✓）， 也与 v2.2 emit_scan 的 AC 读数 Gdd = −3.5 dB 同量级 —— 三次独立测量同一结论。
  • 而 v014 链板头注规划「drv1+drv2 = +14~16 dB」→ 实际差约 18 dB。这个差距此前没人看见， 因为 fourband 只记了链级一个数，从没把「级间为负」摆到台面上。

4.2 定位：不是器件坏了，是阻抗没匹配

先排除一个嫌疑：DRV2 共基管 XQ3/XQ4 的 Vbcas=2.05V 固定而其发射极 ccas1 实测 1.006 V（Vbe=1.044 V、 C-B 结正偏 ~85 mV，形似准饱和）。扫 Vbcas 1.80→2.05 V（5 点）链出幅度只动 0.05 dB → 嫌疑排除 ✓。

真正的机理是级间/级内阻抗：drv 子板 RL=25Ω（输出）+ 下一级 Rin=50Ω（输入并联）， 而共基级输入阻抗 ≈ 1/gm ≈ 2.6 Ω（drv2, gm=371 mS）/ 9.1 Ω（drv1, gm=110 mS）， 再串 Cin=1p（5.5 GHz 处 2.9 Ω）→ 每级都在把小信号电压吃掉。

4.3 验证：全局阻抗重标定（单参数族对照，网表其余逐字不动）

工况 drv1 级 drv2 级 链级 CG
名义（Rin 50 Ω / RL 25 Ω） −1.25 dB −2.09 dB −13.19 dB
Rin 50 → 1k +1.82 dB −2.11 dB −5.13 dB（+8.1）
RL 25 → 100 Ω +11.60 dB +1.78 dB +8.34 dB（+21.5）

→ 把输出负载从 25 Ω 提到 100 Ω，整链单音增益从 −13.2 dB 抬到 +8.3 dB，各级由负转正。 机理判定成立：根因是级间/级内阻抗未匹配，不是某一级的器件或偏置坏了。

边界声明（诚实条款）：RL/Rin 同时承载直流，25→100 Ω 会移动直流工作点 （drv2 集电极静态电压 2.13 V → ~1.0 V），故上表是参数族研究而非纯 AC 对照； 取值需 b7e7 在保住 DC 余量（Vce > 1.2 V、无准饱和）与 i_vcc ≤ 45 mA 判据下联合优化， 并回填 OP + sp + tran 三板判读。

S3a EVM @256/1024-QAM ≤ −38 dB 同上，×2 驱动 −41.7 dB ⚠️ 余量仅 3.7 dB
ACPR（802.11 常规） ~−45 dBc −43.95 dBc @ −36 dBm ⚠️ 已贴线
链级输出功率 +16 dBm（S1 类） 当前拓扑整链 −13.2 dB CG，无法到 +16 dBm ❌ 见 §4

结论：动态指标的瓶颈不是非线性本身，而是①链级增益不足（阻抗未匹配）→ 无法到达工作点； ②到达后 ACPR 余量只有 1 dB。建议优先级：先修阻抗匹配（b7e7，§4.3 给了方向）， 再谈 DPD/预失真。
