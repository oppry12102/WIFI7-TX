3.2 真值与裁决（组长判读，纪要见 phys/top/）

  1. via_stack 六组合全通（probe 实测 + 官方 maximal deck）： M2↔M3 / M3↔M4 = 0.70×0.61；M4/M5↔TM1 = 1.64×1.64 大环档。 Q1 裁决：全栈单颗、中间层焊盘全留——柱下 keepout 为必需（非保守），R-VIA-01 max 列 = techlef 真值， target = max×½ 降额（最终 PEX ≤0.2 Ω 门，187 件/边维持）。 金属 Rsheet 真值（libs.ref techlef，开源 PDK 唯一金属 RC 出处）： M1 0.135 / M2–M5 0.103 / TM1 0.021 / TM2 0.0145 Ω/□（厚 0.40/0.45/2.0/3.0 µm）； Cont 22 / Via1–4 20 / TopVia1 4.0 / TopVia2 2.2 Ω/件。A1「15 Ω/□」作废。
  2. 镜像语义：库无缺陷零改动——Trans(2,True,0,0) ≡ 左右镜像；b7e7 判别式把 mirror 参数记反（已澄清）。
  3. cmim 实装：PCell 名 "cmim"，参数 = w & l；0.84 pF → 23.66 µm 见方。
  4. R-RES-01 poly 真值：cornerRES 三档 rhigh 1160/1360/1560、rppd 234/260/286、rsil 6.02/7.0/7.98 Ω/□ （1σ 5/2/1.7%）；2 kΩ 电阻 = rhigh 1360 typ。
  5. R-ANNO-01 注记纪律：/25 被 connect 进金属网 = 次级 label（写非网名必生幽灵网）； 63/0 被器件模式匹配（varicap/ntap/isolbox/rfnmos）；占位说明不回 GDS；254/0 私有层默认不用 （官方穷举零命中，Q4 裁决：无自由注释层）。
  6. LVS 口径：层次网表 NAMES_SEP="/"（Q2）；块级岛不放 bondpad（Q3，M2 两浮空 pad 已撤）。
  7. guard_ring 双环 + keepout（需求单⑤⑥）：外 ptap×50 + 内 ntap×48（inset 2.0）； NBL.b 真值：ntap 环 NBL 宽 1.26 µm + space 1.5 → 中心距 ≥2.76，库定 step_n=2.8； M1.b 真值：min space/notch 0.18 µm → 接线盖头法纪律（wire 加宽与端头大面积重叠合并=无边缘对，禁擦边）。
  8. net_check v2.1 两修复：①悬空桶（hit=−1）误入短路判定→除名；②bbox 包含误吸环形多边形环内 label → bbox 粗筛 + Polygon.touches(zero-box) 精判（merged 对嵌套多边形吞成外框，勿用此法，真环形安全）。 ⚠ 代跑口径：M2/M3 件若依赖旧版 net_check 语义（假短路放行），判读以 v2.1 严口径为准。
