## 二、M4 v2 草案五项裁定（裁定十九）

### 2.0 先立两条实测纪律（b7e7 探针口径订正）

1. **摆位/bbox 一律以 gdstk 全层读回为准**。`all_boxes` 只统计带 label 的端口形状，漏无 label 的走线：

   | 子块 | 真 GDS 全层 bbox（cell 系） | 尺寸 | b7e7 草案 |
   |---|---|---|---|
   | mix `TX5G_M2_MIX_V28` | **(−79.200, −7.310)~(66.350, 274.030)** | **145.550×281.340** | 145.2×281.265 ✗ |
   | drv1 `TX5G_M3_DRV1_V20` | (−62.000, −2.310)~(325.640, 218.940) | 387.640×221.250 | ✓ 一致 |
   | drv2 `TX5G_M3_DRV2_V20` | (−81.000, −11.000)~(108.000, 250.000) | 189.000×261.000 | ✓ 一致 |

   左缘真值 **−79.200** 由一条**无 label 的 M4 横带 `x[−79.200, 54.000] y[16.000, 20.000]`** 决定（探针漏计）。
   **v2 摆位表（组长核定）**：mix place **(79.200, 7.310)**；drv1 (247.200, 2.310)；drv2 (693.840, 11.000)
   ⇒ 顶层 (0,0)~(145.55,281.34) / (185.2,0)~(572.84,221.25) / (612.84,0)~(801.84,261.0)
   ⇒ **envelope 801.84×281.34**（草案 281.265 修正 +0.075）；**通道 40.0µm 不变**（572.84→612.84）✓；
   strip235 顶层绝对系 (201.200, 10.310)~(572.840, 221.250) ✓ 复核一致（36 块 union）。

2. **净距一律引 PDK 规则真值**（`tech/drc/docs/main_rules.md`），不用经验值：
   `M1.b 0.18 / M1.e 0.22`（>0.3µm 宽且平行段>1.0）；`M2.b 0.21 / M2.e 0.24`；
   `M3.b 0.21 / M3.e 0.24`；`M4.b 0.21 / M4.e 0.24 / M4.f 0.6`；**`TM1.a 1.64 / TM1.b 1.64`**；
   **`TM2.a 2.0 / TM2.b 2.0 / TM2.bR 5.0`**（>5µm 宽且平行段>50µm）。
   ⚠ **TM1/TM2 间距 1.64/2.0 远大于 M1~M4，是本轮最易踩的坑。**

### 2.1 五项裁定

**① 通道 1 交叉解 → 采纳 TM2 翻越段（①）**，但按真 GDS 重算宽度与间距：翻越段 **TM2 宽 ≥2.0**、
对既有 TM2（x[−21,−19]/[19,21] y[243.03,265.03] 与横条 y[264.03,266.03]）净距 **≥2.0**；
翻越段若做到 >5µm 宽且平行段 >50µm 则触发 **TM2.bR = 5.0**，请在 gen v2 内置断言。
备选②（绕岛北缘）路径长且与 TM2 干路挤，不采纳；③ 已否决（岛内下行穿核区）。

**② mix 顶出线带净距口径 → 否决草案位置 y[238.1, 241.1]，给替代窗口 y[237.66, 240.03]**
真 GDS 实测上方障碍底边（草案三处坐标全部偏低，故间隙被系统性高估）：

| 障碍（cell 系） | 草案报值 | **真值** |
|---|---|---|
| TM2 竖条 x[−21,−19] / [19,21] | —（漏列） | **底 242.030** |
| TM1 pad x[−20.950,−19.050] | nbiasH 242.96 | **242.080** |
| TM1 pad x[−0.820,0.820] | — | **242.210** |
| TV2 | 转接孔 242.65 | **242.580** |
| 下方器件 P2 M1 焊盘 | body 顶 237.09 | **M1 pad 顶 237.160**（body/activ 实测顶 <228，骑体规避律裕度 >10µm） |

⇒ 草案带顶 241.10 对 TM2 净距 **0.93 < TM2.b 2.0** ✗、对 TM1 pad **0.98 / 1.11 < TM1.b 1.64** ✗ ⇒ **双违规**。

**核定窗口**：
* 带底 **≥ 237.66**（P2 M1 pad 顶 237.16 + 0.5µm 净距口径）；
* 带顶 **≤ 240.03**（rfop/rfon 竖段 x 带内受 TM2.b 2.0 约束；若把翻越段挪出该 x 带，可放宽到 240.44）；
* 带宽 **2.37µm ≥ TM1.a 1.64 ✓**，余量 0.73µm。
* **金属-电阻 body 净距口径：≥0.5µm 即可，不要求 2µm**——幻影焊规避律看的是「不覆盖 body bbox」，
  实测 activ body 顶 <228，与窗口裕度 >10µm，草案「1.01µm 间隙已满足」的结论方向正确。

**③ 通道 2 主层 → 批准 M4 直行，M3 备选不启用（保留为 escape hatch）**
真 GDS 实测：drv2 `inp/inn` M1 焊盘 `x[−46.150,−45.850] / [−39.150,−38.850] y[5,8]`；
同 x 带 gnd M4 轨 `y[9.560,100.000]`（草案写 111，**数字转置**，真值 100 = GND_Y），
其根部另有 0.7µm 宽局部 pad `y[9.255,9.865]` ⇒ **实际净距 1.255µm**（草案 1.56 系只取 0.3µm 宽轨底）。
规则侧：M4.e 触发（线宽 3µm>0.39 且平行段>1.0）限 **0.24**；M4.f 不触发（无 >10µm 宽线）。
⇒ **1.255 ≫ 0.24，M4 直行合规**。同时复核 **「M2 是唯一净空进线层」成立**：drv1/drv2 岛内 y[0,20] 带
M2 仅零星 pad，长条只有岛缘 guard 竖条（drv2 x[−78,−76] / [103,105]）。

**④ gnd 出轨封顶 → 立案 v21 候改（不阻塞 v2）**
独立复核 **b7e7 §3 系统性发现成立**：drv1 出轨 M4 `x[−42.150,−41.850] / [−35.150,−34.850] y[9.560,82.000]`，
drv2 同构到 100.000，x 带与输入焊盘完全重合 ⇒ M3+ 高层进线在该 x 带被封。
记入候改清单，v21 选项：Rin.P2 出轨改道 或 焊盘区扩双焊盘。

**⑤ M4 v2 动图许可 → 有条件批准**，条件四条：
* (a) 摆位表按 §2.0 核定值（**全层 bbox**）；
* (b) 通道 1 出线带按 §2.1② 窗口 `y[237.66, 240.03]` 重算，翻越段按 TM2.a/b 重算；
* (c) gen v2 内置 **body keepout 自动复检 + 全层 bbox 断言**（治本：禁止用 `all_boxes` 子集做 bbox/净距判读）；
* (d) 出件先投 8510，我侧代跑 **DRC + 全层 bbox/净距复核** 后再进 M4 组装。
