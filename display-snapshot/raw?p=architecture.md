## 0. 工艺平台（v1.1 定稿：IHP SG13G2 开源 PDK）

**选定：IHP SG13G2，130 nm SiGe BiCMOS，Apache 2.0 开源**（选型论证见 research/PDK_SG13G2_落地评估_2026-10-16.md）。

已实测锚点（本组 ngspice-47 + PDK 模型实跑，pdk/sim/）：
- SiGe HBT（npn13G2, Nx=4, Vce=1.2 V, typ 27 °C）：**β 峰值 ~820；fT 382 GHz @ 3.8 mA → 434 GHz @ 9.6 mA**（ft_ic_np13G2_Nx4.csv）。RF 有源级（混频器核心/驱动/PA 前级）以 HBT 为主力器件。
  **器件级 P0 sanity 闸门已过**（2026-10-15 复测：fT 交点 383.2/434.2 GHz vs 锚 +0.31%/+0.05%，β 峰 812.9 vs 820 −0.87%；sim_report/sow2_results/d1_p0_sanity_typ_v1.json）。口径注记：锚点为 0 dB 交点法；-20 dB/dec 理想段外推因 VBIC 高频寄生变平偏低 ~18%（307/356 GHz）——批扫统一交点口径。corner 批扫（3 corner × 5 Vce × 25 Ic）进行中。
  工作点校准（偏置链计算用）：Vbe=0.88 V @nx=6, Vce=1.2 V → Ic≈6.9 mA，**β≈570**（β 820 是 0.5 mA 量级峰区值，勿用于工作点电流预算）。
- 仿真环境：sp 分析可用（RF port=VSRC 选项，含 donoise 噪声相关矩阵，已用 50Ω 直通校准）；**hb 不在**（Debian 构建 ngspice-47）→ P1dB/OIP3 走 tran 双音+FFT。

## 1. TX 链路拓扑

```
 数字前端(DFE)      模拟基带/RF（SG13G2 130nm SiGe BiCMOS，选定）     
┌──────────────┐   ┌────────────────────────────────────────────────────┐
│ Fs_bb=320Msps │   │  DAC(12b,1.28Gsps,IQ) → 重构LPF(4阶,fc≈420M)        │
│ ×4插值 FIR    │──▶│    → VGA(0~15dB,0.5dB步) → GM级+无源正交混频器       │
│ DC/IQ预矫正   │   │    → 驱动级 → 功率级(PA) → 片上transformer → 焊盘    │
│ CFR(预留)     │   │       (25%占空LO混频)  (2.4G / 5-6G 双路)           │
└──────────────┘   └──────────────┬─────────────────────────────────────┘
       ▲                          │ 耦合器(-25dB)
       │ 校准系数回写              ▼
┌──────┴──────┐           ┌───────────────┐
│ 校准/功控逻辑 │◀──────────│ RF功率检测+ADC │
└─────────────┘           └───────────────┘
       ▲
┌──────┴───────────────────────────────┐
│ LO 合成: PLL(ΣΔ分数N,BW≈800kHz)       │
│ VCO 4.8–7.2GHz(双带) → ÷2(2.4G)/直通 │
│ → 多相IQ → 25%占空 → LO分配缓冲      │
└──────────────────────────────────────┘
```

要点：
- **直接变频（zero-IF）发射**：无中频滤波/镜频抑制硬件负担，三频段共用基带带宽可编程。
- **双功率路**：2.4 GHz 独立一路；5/6 GHz 共用宽带一路（transformer + 开关电容调谐覆盖
  4.9–7.125 GHz）。理由：5/6 GHz 单路宽带可省面积；2.4 GHz 频率比悬殊（>2×），分路效率优。
- 25% 占空比无源混频器：较 50% 方案噪声/线性更优，LO 生成用脉冲整形。

> **v1.4 晶体管级实测口径更正（SOW-3 v2.3，2026-10-16 组长代跑，v014 定稿板）**——
> 上表增益列是**行为级设计预算**，晶体管级实测与之有三处实质差异，**按下列数字为准**：
>
> 1. **链级 CG 真值 = −13.19 dB**（相干窗逐 bin 直读，200 ns 整窗 / Δf = 5 MHz / 64 音 5…320 MHz）。

>    fourband 把 4 个基波取在 ±9/±11 MHz（非 ±10 MHz），500 ns 窗上与真实音不正交 →
>    24 频最小二乘把一根拆成两根（−3.9 dB）；且回归传 `2*ifamp` = 20 mV 而 v014 实际 15.8 mV（−2.05 dB）。
>    在同一份数据上复现旧回归值（−47.12 vs 记录 −47.17 dBV）→ 两值同源，差异可完全归因。
> 2. **驱动段实测为净损耗**（上表「驱动级 +6 dB」行）：单音逐级 混频器出 −39.85 dBV →
>    **DRV1 −1.25 dB** → **DRV2 −2.09 dB**（净 −3.3 dB）；三次独立测量（SOW-2 逐级功率 /
>    AC 读数 Gdd −3.5 dB / 本轮瞬态）同结论，而 v011a 链板头注规划 drv1+drv2 应有 +14~16 dB → **差约 18 dB**。

## 4. LO 合成

- PLL：ΣΔ 分数 N（三阶 2-1 MASH 假设），环out带宽 800 kHz；带内 −95 dBc/Hz、
  VCO @1 MHz ≤ −129 dBc/Hz（spec §8 口径）。
- VCO 4.8–7.2 GHz 双子带；2.4 GHz 档 ÷2 直生、5/6 GHz 直通。
- 正交：多相滤波器（RC-CR，两级）+ 25% 占空整形；正交误差预算 0.3°/0.05 dB（校准后，spec §7）。

## 5. 校准与功率检测辅助路

- 片上方向耦合器（−25 dB，假设）→ 对数 RF 检波器 → SAR ADC → 数字功控：
  闭环精度 ±1.5 dB（spec S12），覆盖 +20~−20 dB 相对满功率。
- 校准项与触发：LO 馈通（数字 DC 补偿，产测+运行粗调）、IQ 不平衡（产测一次 + 温漂查表）、
  PA 温漂（运行时闭环跟踪，周期 100 ms）。
- 观测路假设：产品无片内 TX→RX 回环；行为级验证用模型回环（仿真岗建）。

## 6. 数字前端与接口

- ×4 插值（半带级联 FIR，63 抽头等效）、通带纹波 ≤0.05 dB、阻带 @1.12 GHz ≥50 dB。
- DC/IQ 预矫正系数接口（校准回写）；CFR 预留（v1 不启用）。
- 接口假设见 spec §6（DDR 640 MHz 或串行，集成时定）。

## 7. 风险登记（集成评审重点核对）

1. 6 GHz 320 MHz 档 SEM 裕量（滚降+PA 宽带压缩的联合作用）——仿真岗重点角。
2. 4096-QAM EVM 全温全角保持 −38 dB 规范线（设计目标 −41）——PVT 蒙特卡洛。
3. 双路 PA 的 5/6 GHz 宽带覆盖（6.1–7.1 GHz 高端 PAE 跌落）。
4. 25% LO 占空误差→正交误差→EVM 灵敏度。
5. 功率检测在深回退的温度漂移（闭环精度假设）。
6. **（v1.1 新增）130nm 数字效率**：DFE/DAC/PLL 数字部分在 SG13G2 上的面积/功耗高于

## 8. 线性度判据审计（v1.3 新增，组长主笔；b7e7 终局取舍依据）

> 审计对象：SOW-2 任务书对 mixer/链定的「链出 IM3 低边 ≤ −45 dBc」双音代理判据。
> 审计问题：①判据从 802.11be 规范怎么推出来、严不严；②实测 −40.1 dBc 的差距物理上是什么；
> ③45 mA 组合拳是否必须（+83 mW 含参考支路代价谁背书，v1.4 勘误口径）；④判据达成 ≠ 系统合规，缺口在哪、谁补。

### 8.1 三层判据链（规范 → 系统 → 块）

| 层 | 判据 | 出处/口径 |
|----|------|----------|
| 规范层 | 4096-QAM EVM ≤ **−38 dB**（发射机合规线）；SEM/杂散管带外 | 802.11be（spec §2 双线制引用） |
| 系统层 | 全链 RSS ≤ **−41 dB**（设计目标）/红线 −38；PVT MC max −39.7 | spec §7 v1.2 冻结；fde9 波形级 −41.8（含成形）已闭合 |
| 块层 | VGA/混频 AM-AM/AM-PM 分配 **−46 dB**（RSS 之一项，设计引导值非硬闸） | spec §7（R-08 冻结）；分配表 RSS −38.8 为全分配保守堆叠 |
| 代理层 | 链出 IM3 低边 ≤ **−45 dBc**（双音，IF −23 dBm/音 测试口径） | SOW-2 任务书；**本节审计对象** |

换算（代理层 ↔ 块层）：双音每音 −23 dBm/音下，IM3 边带 −45 dBc（相对单音）⇔ 两个边带总交调功率 /
双音总功率 = 10^(−4.5) ⇔ **EVM 贡献 −45.0 dB**——与块分配 −46 dB 差 1 dB（判据略松 1 dB，双边带对称口径）。
**结论①：判据不过严**（上口 04:10Z 代理审计结论维持，本次给出推导固化）。

### 8.2 实测差距的物理归属（IM3 改判开关级/IM2 主导，正式入档）

- v010 链实测：IM3 低边 **−40.14 dBc** @ IF −23 dBm/音（对判据差 4.9 dB）；上下边带不对称 5~10 dB。
- mixer 单板 M3 三点（−23/−17.9/−8 dBm/音 → OIP3 −16.2/−8.2/+0.5 dBm）：低电平段 OIP3 斜率
  **+1.56 dB/dB** ⇒ IM3 绝对斜率 **s = 2β−1 ≈ 2.13 dB/dB**（三阶应为 3，二阶为 2）——介于其间偏二阶；
  高电平段 s≈0.76（压缩区）。
- 三条旁证（b7e7 判读，收录入档）：①IM3 上下边带不对称=开关级指纹（gm doublet 中心对称给不出）；
  ②OIP3 漂移介于二阶/三阶=IM2 主导+混合路径自洽；③尾流节点共模包络→调制换向点机理
  （ntail FFT 探针 2 MHz 分量，45 mA 后应缩 ~2.8×，判别实验必选）。
- **结论②：mixer 线性度瓶颈正式改判「开关级/尾流（IM2 主导混合路径）」**，v1.0~v1.2 的 gm 级
  （multi-tanh 双 gm 对）假设降级为已验证非主导路径（结构保留：OP 健康、CG 税符合模型）。

### 8.3 判据的两种语义与「不充分」结论

| 语义 | 口径 | 状态 |
|------|------|------|
| (a) SOW-2 块级验收口径 | 双音 IF −23 dBm/音，v0.10↔v0.11 同口径可比 | v010 −40.1 → 差 4.9 dB；45 mA 预期 −44.6~−49.1 → **压线~达标** |
| (b) 系统合规口径 | 标称工作点（mixer IF 输入 −16~−18 dBm/音 平均，档位联动区间）下带内交调 EVM | 换算通路见下，**未闭合** |

换算通路（低电平段 s≈2.1）：电平 +ΔdB ⇒ IM3c 恶化 (s−1)·Δ ≈ **1.1·Δ dB**。
测试点 −45 dBc 判据 ⇔ 标称点（+5~7 dB）≈ **−38~−39.5 dBc** → EVM 贡献 −38~−39.5 dB：
**够红线 −38 的边缘、不够块分配 −46（差 6~8 dB）**。三阶假设（s=3，2·Δ）下鸿沟是 10~14 dB——
IM2 主导斜率救回一半，这是判据「不充分但不致命」的定量原因。
**结论③：−45 dBc 判据必要且方向正确，但达成它 ≠ 标称点合规**；合规闭环靠三件事：
①45 mA 把标称点抬到 −43.6 dBc（收益上沿）；②v0.12 drv 轮增益补齐后的**电平重配**——VGA 档位联动
把 mixer 输入电平再压 3~5 dB（DAC 回退+VGA 补，噪声/量化代价换线性度，波形级核，免费杠杆）；
③fde9 波形级 OFDM EVM 终审（含 IM2 带内分量，§8.5-④）。

RSS 快算（背书 ③-①的充分性上沿）：VGAMIX 贡献若到 −43.6 dB，其余块取设计值（DAC−53/LPF−58/
LO−44.1/IQ·LOFT−55/PA−57.2@DPD20）→ 全链 RSS ≈ **−40.1 dB**（贴设计目标 −41，红线 −38 裕 2.1）；
若 45 mA 只兑现下沿 −44.6（标称 −39.1）→ RSS ≈ **−37.1 dB 破红线** → 靠 ③-② 电平重配补。
**故 45 mA 拍板维持（必要性成立），v0.12 drv 轮升格为合规闭环必要环节**（不再只是增益缺口修复）。
