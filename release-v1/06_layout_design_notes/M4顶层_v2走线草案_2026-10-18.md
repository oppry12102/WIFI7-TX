## 3. ★系统性发现：端接电阻 gnd 出轨封顶高层进线（三件同构）

v20 三件的输入端接电阻（drv1 Rin1/Rin2 1000Ω、drv2 Rin1/Rin2 1000Ω+Rb1/Rb2、mix 同族）其一端接输入焊盘（M1，y[5,8]），另一端（gnd）出脚从**焊盘正上方 x 带**以 M1→M4 堆叠过孔垂直上引至 gnd M4 干路（drv1 GND_Y=82 / drv2 GND_Y=100，gen 源码 `GND_Y` 常量）。gnd 出轨 x 带 = 焊盘 x 带（±0.15µm）：
- **信号网高层进线（M3/M4/M5/TM1 任一层）在此 x 带内 y≥9.56（drv1）/y≥9.56（drv2）全部被封**；
- M4 轨顶与 gnd 干路同层搭接 2µm 属**合法同网**（Rin.P2=gnd），非缺陷——已核实（源码 + 布局并集），**无 LVS 风险，勿入判读预期**；
- 影响：M4 v2 信号进线不能走 M3 以上直达焊盘；**M2 是唯一净空进线层**（drv1/drv2 岛内低空 M2 实测零占用——guard 竖条在 x∓76 之外的岛缘，不挡岛内）。
- 此结构系核内设计（v13 以来如此），**非 v20 回改引入**；若未来要高层进线，需 v21 核改（Rin.P2 出轨改道或焊盘区扩双焊盘）——挂候改清单备选，不阻塞 v2。

## 4. 通道 1 方案（mix.rfop/rfon → drv1.inp/inn）

**层链：TM1（mix 顶出带）→ 通道 1 空地下钻 via_stack(TM1→M2) → M2 横进 drv1 岛 → via1 落柱焊盘。**

- **mix 顶出线带**（cell 系 y[238.1,241.1]，宽 3µm，顶层 y[245.41,248.41]）：TM1 层。避让：下方 rhigh13 body 顶 237.09（间隙 1.01）、六根立管顶 235（间隙 3.1）、转接孔 242.65（间隙 1.55）；上方 nbiasH TM1 底 242.96（间隙 1.86）。窗口紧但全为正间隙——**候组长确认 TM1 对 body/label 的净距口径**（幻影焊规避按「不覆盖」已满足；若组长要求 ≥2µm 金属-体间隙则此带不可用，需回 §6-③）。
- **通道 1 竖穿段**：x165/x172（顶层）双竖线（TM1→通道下钻点），间距 7µm。
- **同层交叉问题**：rfop 横段（x59.67→x165）与 rfon 横段（x99.67→x172）同带重叠 x[99.67,165] = 短路。**候选解**：
  - ①（推荐）**TM2 翻越段**：rfon 在 x[150,166] 段升 TM2（TM1→TM2→TM1 两处转接 via；该带 TM2 实测空——mix TM2 仅 nbiasL 竖条 x[97.85,99.85]/[139.85,141.85] y[250.27,272.26] 与 y[244.8,248.4] 带不重叠），跨过 rfop 下拐竖线；
  - ② rfon 绕 mix 岛北缘：出带后右行至 x>114.67（nbiasH TM1 横条右缘）上拐 y>250 高带走行再下行——路径长、与 nbiasH/nbiasL 走带挤，不推荐；
  - ③ rfop 改走通道 1 南缘低空（y<16 TM1 空）从 mix 右缘 y5~10 出——但 rfop 立管在 y235，岛内下行必穿核区，**不可行**（否决备查）。
- **drv1 岛内进线**：M2 横段 y[7.31,10.31]（与焊盘同高带）从岛缘 x185.2 到落柱点：M2 实测全空 ✓；落柱 via1（M1-M2）中心 (205.2,8.81)/(212.2,8.81)，M1 底板罩 0.3µm 焊盘、板宽按 via 规则 ~1.6µm——下方 M1 仅焊盘本体 ✓，上方 M3+ 无图形 ✓（gnd M4 轨 y84.31 起——不同层 ✓）。
- rfop→inp / rfon→inn 同侧配对，无交叉。

## 5. 通道 2 方案（drv1.cop/con → drv2.inp/inn）

**层链：cop/con 上方下钻 via_stack(M1→M4) → M4 横穿条带区上空 → drv2 岛 M4 进线 y[16,19] 带 → via 链(M4→M1) 落柱。**

- **drv1 侧下钻**：cop (228.2,168.31)/con (266.2,168.31) 上方 M2~TM1 实测净空 ✓；下钻链 M1→M4（3 段 via）落 M1 横条（10µm 宽，载流充裕）。出线绕行：vcc TM1 竖条（x顶层 232.38~233.98 / 260.38~261.98，y[164.44,202]+2.31）贴 cop/con 内端——**M4 层无此障碍**（竖条是 TM1），M4 出线直行 y168.31 向右即可。
- **M4 横穿条带区上空**（x303.2~612.84）：cmim 真件占 M5+TM1（介电上下板），**M4 在其下不受限** ✓；条带区 y 全高 M4 实测零占用（drv1 M4 仅 gnd 干路 y82.31~86.31 + 双短桩 x251.05/285.05——y[82,108] 与 y168 带不重叠）✓。
- **drv2 岛进线**：M4 横段 y[16,19]（焊盘同高带）从岛缘 x612.84 到落柱点：**风险点——gnd M4 出轨 x[647.69,647.99] y[20.56,111] 与进线横段 y[16,19] 同层净距 1.56µm** ⚠。若 M4.minSpace>1.56 则进线需微降 y[16,18.5] 或右移落柱；inn 同（x[654.69,654.99] 同轨）。落柱链 M4→M3→M2→M1 中心 (647.84,17.5)/(654.84,17.5)。
- 替代层链（若 M4 净距不合规）：通道 2 全程降 M3（drv2 岛内 M3 仅 x34/41 竖条 y[10,54]，远）——M3→M2→M1 落柱，绕开 gnd M4 轨。**候组长裁主/备**。
