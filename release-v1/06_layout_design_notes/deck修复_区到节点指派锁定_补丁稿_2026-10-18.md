## 〇 一句话

deck 现状 bug = 端子识别区取 **body 级 covering bbox**（npn13G2_dev=covering(e/b/c)，npn13G2_b=dev−c_pin≈整 body）→ 骑体金属落入即整域拽进端子节点。修复 = **识别区按定律 v2 真值收紧 + cont 落点门**，三通道（E/C/B）各自锁定：

```
E 通道 = 域 ∩ emwind 窗列 ≠ ∅（无需 cont）                      ← connect(emwind_drw, metal1_con) 原语义保持
C 通道 = 域 ∩ c_pin 带 ≠ ∅ ∧ 域内 collector cont 落点数 ≥ 1
B 通道 = 域 ∩ (b_pin 带 ∨ body 矩形) ≠ ∅ ∧ 域内 base cont 落点数 ≥ 1
```

## 二、补丁逻辑（伪 Ruby，对应 bjt_derivations.lvs L59 一带的改写）

```ruby
# ── BEFORE（bug 语义）─────────────────────────────────────
# npn13G2_dev   = poly.select(...).extents            # body covering bbox
# npn13G2_c     = dev & c_pin_layer                   # c_pin 图形层（宽）
# npn13G2_b     = dev - c_pin_layer                   # ≈ 整 body（宽）← 幻影焊根源
# npn13G2_e     = dev & e_pin_layer                   # e_pin 图形层（宽）

# ── AFTER（定律 v2：识别区=真值带，域级指派加 cont 门）─────
te = emwind_drw            # (61,0)? emwind 窗层——以 deck 现有 layer 引用为准
te_band  = te.extents      # 每指 ±0.035 × y −0.45..+0.45（不必重建，直接用窗层）
tc_band  = c_pin_layer.extents & box(y: 0.98..1.28)   # c_pin 带
tb_band  = b_pin_layer.extents & box(y: -2.43..-0.62) # b_pin 带
body_band= dev.extents     # body 全矩形（只作 B 通道 OR 项，见 L59 原语义保留但加门）

cont_c = cont_drw & box(y:  1.05..1.21)   # collector cont 孔带
cont_b = cont_drw & box(y: -1.22..-1.06)  # base cont 孔带

# 端子识别（域级）：
npn13G2_e = metal1_con.select { |d| d.interacting?(te_band).any? }  # E：骑窗即焊，无 cont
# C：骑 c_pin 带 ∧ 域内(并集)含 ≥1 collector cont
npn13G2_c = metal1_con.select { |d| d.interacting?(tc_band).any? && d.interacting?(cont_c).any? }
# B：骑 b_pin 带 ∨ body 带 ∧ 域内含 ≥1 base cont
npn13G2_b = metal1_con.select { |d| (d.interacting?(tb_band).any? || d.interacting?(body_band).any?) && d.interacting?(cont_b).any? }
```

要点（与现行实现的差异清单）：
1. **识别面从 body bbox 收紧为三带**：E=te 带、C=tc 带、B=tb 带∨body（body 仅 B 通道保留——判 4 裁决 tb 参与 base，但 cont 门挡住「无孔骑带」误焊）。
2. **C/B 加 cont 落点门**：「骑带≠焊」实证（★判例：正常 E 指 M1 底缘骑 b_pin 带 0.165µm 不焊）⇒ 域内无对应 cont 孔不得焊。
3. **E 通道不加 cont 门**：connect(emwind_drw, metal1_con) 原语义（dump 证 cont∩e_pin=0）。
4. **域级指派语义不变**：仍是域命中即整域拽入（幻影焊的「域横跨」机制由识别区收紧自然消解——大域骑窗仍会焊，**这是 deck 的固有语义**；修复目标=「该焊的焊、不该焊的不焊」，不是消灭大域）。若要连大域横跨也防，需第二层「域分割」——**不在本补丁范围**（会改变 LVS 语义，须另裁）。
5. **ptap_holes 同源修正**（npn_mk=trans∩ptap_holes）：主管 ptap_holes 现为 0 ⇒ npn_mk 恒空 ⇒ 主管不识别。修正 = ptap_holes 收集或 npn_mk 判定改为 `trans ∧ (ptap_holes ∨ body_band)`（与 B 通道同口径），或 ptap_holes 层引用按 PDK 实际补齐——两者组长侧二选一，几何效果等价：主管不再因 ptap 缺失而漏识。
