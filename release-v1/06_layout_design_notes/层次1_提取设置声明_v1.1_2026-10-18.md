## 3. 连通域与网名

- **连通域**：每金属层 unary_union → 连通域；via 连接=孔中心落域内 → 连上下两层域（union-find）。
- **网名**：datatype 25 文本落域；多网名同域如实双名（如 XBI/nref|gnd）。
- **网名优选策略**（裁定①②，终裁口径不变）：
  - **mix（revised 模式）**：映射名只作归一参与计数，候选=无映射原名，取域内器件 dnode 挂靠计数最大者；并列时专用网（ntaila/nsens 类）优先于全局网（gnd/vdd 类）。
  - **drv1/drv2（legacy 模式）**：映射名优先（XBI*/nref→nref 优先于原名）；无映射名时取列表首项。
  - **同函数同策略**：cdl 与 R 分段网同函数（`_resolve_net`）同策略，禁止两套（裁定②）。
- **异常留痕**（裁定③）：域内原名数≥2 加 WARNING merged-domain 头行 —— **本版三件 0 条**（v20/v28 修复闭环实证）。

## 4. 层次 1 金属 R 口径（tier-1，bbox 近似 · 保守）

- **逐段 R**：`R = RSH[layer] × L / W`，L/W 取域 bbox 长/短边（凸正交近似；L 形真实路径偏长 → 低估，视为保守下界；周长法上界未启用）。
- **RSH target**（PDK 官方表，已入链）：M1 0.110 / M2~M5 0.088 / TOPM1 0.018 / TOPM2 0.011 Ω/□。
- **via 并联**：`R_via = R_typ / n_vias`（n_vias 缺省按 VIA_PADS 估计；VIA1-4=50 pads，TOPVIA1/2=1 pad）。
- **via typ**（PDK 官方表）：VIA1-4 9.0 / TOPVIA1 2.2 / TOPVIA2 1.1 Ω/只。
- **锚点最短路**：以 M1 为锚，域级图 BFS（边=via 连接，权重=层间 via 典型电阻），累计 R_cumulative。
- **局限**：bbox 口径对 L 形/蛇形金属低估真实路径电阻；via 数按估计非逐只计数；未含寄生电容（tier-1 R-only）。
- **轮间变化监测（v1.1 正式启用）**：**不设硬闸值**（定位 = 版图迭代参照 + 联仿 sanity，不入门）；每轮重提后对四类关键网（**E 回流 / gnd 主干 / ntaila / vcc 馈电**）的 R_cumulative 做轮间对比，变化 **>20%** 或 **量级跳变（×10）** → 报组长复核；其余网不监测。工具 = `monitor_baseline`（skills/monitor_baseline.py）；首条基线 = v20/v28 三件（`轮间监测基线_v20v28_2026-10-18.json`）。首基线快照：drv1 gnd 2.70Ω/vcc 8.32Ω/e1·e2 0.18Ω；drv2 gnd 6.66Ω/vcc 20.66Ω/e1·e2 0.18Ω；mix gnd 7.74Ω/e1a~e2b 0.18Ω（ntaila 于 mix 并入 gnd 主干域计 0——独立网未单列，下版核）。
