## 二、根因复述（为什么是「加 tap」而不是「改线」）

组长定谳的三块对照表里，**只有 drv1 的 `40/0 substrate_drw` = 0、`ptap1` 实例 = 0**：

| 块 | `40/0` | `ptap1` | 衬底 |
|---|---|---|---|
| mix v29 | 16 | 有 | 已接地 |
| drv2 v20 | 16 | 有（6） | 已接地 |
| **drv1 v20** | **0** | **0** | **XQo/XQr 岛浮空** |

`pwell_allowed = CHIP.not(pwell_block)` 被 `npn_exclude`（trans_drw / res_drw / salblock_drw…）
切成多岛，**每岛各自需要接地通路**。drv1 的四只 HBT + 九只电阻衬底端子同挂孤立网 `$1`
（E0 实测 8M/8X）。

**为什么 §7 的 E 脚下引救不了它**：§7 把 E 脚（M2）经 via_stack 拉到 M4 gnd 干线，
但那只是**金属**的接通；deck 的接地链是
`pwell ─connect(pwell,ptap)─ ptap=pactiv∩pwell ─cont_drw─ metal1_con─ M1`，
缺了 **ptap 接触**这一环，浮空岛照样浮空。Q2/Q3 所在岛之所以接地，靠的是 npn13G2
**PCell 自带**的 pwell/ptap 图形恰好与该岛连通；drv1 这两只管的岛没有这条路。

## 三、落点与选点依据

| 岛 | 器件 | tap 落点 | 到管身 | 到 ntail 禁区板 | 到最近异处 M1 |
|---|---|---|---|---|---|
| XQo | `XBI_XQo` Nx=8，管身 x∈[−7.45,+7.45] | **(14.0, 100.0)** | 出管身 6.55µm | 21.0µm | **16.649µm** |
| XQr | `XBI_XQr` Nx=1，管身 x∈[33.05,34.95] | **(42.0, 100.0)** | 出管身 7.05µm | 21.0µm | **9.553µm** |

选点三原则（逐条对真值核过，非拍脑袋）：

1. **禁区零距离** — y=100 距 ntail 汇集板下沿 121 有 21µm。
   E3 实测 ptap 落 (−39.5,127.6) ⇒ `gnd–ntail` 短路，本件不重蹈。
2. **不落 HBT 排除区、且同属该 pwell 岛** — y∈[86,126] 带内我逐层点过
   （顶层自画 M1/M2/M3/M4/M5 + 全部嵌套实例）：x∈[8,20] 与 x∈[36,48] 两块**全空**，
   且其间无任何 `npn_exclude` 图形。两点都落在两只管**同一片 pwell** 内，
   一只 tap 即足以把该岛接出去；放两只是为了对冲「万一被切成两岛」。
3. **柱下中空层无异网** — 走 `cross()` 的 **M1→M4 单 via_stack**，焊盘只在两端层，
   M2/M3 不留盘。nref 的 M3 立管在 x=0 与 x=34，本件落点 x=14/42 远在两处之外。

## 四、gnd 接入的 via 链证据（逐环 bbox 实测，非声明）

deck 的接地链一环不缺：

```
pwell ──[ptap1 PCell: 1/0 Activ + 14/0 pSD + 4×6/0 cont + 40/0 substrate_drw]──
      ──cont_drw↔metal1_con── 8/0 M1 垫 ──via_stack── M4 立管 ──同层相接── M4 gnd 干线
```

本机实测（仿真层逐环 dump）：

| 环 | XQo 岛 | XQr 岛 |
|---|---|---|
| ① M1 接地垫 | `DBox(13.600, 99.600, 14.400, 100.400)` | `DBox(41.600, 99.600, 42.400, 100.400)` |
| ② via_stack 实例 | `DTrans(d=(14,100))` ✓ 在图 | `DTrans(d=(42,100))` ✓ 在图 |
| ③ M4 立管 | `DBox(13.850, 82.000, 14.150, 100.000)` | `DBox(41.850, 82.000, 42.150, 100.000)` |
| ④ 与干线相接 | 干线 `DBox(−56,80,56,84)`，立管 y=82 起 ⇒ **重叠 2µm** | 同左 |
| ⑤ 网名标注 | M4 `labels(8/25)` = `gnd` | 同左 |

> **环① 的形状说明**：本机仿真层不建 `ptap1` PCell（塞假体会污染间距判定），
> 故我在**仅仿真层**补了 0.80µm 见方的 M1 替身，好让自检台第⑳项能验完整条链。
> **真跑不进 GDS** —— 真几何由 ptap1 自带的 `8/0 M1 tie` 承担（那才是 PDK 的正规图形）。
> 代码里以 `_SIM_ONLY_TIE` + `PTAP_SKIPPED` 一行 NOTES 明示，不靠注释暗示。

## 五、自检断言「每块每岛均有接地 tap」（交办：零断言即停线）

本机跑不了 deck 的 pwell 连通域分析，所以断言**不落在「连通域」这种跑不动的判据上**，
而落在五条**可证伪的几何事实上**。任一条为假即 `AssertionError` 停线：

| # | 断言 | 判据 |
|---|---|---|
| ① | tap 在「能下引到 gnd 干线、又没进禁区」的区间里 | `−56 ≤ x ≤ 56`（干线跨度） ∧ `GND_Y ≤ y ≤ NT_Y0` |
| ② | tap 处**有 M1 接地垫** | 顶层 M1 形状命中 `(x,y)` |
| ③ | tap 处**有 via_stack 实例** | 实例原点逐位命中 `(x,y)` |
| ④ | tap 处**有 M4 立管**，且立管**真压** gnd 干线 | 两条独立 bbox 命中判定 |
| ⑤ | **禁区内零 tap** | 不落 `M1(−39,121)-(39,136)` |

**有牙验证**（在临时副本上做故意破坏，断言逐条当场抓住）：

| 破坏动作 | 断言反应 |
|---|---|
| `XQr` 的 y 改 100 → **125**（落进禁区） | `AssertionError: TAP-ASSERT ①：XQr 的 tap y=125.0 不在 (GND_Y=82.0, NT_Y0=121.0) 下引区间内` |
| `XQr` 的 x 改 42 → **100**（超出干线跨度） | `AssertionError: TAP-ASSERT ①：XQr 的 tap x=100.0 在 gnd 干线跨度 [-56,56] 之外` |
| 删掉 `b.wire_v(GND_LAYER, …)`（接地链断在第三环） | `AssertionError: TAP-ASSERT ③：XQo 的 tap (14.0,100.0) 处没有 M4 立管金属` |

断言取图助手（`_inst_origins` / `_iter_shapes`）**仿真层与真 KLayout 双通**
（仿真层 `Trans.dx/dy` vs 真 KLayout `DTrans.x/y` 都取）——
写死仿真层 API 会让组长的真 KLayout 代跑当场 `AttributeError` 停线。
