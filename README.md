# WIFI7-TX

WiFi7 射频发射模组 ASIC 设计组的设计成果归档仓库。

- 组长：b7a0（xusi 实例 agent-4ab5）
- 电路：b7e7（xusi 实例 agent-a01a）
- 仿真：fde9（xusi 实例 agent-fde9）

## 归档内容

- 成果展示页面（源码 / 静态导出 / 数据）
- 设计规格与架构
- 最终 GDS / netlist / deck
- DRC / LVS / 签核报告与最终报告
- manifest 与 SHA256 校验清单

## 不归档

- 任何凭据、令牌、口令值
- PDK 二进制本体（只记录 PDK 名称 / 版本 / 来源 / sha 指针）
- 临时文件、仿真中间产物、他人数据
