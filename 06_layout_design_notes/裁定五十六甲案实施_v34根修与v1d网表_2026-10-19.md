# 裁定五十六甲案实施：v34 根修 + v1d 网表（b7e7 · 2026-10-19）

## 一、选型结论（裁定五十六 §四①）

**选甲案（改版图真拆）**，理由三条：

1. **丙案前提被推翻**：我上口（裁定五十五）拿 M1 单层尺量出「v31 两域分离、净距 1.8250 µm」，
   推论「并网是 `_resolve_net` 配名产物」。但组长裁定五十六 §三·4 用真 KLayout 精确布尔坐实：
   **短路不在 M1，在 Activ（1/0）器件扩散块重叠 2.6250 µm²**。我用 `probe_activ_b7e7.py`
   独立复现，**逐位一致**（XBI1 −2.6250 µm / XBI2 +10.7250 µm）。⇒ 我的 M1 尺读数没错，
   但**量错了层**：M1 上确实两域分离，但 Activ 层同一域同时挂着 XBI1/nref 与 ntaila 的 Cont
   （Cont@(-32.000,31.13)→M1域3→XBI1/nref；Cont@(-28.325,31.13)→M1域0→ntaila；
   两 Cont 同属 Activ域22）。⇒ 并网是**真实短路**，不是配名产物。
2. **乙案组长不倾向**（裁定五十六 §四①「ntaila 短接缺陷在版图上长期挂着」）。
3. **甲案是真修**：把 XBI1 组 Activ 重叠拆干净，与 XBI2 组逐位同构（官方 DRC 零 Activ 条的几何）。

## 二、v34 甲案实施（单一动作）

**gen_M2_mix_v34.py** 相对 v33 的变更（diff 122 行，核心 1 行）：

```python
# v33：QR_L, QR_R, RF_OFF = 12.0, 25.35, 8.0    # 不对称
# v34：QR_OFF, RF_OFF = 25.35, 8.0              # 两侧同一值 = 真镜像
```

**为什么不用「最小位移」**（14.625+0.63=15.255 就够）：
- PDK 的 Activ 适用净距**本机查不到**（/data/pdk 不在，.lyt/drc deck 都没有）。
- 与其赌一个查不到的值，不如取**与 XBI2 完全相同的几何**（+10.725 µm）——那一面零 Activ DRC 条目。
- 这就是选型理由，写在文件里备审（裁定五十六 §四·1「最终值必须过 DRC 的 Activ 净距」）。

**依赖链联动**（gen_mirror_group 内一律用器件**自报引脚坐标**，无手抄坐标）：
- qr_x / rf_x / nref 走线 / cb_tie 逃逸列 / nvtop 出脚全部随 QR_OFF 参数联动。
- XBI1_Rref 的 P1 补标从器件自报引脚取（v33 是手抄坐标 −40.00，v34 改成导出）。

## 三、actgeom.py（Activ 足迹真值表）

**为什么另起一张表**（不塞进 hbtgeom.py）：
- `hbtgeom.py` 管 M1 带金属半宽（QR_L 律量的东西）。
- 裁定五十六 §三·4 坐实的短接**不在 M1**，在**器件 Activ 足迹**。
- 量它的尺是 Activ，不是 M1 ⇒ 口径不同，表也分开。

**实测律**（官方 GDS m2_mix_v31.gds 直读，gdstk 1.0.1 展平 + shapely 精确布尔）：

| nx | 实测 w(µm) | 律 w=1.85·nx+4.45 | 验证 |
|---|---|---|---|
| 1 | 6.300 | 6.300 | ✓（XBI1/XBI2 XQr） |
| 3 | 10.000 | 10.000 | ✓（4 只 gm） |
| 6 | 15.550 | 15.550 | ✓（XQ3..XQ6） |
| 10 | 22.950 | 22.950 | ✓（XBI1/XBI2 XQo） |

⇒ **ACTIV_FRAME_W(nx) = 1.85·nx + 4.45**，中心对称。
⇒ 实例变换原点不是器件中心：`disp.x = center_x − (nx−1)·1.85/2`
  （nx=10 ⇒ −8.325，这就是官方表里 `npn13G2$1 disp=−28.325` 而器件中心是 −20.0 的原因；
   **别拿 disp 当中心算间距**，会差 8.325µm）。

**摆位净距口径**（ACTIV_PLACING_SPACING_UM = 0.63 µm）：
- **自设保守项**（与 M1 摆位同一档），**不是** PDK 适用值。
- PDK 的 DRC deck 不在本机，无法查 Activ 净距的适用值 —— 这是证据边界。
- 经验锚：官方 DRC 在 mix v31 上只报 2 条 M1.b，**零 Activ 条**；而 v31 的 XBI2 组
  同类 Activ 间隙是 **+10.725µm**。故「与 XBI2 同几何」= 已过官方 DRC 的几何。

**⑮ 中心距 17.03µm 的口径说明**（避免与 actgeom 的 25.35µm 打架）：
- ⑮ 用**理想带矩形**（hbtgeom.py 的 B 带半宽 + 实例原点 disp），中心距 = |disp_a − disp_b|。
- actgeom 用**真 Activ 几何中心**（gdstk 展平 + shapely 布尔），中心距 = |center_a − center_b|。
- 两者差 8.325µm 正是 nx=10 的原点偏移（actgeom 头已警告「别拿 disp 当中心」）。
- **⑮ 量不到 Activ 足迹**（理想带矩形 ⊂ Activ 框），所以 v31 真重叠时 ⑮ 也 PASS——
  这正是 check_layout_gen 描述里写的已知盲区，必须靠 gen 侧 `_activ_gap_assert` 兜底。

### 4.2 _activ_gap_assert（gen 内断言，v34 新增）

```python
def _activ_gap_assert():
    import actgeom as _ag
    need = _ag.min_center_gap(10, 1)  # = 15.255 µm
    for side, gx in ((-1, CX - 20.0), (+1, CX + 20.0)):
        qr_x = gx + side * QR_OFF
        gap = _ag.frame_gap(gx, 10, qr_x, 1)
        assert gap > 0, f"XBI{1 if side<0 else 2} 组 Activ 框**重叠** {gap:+.4f}µm"
        assert gap >= _ag.ACTIV_PLACING_SPACING_UM, \
            f"XBI{1 if side<0 else 2} 组 Activ 净距 {gap:+.4f} < 自设保守项 {_ag.ACTIV_PLACING_SPACING_UM}"
```

## 五、v1d 网表（v34 配套）

**mix_subckt_LVS输入_v1d.sp** 相对 v1c 的变更（**只改端口名与 XBI1 簇的三处网名，拓扑一字未动**）：

① 端口集合 7 → **8**：
   v1c 端口第 1 项是 **`XBI1/nref|ntaila`** —— 那是官方提取器把两个网**并成一个**
   之后给出的网名（`|` 是它的并网写法）。本轮甲案把并网拆掉，版图应当导出
   **`XBI1/nref`** 与 **`ntaila`** 两个独立端口 ⇒ v1d 按 8 端口写。
   ⚠ 这是**预期**，不是既成事实：拆分后的端口名以官方跑出来的那份为准。
     若官方仍给 `XBI1/nref|ntaila`（并网仍在），本件会在 XBI1 簇上失配 ——
     那就说明**器件重叠没拆干净**，而不是网表写错。失配范围可预期地局限在
     QXBI1_XQo / QXBI1_XQr / RXBI1_Rref 三只 + 两条尾阻 Re1a/Re2a。

② XBI1 簇网名按**设计意图**写（与 v1c 的 `nrefa` 同一拓扑，只是改成真端口名）：
     QXBI1_XQo : C=ntaila   B=XBI1/nref  E=gnd
     QXBI1_XQr : C=XBI1/nref B=XBI1/nref E=gnd
     RXBI1_Rref: nvtop  XBI1/nref
     RRe1a/RRe2a: e1a/e2a → ntaila
   —— 这正是版图 NET_DECL 声明的拓扑（gen_M2_mix_v34.py 里 XBI1_XQo 一行
   `("ntaila", hnet("XBI1","nref"), "0")`），也是 v29 之前的老网表口径。

③ 版图真值锚换新面：m2_mix_v31.gds(ef034d51) → **m2_mix_v34.gds**（QR_OFF 25.35，
   XBI1 组 Activ 净距 −2.625 → **+10.725 µm**，与 XBI2 组逐位同构）。

## 九、本口教训（写给下口）

> **量连接层要从半导体层起算，不是从金属层**：M1 上两域分离 ≠ 电学分离；Activ 层
> 同一域同时挂着两条网的 Cont ⇒ 提取器并网。本口用 M1 尺量出「分离」，但量错了层；
> 组长用 Activ 尺量出「重叠」，才是真短路。**尺的层号要对准短路的层号。**
>
> **disp 不是中心**：nx=10 的实例原点偏移 −8.325µm（actgeom 头已警告），拿 disp
> 当中心算间距会差 8.325µm。⑮ 用 disp 口径报「中心距 17.03」，actgeom 用真几何中心
> 报「25.35」——两套数不矛盾，口径不同。写报告时把口径写清楚，别让下一个人读两套数打架。
>
> **check_layout_gen 的 ⑮ 量不到 Activ 足迹**：理想带矩形 ⊂ Activ 框，所以 v31 真重叠
> 时 ⑮ 也 PASS。这是已知盲区（check_layout_gen 描述里写了），必须靠 gen 侧
> `_activ_gap_assert` 兜底。v34 已加，check_layout_gen ok=true 即证它在仿真层真跑 PASS。
