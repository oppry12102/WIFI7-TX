# tank −7.714% 三判据实验报告：官方全链路=参数口径，H1 成立，H2 数学不可行

b7e7 · 2026-10-18 11:5xZ · 裁定三十五 §二 交办件（三判据实验）

## 〇、结论先行

1. **三判据全部指向 H1（参数口径）**：官方 PCell 几何、模型卡、LVS 提取器三层证据一致——cmim 的官方电容口径是**用户参数 w&l（=MIM 层 36/0 全尺寸）**，非上板交叠净区。w=23.66 模型真值 **843.479 fF（vs 840 名义 +0.41%，良性）**。
2. **−7.714% 是自研提取器口径伪影**：775.202 fF 系把规格密度套在**上板交叠净区**（22.68²）上的估算口径；官方任何工具都不产这个数。
3. **「0.98 内缩」不是线性规则**：上板宽 = via 阵列量化值 `1.26·floor((w+0.12)/1.26+ε)`（xanz 只取整数档）。w=23.66 档内缩恰 0.98 是**巧合**；w=24.591 档内缩变 0.651。判据③问的线性性外推：**不成立，不可外推**。
4. **H2 数学不可行（新证据）**：交叠口径下 C 只能取 1.26 µm 档位值——n=18→775.20（−7.71%）、n=19→863.52（+2.80%），**840 fF 无档可达**。A 案及其变体（含 +0.98 回加）在交叠口径下永远落不进规格。
5. **H1 的 gen v30 影响面极小**：w 23.66→23.6110 后 xanz 仍=18，上板/下板 GDS **零变化**；仅 MIM 层框缩 0.049 µm + label 数值变。选型公式补周边项 `1.5w²+0.16w=840 → w=23.611046` 精确回 840.000。

## 四、H2 不可行证明（交叠口径量化档位）

| 档 n | s（µm） | C（fF） | vs 840 |
|---|---|---|---|
| 17 | 21.42 | 691.65 | −148.35 |
| **18** | **22.68** | **775.20** | **−64.80（−7.71%）** |
| 19 | 23.94 | 863.52 | +23.52（+2.80%） |
| 20 | 25.20 | 956.59 | +116.59 |

840 落在 n=18/19 之间的空档，**任何 w 都无法使交叠口径=840**。H2（含 A 案 +0.98 回加变体——24.591 实际内缩 0.651、交叠 23.94、提取 863.52 ≠ 840）在数学上不可达。

## 五、判据实验对处置预案的落点（候组长落槌）

1. **H1 成立 ⇒ tank 规格偏离销案**：官方口径链（规格→模型卡→LVS→PCell 显示）全为参数口径，w=23.66 真值 843.479（+0.41%）；775.202 系自研提取器口径伪影。
2. **pex_extract.py cmim 段口径声明**（H1 预案原文）：建议措辞——「c_ff 系上板交叠净区估算（真实平行板重叠面），器件真值以参数 w&l 模型口径为准（×1.5 fF/µm²+40 aF/µm·周长）；两者差随 via 量化档位变化，w=23.66 档恒为 0.98 位移项」。
3. **gen v30 选型公式补周边项**（H1 预案原文，候裁）：`1.5w²+0.16w=840 → w=23.611046`；**GDS 上板/下板零变化**（xanz=18 不变），仅 MIM 层框 23.66→23.611（缩 0.049）+ label 数值——影响面极小，混净空地图/走线无扰动。
4. deck Ct=0.84p 不动；双计剔除照旧；门2 档乙 A0″=775.2018 fF（fde9 侧已裁）不回流——注意 A0″ 用的是提取实物值，若组长认 H1，门2 是否改用模型口径值 843.479 请一并裁定（个人建议：门2 档乙维持 A0″ 提取值不动，它测的是「提取器与版图的一致性」不是规格符合性）。

## 七、Appendix：本侧复现脚本（全部数值可一键复算）

def cmodel(w, cj=1.5, cjsw=0.04): return cj*w*w + cjsw*4*w      # fF（正方形）
xanz = lambda w: int((w + 0.12)/1.26 + 0.001)                    # via 阵列档位
top  = lambda w: xanz(w)*1.26                                    # 上板宽（量化）
assert abs(cmodel(23.66) - 843.479) < 1e-2                       # 判据②参数口径
