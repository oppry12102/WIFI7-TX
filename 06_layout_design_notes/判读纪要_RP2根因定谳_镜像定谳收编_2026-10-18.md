## 一、R P2 断路根因定谳（第五受害面收口）

- **机制**：emitpath P2 引脚距公式 `y_p2 = y_p1 + 1.56` 只对 rppd 档成立（GDS 逐位实测：rppd=1.56 / rsil=1.40）；rsil 件 stub 从公式点起画 → 悬在焊盘顶上方 **0.03µm**，同层无 via 跨接 → 直流断路。
- **调用序佐证**：place_emit_chain（画 stub）先于 mkres（放 PCell），`Re.p["P2"]` 真值从未回填——**公式锚定，非 enclose 漏算**（与上口疑点③「gen 电阻出脚漏算?」对上：是引脚距档位错，更precise的答案）。
- **修法（v20）**：先 mkres 后 place_emit_chain，stub 从 pin 真值锚定 + 断言 |公式−真值|<0.005 防回归。
- 与 E 回流 0.085µm 缝**同族不同根因**（同＝emitpath 预估偏差型断路；异＝0.085 是 via 焊盘 enclose 认知差、v19 已修；0.03 是 P2 引脚距档位错、进 v20）。
- **普查定谳：受害面＝Re1/Re2 ×2 件共 4 条，显形即全部**（mix 不走 emitpath 从 pin 真值画线＝天然免疫，反向印证；Rin/Rb/RL/mix 其余全连通）。

## 二、裁定十六：drv2 v3 网表 RRin 化石回改案

- **案情**：drv2 LVS 输入 v3 两行 `RRin1 inp XBI1/nref` / `RRin2 inn XBI2/nref` ＝ 真短并域化石——版图真值 Rin P2 接 gnd 轨（gen §7 cross+M4 直下，有意画到地）；并域时代 cdl 提取名 nref＝nref|gnd 同域呈现，v3 把并域名烙进了原理图。v1 原稿 `inp 0`（端接到地）＝设计意图正确。
- **裁定：批准回改，时机绑定 v20**——
  1. **现役 v3 不动**（v18/v19 并域现实下对拍自洽；v20 前擅动＝破坏对拍基准一致性）。
  2. **v20 GDS 到货同批出 drv2 sch v4**：两行回改 `inp 0`；LVS 标准输入对升「**v20 GDS + v4 sch**」。
  3. **随件证据三件套**：①v1→v3 两行演化对照（证 v3＝化石非新意图）；②v3 全量并域化石普查（涉 nref/并域名呈现的行全列，预期仅此两行）；③电路意图注记一行（Rin 端接＝gnd 设计依据：v1 原稿引文 + spec 对应节）。
  4. **drv1 侧核对**现役 sch 该两行当前值，随件声明（v1 已是 inp 0 则声明即毕；若 v3 也动过则同批修）。
  5. **sim 侧不受影响**：pex 提取件（验收锚三件）Rin P2 网名 nref→gnd 归位、Re P2 接上 ntail、真短 8 案断开——全部列入 **v20 重提判读预期（预期修复项）**，非判据器故障；A0→E 链与六判据不动。
- **理由**：原理图是对拍基准，基准回改必须全链路留痕；「原理图迁就版图」仅限**化石订正（恢复 v1 意图）**，不得引入新语义。
