## 一、方法上的三个坑（**初版结论作废的教训，记在此处**）

1. **`nx` 参数大小写两写**：前仿面用小写 `nx=`、PEX 面用大写 `Nx=`。
   正则若不 `re.I`，前仿 22/22 实例会全部误判成「无 Nx」——
   我第一版就踩了这个，得出的「前仿面零 nx 展开」结论**是错的，已作废**。
2. **`{nx}` 是子电路参数传递，不是常数**：前仿 `.subckt hbt_mirror … nx=8` 体内
   `XQo nout nref 0 0 npn13G2 nx={nx}` —— 每次实例化传参不同（`nx=8` / `nx=10` / 缺省 8）。
   按字面读会把它当成固定值。
3. **不展开 `hbt_mirror` 就比 nx，会把「封装 vs 展平」误读成「nx 面差」**：
   前仿把参考二极管封装在 `hbt_mirror` 子电路里（**9 处调用**），
   PEX 把其中 **7 处展平**成显式 `npn13G2` 对，只留 `lo_buf` 的 2 处（**PEX 仅 2 处调用**）。
   **必须先展开再比。**

另：**实例名在两面之间被重排**（前仿 `XQ1a/XQ2a…` ↔ PEX `XQ1/XQ2…`），
按实例名对齐会错配；须按 (subckt, 四端节点, nx) 三元组对。

| subckt | 前仿 n/ΣNx | PEX n/ΣNx | Δ(n / ΣNx) |
|---|---|---|---|
| hbt_mirror | 2 / 1 | 2 / 1 | 0 / 0 |
| lo_buf | 9 / 31 | 9 / 31 | **0 / 0** |
| **gilbert_mix** | **13 / 59** | **15 / 65** | **+2 / +6** ← ★唯一有差 |

**结论（静态面，无仿真）**：

- 五个 `.subckt` 里 **四个的 nx 面逐子电路完全相同**（lo_buf / drv1 / drv2 / hbt_mirror）。
- **全部 nx 面差 = `gilbert_mix` 内 2 只三端全接地器件**：
  `XQ5 gnd gnd gnd 0 npn13G2 Nx=3` 与 `XQ6 gnd gnd gnd 0 npn13G2 Nx=3`（L199/L200），
  ΣNx=6，**前仿侧无对应物**（PEX 提取器的接地填充件）。
- 逐器件配对后，`front_only` 与 `pex_only` 的其余条目一一对应
  （`*ref*` 是前仿 `hbt_mirror` 私有内节点 `nref` 的占位名，PEX 把它拉平叫 `nref`），
  **nx 值全部相等**。
