## 二、阻塞项（双门跑不起来，两处）

### 阻塞 A：cdl 不是整个 `.subckt` 体的 drop-in 替换 —— **需裁口径**

cdl 只含 **L0 实物器件**（HBT/电阻/MIM）。deck subckt 里另有一批**按设计就不入 CDL** 的件：

| deck 内元件 | 类别 | 为何不在 cdl |
|---|---|---|
| `Bvbl`/`Bvbh`/`Bvifb`/`Bvt`/`Is0` | 行为偏置源 | cdl 规则 3「剥 V·Cin·Ct·Lt」 |
| `RL1/RL2` 45Ω tank、`Lt1/Lt2` 1nH | L1 备案理想件 | 立项书 §1 保真度 **L1 不实做**；`CDL格式纪律` §3.2「RL 与 tank L 均不入 CDL」 |
| `Cca1/2`、`Ccb1/2` 1nF | 片外耦合 | `CDL格式纪律` §3.1「删除此四件，以 PAD_IFP/PAD_IFN 片外耦合替代」 |
| `Rd1/Rd2` 10Ω、`Ct1/Ct2`、`XBI1/2` 理想源 | 已在 cdl 实物化或 L1 化 | cdl 规则 2「hbt_mirror 内联」 |

**实测后果**：整段替换后 mix 的 `nbiasL`/`nbiasH` 失去驱动 → `Warning: singular matrix:
check node xmi.nb2n` → gmin stepping 失败，tran 不收敛。**这不是模型错，是替换边界错。**

**请示裁一个口径**（三选一，我不自决）：
- **口径甲（推荐）**：cdl 只替换 **L0 器件行**，deck 的偏置源/tank/理想 Lt/PAD 耦合**逐字保留**
  ——与立项书 §1 L0/L1 分级、CDL纪律 §3.1/3.2 完全一致。实现：在 deck 体内按器件名白名单
  逐条替换（Q/R/C 实物器件），非 L0 行不动。
- **口径乙**：整段替换，另需 b7e7 补一份「理想件回填 cdl」（含 B 源与 Lt/RL），否则链不闭合。
- **口径丙**：先只跑 drv1+drv2（其 cdl 依赖的理想件较少），mix 待 deck 侧补件后再并入。

### 阻塞 B：cdl 器件行须 Q/R/C → X 行改写（技术性，已解决，待确认）

ngspice 对 `R n1 n2 <name>` **只查 `.model` 卡、不查同名子电路**；子电路只能用 `X` 实例化。
故 `m5_pex_substitute.py` 做两处**纯语法**改写（不改任何数值/拓扑）：
1. `Q1 c b e npn13G2 we=.. NX=.. M=.. sub=0` → `XQ1 c b e 0 npn13G2 we=.. Nx=..`
   （PDK 的 npn13G2 是四端 `.subckt c b e bn`；cdl 的 `sub=0` 即衬底端接 0，语义等价）
2. `R1 a b rsil l=.. w=..` → `XR1 a b rsil l=.. w=..`；`C` 同理 → `XC`

**请示确认**：这两处改写是否认可？（我认为属「不改口径的语法适配」，但既然动到正式件，
