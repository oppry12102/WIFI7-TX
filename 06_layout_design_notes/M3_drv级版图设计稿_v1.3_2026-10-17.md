## 0. 一句话

v1.1 只改了一行：`bb1` 的 M5 底段横线原来画到 `ch=24`，而回流竖管在 `x=50` ——
**差 8µm 没接上**，bb1 在版图上断成两截。岛尺寸、发射极回流核算、
器件数、阻值全部未变。

---

## 1. 勘误：bb1 断线

```python
# v1.1
b.wire_h(BIAS_LAYER, y_lo, min(px, ch), max(px, ch))   # y_lo=-2, px=42, ch=24
...
b.wire_v(BIAS_LAYER, 50.0, y_hi, y_lo)                 # 竖管在 x=50
```

几何结果（`inspect.py --shapes=M5` 实测 v1.1）：

```
x[ +24.00, +42.00] y[  -2.15,  -1.85] ['未标注']   ← 死头段（Rb2.P1 → x=24 就断了）
x[ +49.85, +50.15] y[  -2.00, +110.00] ['bb1']     ← 竖管在这一半
```

`bb1` 断成两截：`Rb2.P1 → 一条死头横线` 与 `x=50 竖管 → XQ2.B`。
**LVS 必失配**（一条网拆成两条）。

**为什么 v1.1 的 11 项自检没看见**：

- ⑤b「同名分裂」只数**带标注**的连通分量 —— `'bb1'` 只标了一处（M5 立管上 + B 脚上，
  都在连通的那一半），另一截**无标注**，于是断线隐形；
- ⑤c/⑤d 判的是短路，不管断线；
- ⑦「引脚↔网名」比的是 `DEV_NETS` **声明**，不验版图实际接到哪只脚。

## 2. v1.2 的改法

把该横段的终点改成**真正接得上竖管的那个 x**：

```python
land_x = ch if y_hi is None else 50.0
b.wire_h(BIAS_LAYER, y_lo, min(px, land_x), max(px, land_x))
```

- `bin`（`y_hi is None`）落点仍是 `ch=−24`，一根立管直通 B 脚 —— 行为不变；
- `bb1` 落点改成 `50.0`，与 `wire_v(50.0, y_hi, y_lo)` 的竖管同 x，接上。

复核：v1.2 的 M5 成员全部落在 `bb1` 一个连通分量内（含 x=42 的柱头焊盘）。
bin 路径不受影响（M5 y=4 的横段在 x≤35，bb1 的 y=−2 横段在 x∈[42,50]，两条不交叉）。

## 3. 为什么是新加的第 ⑫ 项抓到的

自检台新增「⑫ 引脚极性（几何取证）」：拿 PCell 真实引脚坐标 + 过孔感知连通分量，
验「网表给这个脚的网名」是否真在这一脚的连通分量上。它对本件报：

```
[FAIL] 引脚极性 Rb2.P1@42.00,8.00：网表该脚是 bb1，版图该脚所在连通分量上是「无标注」
```

即 `Rb2.P1` 那一侧的连通分量上根本没有 `bb1` 这个名字 → 断线。
同一条注入已进 `teeth_v11.py`（注入 8 那条同族的 Rd 接反，以及 drv1 自身的两条）。

## 追加（2026-10-17 07:5xZ）· Slt.c.M1 开槽方案（纪要 §4.2 真几何族最后一条）

**问题**：`Slt.c.M1` = 「M1 无开槽最大宽度 30µm」。drv2 的 ntail 汇流轨是一块
150 × 32.3µm 的 M1 大平面（x∈[−62,88]，y∈[117.7,150]），最窄边 32.3µm > 30µm → 违规。

**口径澄清**：组长纪要把它记成「150µm 宽」。DRC 里 `width` 取 bbox 的**最窄边**，
所以真正超限的是 32.3µm 那一侧。这一点在投信里一并问了（若 deck 实为「任一边 >
30 即违规」，则本方案还须沿 x 再切，请裁定）。

**方案**：**两条 16.15µm 的轨 + 右端 5µm 搭桥**（净槽宽 2.3µm）

| 件 | 形状 | 最窄边 | 判据 |
|---|---|---|---|
| 下轨 | x∈[−62,88], y∈[115.4,131.55] | 16.15 | <30 ✓ |
| 上轨 | x∈[−62,88], y∈[133.85,150] | 16.15 | <30 ✓ |
| 搭桥 | x∈[83,88], y∈[131.55,133.85] | 2.3 | <30 ✓ |

- **EM 一步不减**：2 × 16.15 = 32.3µm = 原 W_NT。ntail 29.28mA @ M1 的 1mA/µm
  ⇒ 仍 0.976 mA/µm（与开槽前同值，未拿 EM 换 DRC）。
- **为什么必须有搭桥**：槽横切一刀，平面断成两片 ⇒ 版图上 ntail 变成两个连通分量，
  LVS 判该网多段（自检台第 ⑤b 项「同名分裂」当场报）。搭桥在**右端 5µm**，
  远离左端的 Rin（x=−46/−39）与右侧的 Rb（x=35/42）的引脚列。
- **对上下行的影响**：镜像组 XQo.C 从下方 y≈109 上来、Re1/Re2.P2 从上方 y=172.56 下来，
  两者原本分别落在平面**下边**与**上边** —— 开槽后这两条接触路径**一字未改**
  （下轨下边仍在 115.4、上轨上边仍在 150）。整体下移 2.3µm 是槽宽的代价。
- **待代跑校准**：槽自身的最小宽/最小间距规则本机查不到（无 PDK）。2.3µm 是按
  「> M1 间距 0.18 且给电流留路」取的；若 deck 另有 `Slt.a`（槽宽下限）要求更大，
  按回执调。
