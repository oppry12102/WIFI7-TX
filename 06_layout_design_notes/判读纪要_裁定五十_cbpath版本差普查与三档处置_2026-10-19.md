## 一、两份 cbpath 的差异（逐行 diff，零歧义）

`diff -u verify/drv1_v21_run/cbpath.py(25190557) outbox_files/design/sow6/cbpath.py(074d7bea)`
⇒ **仅两处**：①注释块补 6 行（裁定 21.2 说明）；②`cb_tie()` 内 M1.e 自动退让判据段。

旧（25190557）：
```python
ey0 = min(e[1] for e in e_pads)       # 最靠近 B 带的 E 指底座下沿
gap = ey0 - (yb + w / 2)
if 0 <= gap < M1E_GAP:                # ← 只看 y 向净距，无条件退让
    yb_wire = ey0 - M1E_GAP - M1E_MARGIN - w / 2
```
新（074d7bea）：
```python
for e in e_pads:
    ov_x = min(seg_x1, e[2]) - max(seg_x0, e[0])   # 平行段 = x 投影交叠
    gap  = e[1] - (yb + w / 2)
    if 0 <= gap < M1E_GAP and w > M1E_PARW and ov_x > M1E_PARL:   # ← 补触发门
        yb_need = min(yb_need, e[1] - M1E_GAP - M1E_MARGIN - w / 2)
```
常量（两份一致）：`M1E_GAP=0.22`、`M1E_PARW=0.15`、`M1E_PARL=1.0`、`M1E_MARGIN=0.005`、`W_DEFAULT=0.30`。
⇒ 官方 M1.e 触发条件是**两个条件的合取**：线宽 > 0.15 **且** 平行段 > 1.0。
**旧件漏了「平行段」这一半** ⇒ 凡 y 向净距落进 [0, 0.22) 一律多退 `M1E_MARGIN` 方向的 0.02µm。

### 实测机理（drv1 v21 非退让变体，gdstk 逐多边形实测，非推算）
```
被改的那条 M1 段   x[34.000, 35.200] y[106.710, 107.010]   (w=1.200, h=0.300)
正上方最近 E 指底座 (33.65, 107.215)-(34.35, 108.77)
   → y 向净距 gap      = 107.215 − 107.010 = 0.205 µm   （< M1E_GAP 0.22）
   → x 投影交叠 ov_x  = 34.350 − 34.000 = 0.350 µm     （≤ M1E_PARL 1.0 ⇒ 官方不触发）
```
⇒ 官方 M1.e **不构成违规**（触发门未成立）⇒ 退让是多余的；旧装配把它退到 gap 0.225。
**两轮官方 DRC 全程没有出现 M1.e 项**（见 §三），这就是「官方不触发」的直接实证——
如果触发成立，DRC 必然报 M1.e 而非只报 M1.b/M2.b/V1.b。

## 三、结论

1. **版本差 = 「多退 0.02µm 的保守装配」，非缺陷、非回归**。官方 DRC 四件全部零差、
   官方 LVS 全部同结论、提取网表逐字节同 ⇒ **对数值链零影响**。
2. **裁定 21.2 的新口径（触发门同样约束自动退让）与官方 deck 一致**；
   旧装配多做的退让是当时为绕开「短差 0.015µm 被 M1.e 抓」（mix v28 案）留下的**过度保守**，
   被沿用进了后续所有件的装配链。
3. **事故定性：我侧代跑依赖登记缺项**。BOOT/纪要长期只记 GDS sha，从未记「装配该 GDS 所用的
   依赖件 sha」⇒ 同名裸名依赖（`import cbpath`）换代后**静默改几何、不报错**。
   他原文说得很准：「**而且不报错、只是悄悄不同**」。

## 五、★ 新通用律 F13（锚的装配依赖登记律）

> **F13**：登记一个面锚时，必须同时登记**装配该 GDS 所用的全部依赖件 sha256**（尤其被 `import`
> 的**裸名**模块：`cbpath` / `resgeom` / `emitpath` / `lib13g2`）。
> 只记 GDS sha 而不记依赖 sha，等于把「**可复现的装配**」记成了「**可复现的几何**」。
> 同名裸名依赖换代会**静默改变几何、不报错**——必须靠「按 sha 取件」纪律兜底。

配套两条：
1. **取件一律按 sha**（他 README 已写死，本组沿用）：目录里那份 ≠ 你要的那份；
   「同名工具模块 + 靠 sys.path 解析」的老坑在这里第二次咬人（第一次是两个 `hbtgeom.py` 打架）。
2. **版本差普查律**：发现依赖代差时，**不逐件猜测影响面，直接四件普查**（复跑 + gdsfp + DRC + LVS），
   把「可能影响 v21」升级成「实测 1/4/3/1 处、DRC 与提取全零差」的定量结论——
   成本约 2 分钟（4 次 gen ＋ 4 次 DRC ＋ 2 次 LVS）。
