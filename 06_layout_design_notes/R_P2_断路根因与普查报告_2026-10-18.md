## 一、根因定位（L92 ①）

**1.1 机制：emitpath 的 P2 引脚距公式与 rsil PCell 真值不符**

- **emitpath 公式**：`y_p2 = y_p1 + 1.56`（resgeom 真值表拟合 0.72+0.84·l，l=1µm）
- **PCell 实测真值**（GDS 逐位）：**rppd 档 P1P2 中心距=1.56**（焊盘 y[−0.430,−0.130]/[1.130,1.430]
  → 中心差 1.56，公式对该档成立）；**rsil 档（w=1.75/4.665）P1P2 中心距=1.40**
  （焊盘 y[−0.330,−0.070]/[1.070,1.330] → 中心差 1.40）——**引脚距随 model/w 档变化，公式只对 rppd 成立**
- **后果**：emitpath 的 P2 stub 从公式点 y_p1+1.56 起画，rsil 真值 P2 焊盘顶在 y_p1+1.53
  → stub 底悬在焊盘顶**上方 0.03µm**（0.16 偏差 − 0.13 半盘高），全同层无 via 跨接 → 直流断路

**1.2 根因代码段**（emitpath.py L200/L205 + gen 调用顺序）：
```python
y_p2 = y_p1 + 1.56                       # 公式预估 P2 pin 中心（仅 rppd 档成立）
b.wire_v("M1", x_col, y_p2, y_p2 + 1.3)  # stub 从公式点向上画
```
gen 里 `place_emit_chain(...)`（画 stub）在 `mkres("Re1",...)`（放 PCell）**之前**调用——
画线时 Re 实例尚不存在，只能用公式预估；mkres 返回的 `Re1.p["P2"]` 真值从未回填校正。
**修法（v20）**：调换调用顺序（先 mkres 后 place_emit_chain，把 `p2_y=Re.p["P2"][1]` 真值传入），
stub 从 pin 真值中心起画；或 place_emit_chain 增加 p2_y 必填参数、断言 |公式−真值|<0.005。

**1.3 与 E 回流 0.085µm 缝：同族不同根因**
- 同族：均为 emitpath 对 PCell 内部几何的**预估偏差型断路**（数字不同）
- 不同根因：0.085µm = via PCell M2 焊盘 enclose 认知差（外沿+0.005/边 vs 外接+0.09/边），
  **v19 已修**（lap=0.6 臂-桶重叠，gen v19 CHANGELOG 在案）；0.03µm = P2 引脚距公式档位错，
  **未修，进 v20 修复单**

**1.4 为什么只有 Re 中招（普查互证）**：mix R1-R4 P2 全连通——**mix gen 不走 emitpath**
（自己从 pin 真值画线）；drv1/drv2 的 Rin/Rb/RL 也连通——它们的 stub 方向朝 P1/焊盘内部
（gen §8 `stub(..., -3.0)` 向下、与焊盘重叠）或由主脚本从 pin 真值画。**唯一受影响面 =
走 emitpath 且 stub 向上离开焊盘的 Re1/Re2 ×2 件 = 4 条**。

## 三、关联疑点（L92 ③）

**3.1 R P2 竖 stub vs nx 小管竖条是否同件/同族？**

**结论：同族（同为 0.30µm 板级 M1 竖条布线产物），不同件、不同根因。**

| 维度 | R P2 竖 stub | nx 小管「C=B 竖线」 |
|---|---|---|
| 来源 | emitpath `wire_v("M1", x_col, y_p2, y_p2+1.3)`（w=0.30 Board 默认） | gen 布线 `wire_v("M1", rbx, rby, rcy)` / `b.wire_v("M1", XQs.p["B"][0], ..., +2.0)`（w=0.30 同默认） |
| 意图 | 有（P2→ntail 引出） | 有（C=B 二极管实连） |
| 缺陷 | 锚点公式错（P2 距档位错 0.16）→ 悬空 0.03µm | **无缺陷**——走线本身正确，是**途经位置**压了 E 指列（通道律缺「避 E 指 x 列」约束） |
| 后果 | 断路（P2 悬空） | 短路（nref/nsens↔gnd） |
| 修法 | gen 源码级：mkres 真值回填（先 mkres 后 chain） | 布线律级：绕 E 指 x 列 ±0.35 外走 |
| 同点 | **均为 Board.wire_v 缺省 w=0.30 的板级 M1 竖线** | 同左 |

**3.2 收敛判断**：两案可收敛为同一根因家族——「**gen 板级 M1 竖线类布线对 PCell 端子
几何的真值脱钩**」：一档脱钩在 y（P2 引脚距公式），一档脱钩在 x（E 指列位置 awareness）。
v20 修复单可合并为一个纲领：**板级竖线一律从 mkpc_at 返回的 pin 真值锚定 + 布线律
避让清单（E 指 x 列 ±0.35）**。回改候选 15 项不必再细分，按此纲领统一出修复件。
